## 二、问题根因

### R1 —— 标签条 sliver 插错层位（上一轮 2-A 的回归）

`lib/pages/member/member_space_page.dart` 的 `headerSliverBuilder` 顺序对比：

| | 顺序 |
|---|---|
| **原始** `62ac3dc`（b7-c4 之前） | `SliverAppBar`(`:856`) → `SliverToBoxAdapter(_buildUserDetailCard)`(`:939`) → `SliverPersistentHeader(标签条)`(`:947`) → `body: TabBarView`(`:965`) |
| **上一轮（错）** | `SliverAppBar` → **标签条** → **详情卡** → `body` —— 标签条跑到统计行**之上** |

- 统计行「关注/粉丝/获赞」在**详情卡内**（`:1490` 起，位于卡尾）；
- 「共 N 支视频」是**视频 Tab 内容的首行**（`:1657` `SliverToBoxAdapter` + `:1664-1667` 文本），属 `body` 区。

→ 标签条正确落位 = **详情卡之后、Tab 体之前**，恰好夹在那两行之间（与用户描述逐字一致）。

### R2 —— 顶栏按钮栏住在封面容器里（耦合）

上一轮结构：`flexibleSpace: Stack[ FlexibleSpaceBar(background: 头图), Positioned(56px 毛玻璃带) ]`
—— 56px 带是**封面容器的子节点**（裁剪域/模糊采样域随封面走），而按钮（`leading`/`actions`）
在 AppBar 工具栏层 → 顶栏没有自己的容器，两容器互相嵌套。

## 三、修复方法（1-A + 2-A + 顶栏带按需显示）

`lib/pages/member/member_space_page.dart` 单文件，+71/−46：

1. **1-A（位置）**：把标签条 sliver 移到 `SliverToBoxAdapter(详情卡)` **之后**，恢复 `62ac3dc` 顺序：
   `顶栏 → 封面 → 详情卡 → 标签条(pinned) → body`。
2. **2-A（解耦）**：
   - 顶栏改为**独立容器**：`SliverAppBar(pinned: true, toolbarHeight: 56, elevation: 0,
     scrolledUnderElevation: 0, backgroundColor/surfaceTintColor: 透明)`，**不再挂头图 `flexibleSpace`**；
   - 封面改为**独立容器**：`SliverToBoxAdapter(child: SizedBox(height: 330, child: _buildHeaderBackground(...)))`
     （原 `FlexibleSpaceBar` 折叠/视差随解耦取消，头图变为纯滚动）。
3. **顶栏带按需显示**：新增 `_tabBandMerged` 判定（标签条带 `GlobalKey` →
   `localToGlobal(Offset.zero).dy <= _topBarHeight(56) + 0.5`，即"标签条已吸附到顶栏下沿"），
   顶栏 `flexibleSpace` 改为 `ListenableBuilder(listenable: _scrollController)`：
   **未合并 → `SizedBox.shrink()`（常态无底、完全透明）**；**已合并 → 通栏毛玻璃带**
   （`MiuixFrostedSurface(borderRadius: 0, outline: false)`），与标签条带拼成一条完整顶栏。
4. 新增常量 `_topBarHeight = 56` / `_coverHeight = 330` 与 `_tabBandKey`；更新 `AppScaffold` 处注释。
