## 1. 问题一：封面「播放量右侧」数据图标错误（实为弹幕数，误渲染成对勾）

### 1.1 现象与取证

- 视频卡片统计行中，播放量右侧图标显示为 **✓ 对勾**；用户疑问「是弹幕还是评论量」。
- 实际数据为**弹幕数**（`VideoCardData.danmakuCount` → `AppIcons.danmakuCount()`）。
- 取证：`docs/icon-sheets/icons/danmakuCount.png` 与 `check.png` 实渲染完全一致（均对勾）；
  正确的弹幕图形已存在于 Web 层 `kWebIconPaths[0xf3fd]` 与字体层 `kBiliSiteIconPaths[0xf3fd]`。

### 1.2 根因链

1. `AppIcons.danmakuCount()` 载体字形为 `Icons.subtitles_outlined`（fontFamily `MaterialIcons`，码点 `0xF3FD`）；
2. BDC 层含 `CupertinoIcons.checkmark`（对勾，fontFamily `CupertinoIcons`）**同码点**条目；
3. `miuixBdcIconFor` 仅按 `glyph.codePoint` 查表，且 BDC 为最高优先级图层 →
   弹幕数被对勾条目截胡，Web 层正确图形永远无法命中。

### 1.3 修复方案与取舍

- 生成器 `tools/bili_bdc_icons_import.py` 输出键改为 **「字体族:码点」复合键**
  （`cupertino:0x…` / `material:0x…`），产物改 `Map<String, String>`；
- 运行时 `miuixBdcIconFor` 按 `glyph.fontFamily`（`CupertinoIcons`/`MaterialIcons`）组键查询；
- 取舍：仅改造 BDC 层（撞码唯一来源层），未整体重构 Web/字体/官方层——
  material 字形 `subtitles_outlined` 修复后落到 Web 层正确图形；
  cupertino 撞码字形（如 checkmark）仍由 BDC 先命中，行为不变；已用单测锁定两条路径。

### 1.4 修复效果验证（编译验证）

- `flutter analyze`：**0 issues**；
- `test/theme/app_icons_test.dart` 新增「L5-10b 跨字体撞码点回归」3 用例通过：
  `subtitles_outlined → webSite.f3fd`、checkmark 仍命中 BDC、material 白名单
  （`alternate_email_rounded`/`campaign_outlined`）不受影响；
- icon-sheet 重生成：`danmakuCount.png` 由 244B→437B，实渲染为**弹幕框图形**（非对勾）。

### 1.5 实机验证（复选框清单）

- [ ] 首页/热门/关注卡片封面左下角统计角标：弹幕图标为弹幕框图形（非 ✓ 对勾）

## 2. 问题二：「稍后再看」图标为未闭合圆圈，缺内部播放图形

### 2.1 现象与取证

- `docs/icon-sheets/icons/watchLater.png`：一枚开口圆环（缺少官方图标内部的播放/箭头图形）。
- 该图标在所有 5 处 UI 一致受影响（互动栏、右键菜单、稍后再看页空态、个人页空卡）。

### 2.2 根因链

`tools/bili_bdc_icons_import.py` 提取视频页内联 SVG `video-watchlater-icon` 时，
**只取第一个带 `d` 的 `<path>` 后 `break`**，官方图标其余子路径（内部播放图形）被丢弃；
（对照 L5-9 工具 `bili_web_icons_import.py` 会收集并合并全部子路径，此处为第一版实现遗漏）。

### 2.3 修复方案与取舍

- 提取循环改为：收集**全部填充型 `<path>`**（跳过无 `d` 与 `fill="none"`，与 L5-9 一致），
  `eo = any(path 含 evenodd)`，合并后统一 bbox 归一化；
- 重跑生成器（Edge 无头渲染视频页 + 官方字体下载），逐条 diff 复核：
  仅键格式全量变化 + `0xf402` 路径补全，其余条目路径与上游源一致。

### 2.4 修复效果验证（编译验证）

- 重生成文件 `lib/theme/app_icons_bdc.g.dart`：`cupertino:0xf402` 为完整图形
  （外圈 + 内部播放三角 + 箭头，多子路径）；
- icon-sheet 重生成：`watchLater.png` 视觉复核 = 圈 + 内部播放三角 + 箭头（与官方一致）。

### 2.5 实机验证（复选框清单）

## 4. 问题四：「更多操作」菜单图标与选项文本同尺寸

### 4.1 现象与根因

- 菜单项图标硬编码 `size: 16`（8 处），行文本 bodyMedium = **14px**；浮层侧
  `IconThemeData(size: 16)` 为**死设置**（显式 size 优先，不生效）；
- 图标来自 4 条管线且混入唯一裸字形 `Icon(Icons.tag)`（"复制 BV 号"），光学大小不一。

### 4.2 修复

- `buildVideoCardActions` 8 处图标**移除显式 size**，由浮层 `IconTheme` 统一驱动；
- 浮层侧 `IconThemeData(size: rowTextStyle.fontSize ?? 14)` —— **图标 = 行文本尺寸**；
- `const Icon(Icons.tag)` → `AppIcon(AppIcons.copy())`（符合「不得直写 `Icon(Icons.*)`」约定，
  BDC 已有 `cupertino:0xf634` copy 图形）；
- 覆盖范围：全部视频卡片入口共用 `showVideoContextMenu`/`buildVideoCardActions`
  （rcmd/hot/follow V 卡、search/detail H 卡、fav/toview 卡片的三点/右键），一处修改全量生效。

### 4.3 实机验证（复选框清单）

- [ ] 右键/三点打开「更多操作」：各项图标大小与文本一致、无突兀大小差
- [ ] 「稍后再看」项图标为完整图形；「复制 BV 号」项不再是裸 # 字形

## 5. 问题五：消息中心会话项支持右键「更多选项」

### 5.1 现状与方案

- 现状：会话项（`_SessionTile`）仅三点按钮可触发菜单；菜单浮层 runner 是
  `video_context_menu.dart` 内私有强类型实现，无法复用。
- 方案：
  1. 新建公共 `lib/common/widgets/miuix_context_menu.dart`：泛化 `ContextMenuAction`
     + `showMiuixContextMenu(context, position, actions, title)`（自 video 文件整体迁移，
     行为不变：180ms 淡入缩放、130ms 延迟关闭、点击外部/Esc 收起、坐标 clamp）；
  2. `session_more_menu_button.dart` 新增 `buildSessionMenuActions()`（置顶/免打扰/删除，
     激活态 primary 色、删除 error 色），三点菜单与右键菜单**共用同一动作列表**；
  3. `_SessionTile` 外包 `GestureDetector(onSecondaryTapUp → 全局坐标弹菜单)`；
     删除动作沿用二次确认 `_confirmRemove`；
  4. `miuix_popup_menu.dart` 菜单壳 `_buildRows` **补传 leading**（历史遗留：自绘壳未接
     `MiuixDropdownItem.icon`，图标不渲染），图标尺寸随行文本 —— 三点菜单与右键菜单一致。

### 5.2 影响面核对

- 全仓仅会话菜单向 `MiuixDropdownItem` 传 `icon`；其余调用点（登录/直播/空间/播放器）
  未传 icon，**不受影响**；
- 死代码 `session_list_page.dart`（无调用方）未改动。

### 5.3 实机验证（复选框清单）

- [ ] 消息中心右键任意会话 → 弹出「更多选项」（置顶/免打扰/删除，带图标）
- [ ] 三点按钮菜单同样显示图标，与右键菜单内容一致
- [ ] 置顶/免打扰/删除（二次确认）功能正常
