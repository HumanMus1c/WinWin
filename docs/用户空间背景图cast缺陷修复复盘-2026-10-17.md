# 用户空间背景图 cast 缺陷修复复盘（2026-10-17）

> 范围：`lib/http/member.dart`（新增 `asJsonMap` + 13 处替换）+ 回归测试。
> 关联：本文件为「非 B7 项」审计轨迹，不计入 B7 批次；闸门（`lib` 内 `import 'package:material_ui` 文件数）保持 **5**。

## 一、现象

用户空间（`MemberSpace`）页面加载时告警：

```
[W] MemberSpace: topPhoto 加载失败 err=获取背景图失败：type 'String' is not a subtype of type 'Map<String, dynamic>' in type cast
```

- 来源 `D:\Documents\logs\runtime.log`：2026-10-16 18:14 起，2026-10-16 23:02 / 2026-10-17 15:24 多次再现（≥8 次）。
- 用户可感知表现：空间页**顶部背景图不显示**（其余板块可能并发报「用户隐私设置未公开」）。

## 二、定因

- 崩溃点：`lib/http/member.dart` 的 `MemberHttp.topPhoto`（原 L344）`final data = res.data as Map<String, dynamic>;`。
- `/x/space/top/photo` 在**风控 / 限流 / 接口异常**时返回**非 JSON** 响应体（HTML 错误页、空体、`text/plain` 字符串），
  Dio 未反序列化为 `Map` ⇒ `res.data` 为 `String` ⇒ 裸 `as Map<String, dynamic>` 抛
  `type 'String' is not a subtype of type 'Map<String, dynamic>' in type cast`，被方法尾部
  `catch (e)` 兜成「获取背景图失败」。
- **同型缺陷面**：`member.dart` 共 **13 处**裸 `res.data as Map<String, dynamic>`（`space`/`space-web`/`archive`×2/
  `spaceSs`/`spaceNavNum`/`topPhoto`/`card`/`bangumi`/`silence` 等），全部同型、同一崩溃类。
- 对照：`fav.dart`、`search.dart`、`toview.dart`、`user.dart`、`video.dart` **已**用 `is Map<String, dynamic>` 守卫，
  唯独 `member.dart` 漏守 ⇒ 属**解析防御缺项**，非「接口不可用」。

## 三、方案

- 于 `MemberHttp` 新增 `@visibleForTesting static Map<String, dynamic> asJsonMap(dynamic body)`（单点定义降级口径）：
  - `Map` → 原样返回；
  - `String` → 尝试 `jsonDecode`（兼容 content-type 未标 JSON 的 JSON 文本）；
  - 其余（含解析失败）→ 记 `AppLogger.w`（含 `runtimeType`，保留可诊断线索）并返回**空 Map**。
- 13 处 `res.data as Map<String, dynamic>` → `asJsonMap(res.data)`：非 Map 降级为空 Map ⇒ 自然落入各站点
  **既有的 `code != 0` 分支**给出友好错误，不再抛 TypeError；**happy path 行为完全不变**（正常 JSON 仍走原逻辑）。
- 新增 `import 'dart:convert';`。
- 取值口径：不新增分支/不新增文案（复用各站点既有默认错误消息），把改动面压到最小。
