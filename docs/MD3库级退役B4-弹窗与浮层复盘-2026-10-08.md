# MD3 库级退役 B4（弹窗与浮层替身）复盘 — 2026-10-08

> 所属批次：MD3 库级/骨架层退役计划 · Part B · **B4（showDialog / showModalBottomSheet → showAppDialog / showAppSheet）**
> 前置：L0（替身层）/ B1 / B2 全家 / B3 已完成并推送。

## 1. 背景与目标

- Material 的 `showDialog` / `showModalBottomSheet` 会创建 **Material 侧路由与内建 Material 主题依赖**，
  是 MD3 库级退役中弹层这一层的入口。
- L0 阶段已准备替身 `lib/core/shell/app_dialogs.dart`（`AppDialogRoute` / `AppSheetRoute`，均为
  **`PopupRoute` 子类型**——这是 `AppEscapeScope` 的"栈顶是否弹层"判定（Esc 第一层）赖以生效的契约）。
- **B4 目标**：把全库 `showDialog` / `showModalBottomSheet` 调用点切到替身，弹层不再经由 Material 路由体系。

## 2. 定因与方案决策

| 决策 | 说明 |
| --- | --- |
| 替换面 | **43 处 / 33 文件**：`showDialog` 39 处 + `showModalBottomSheet` 4 处（含 `<T>` 泛型形态） |
| 参数核查 | 事前扫描确认调用点**不使用** Material 版的特有参数（`useSafeArea` / `routeSettings` / `anchorPoint` / `isDismissible` / `enableDrag` / `shape` / `constraints` 等命中均为 0） |
| 签名对齐 | 41 处调用点均写作**具名** `context: context,` → 把替身 API 改为 `required BuildContext context`（具名必填，与 Material 版一致），**只改替身 1 处而非改 41 处调用点**（最小 diff、语义对齐） |
| `backgroundColor` | 2 处 sheet 调用传入 `Colors.transparent` → `AppSheetRoute` 补该参数：非空时包一层 `ColoredBox`（null = 内容自绘底色，**零漂移**） |
| 转场口径 | 对话框淡入 + 0.94→1.0 轻微放大；面板自下滑入；时长沿用 `kMiuixTransitionDuration`（关闭 200ms） |
| 内容控件 | `AlertDialog` / `SimpleDialog` / `Dialog` 等**内容控件**仍为 Material 控件（属 B6/B7 清扫面），本批只替换"弹出通道" |
