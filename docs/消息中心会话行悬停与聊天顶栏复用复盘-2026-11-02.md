# 消息中心会话行悬停反馈与聊天页顶栏复用复盘（2026-11-02）

轮次：消息中心视觉收口（非退役批次，闸门 0→0）
改动文件：`lib/pages/whisper/session/session_list_section.dart`、
`lib/pages/whisper/session/chat_detail_page.dart`、
`lib/pages/whisper/session/session_list_page.dart`

## 一、现象

CVO 三条反馈（附会话行实机截图）：

1. **会话行的 hover / 按压反馈只作用在卡内子容器**，不是整条对话条：
   鼠标移入时只有 12×8 内距里的内容区变色，卡面底色与左右出血区无反应；
   按下时只有内容微缩，卡底不动。
2. **进入对话后没有顶栏**：私信会话页看不到对方头像与昵称，与列表里的会话行割裂。
3. 对话页顶栏应**复用消息中心的毛玻璃效果**，让消息内容可从其后透出。

## 二、定因

1. 会话行的层级是 `MiuixCard` **在外**、`MiuixPressable` **在内**（卡内容区）。
   库源码 `miuix_pressable.dart`：hover/press 遮罩是 `Positioned.fill` 覆盖**自身子树**；
   sink 是 `Transform.scale` 缩放**自身子树**（`miuix_card.dart` 只在传 `onPressed`
   时才把 `MiuixPressable` 包在卡外）。故遮罩只铺满内距内的 `Row`、sink 只缩放内容，
   卡面（squircle 卡底 + 12px 出血区）不参与反馈。
2. `ChatDetailPage` 只有 `AppScaffold(title 未传)` + `Column[消息列表, 输入条]`，
   没有任何顶栏；入口 `showChatDetailPage` 也未携带会话昵称/头像。
3. 顶栏缺失，自然谈不上毛玻璃透出。

## 三、方案

### 3.1 会话行：反馈上移到整卡

`_SessionTile.build` 交换层级 —— `MiuixPressable` **包住** `MiuixCard`：

| 项 | 取值 | 说明 |
|---|---|---|
| 层级 | `GestureDetector`(右键) → `MiuixPressable` → `MiuixCard` → `Row` | 遮罩铺满卡面、sink 缩放卡片本体 |
| 遮罩形状 | `shape: const MiuixSquircleBorder(cornerRadius: MiuixCardDefaults.cornerRadius)` | 与卡底**同形**（squircle 16），避免圆弧遮罩在卡四角露出方形/圆弧边 |
| 按压反馈 | `feedbackType: sink` / `sinkAmount: 0.98` | 项目既定「整卡轻下沉微缩」口径，不变 |
| 卡内距 | `insideMargin` 仍在 `MiuixCard` 上（12×8） | 内容呼吸不变，仅反馈作用面扩大 |

### 3.2 聊天页：顶栏复用头像 + 昵称

- `showChatDetailPage` / `ChatDetailPage` 新增可选 `peerName` / `peerAvatar`；
  消息页会话列表（`session_list_section._SessionTile`）与旧会话列表页
  （`session_list_page._SessionTile`）都把已解析好的 `_name` / `_avatar` 下传。
- 页内为空时回退 `SessionAccountResolver.displayName/displayAvatar`（同一份进程内缓存），
  保证其它入口进来也不空白。
- 演示模式下昵称沿用骨架占位（与列表行同口径），头像走 `MsgFeedAvatar` 的演示兜底。

### 3.3 聊天页顶栏：同源毛玻璃 + 内容透出

- 骨架改 `reserveTopStrip: false`（不再预留 50px 空白安全行），body 改 `Stack`：
  - 底层 `Column[消息列表, 输入条]`（铺满整页）；
  - 顶层 `Positioned(top:0)`：`RepaintBoundary(SizedBox(key: _headerKey, child: AppTopBarSurface(...)))`。
- 材质**单一来源** `AppTopBarSurface`（与消息页合并栏 / 首页顶栏同款）：
  `surface × 0.72` + `σ20` 模糊 + `chrome.containerRadius` + `floatingShadow`；
  故消息上滑到顶栏后方时可模糊透出。
- 顶栏内容：预留 30px 壳层返回按钮槽位（`GlobalBackButton.defaultLeft` 8 +
  `boxSize` 42 − 内容左缘 28 + 8 间隙）→ `MsgFeedAvatar(size: 32)` → 昵称
  （`titleMedium / w600`，单行省略）。
- 列表避让：`padding.top = 顶栏实测高度 + Style.sm`；顶栏高度首帧用预算
  `_headerReserve = Style.sm×2 + Style.xs×2 + 32 = 56` 兜底，post-frame 实测回填
  （对齐消息页合并栏做法），避免字号/缩放变化时首条消息被顶栏遮住。

## 五、遗留与踩坑

- **踩坑：`topBar` 槽不能用**。`AppScaffold.topBar` 会把 body 按栏高内缩 ⇒ 内容无法
  从顶栏后方穿过，毛玻璃没有可透出的东西。必须 `reserveTopStrip: false` + `Stack`
  叠层 + 列表**自身** `padding` 避让（`Padding` 包列表同样不行：视口裁剪后内容到不了
  顶栏后方）。
- **reverse 列表的 `padding.top` 仍是视觉顶部**：`RenderSliverPadding` 把 `top` 记为
  `afterPadding`（`beforePadding` 取 `bottom`），故 `ListView(reverse: true)` 的
  `padding.top` 就是屏幕上方，可直接用作顶栏避让。
- **顶栏与返回按钮存在 ~3px 纵向差**：`AppTopBarSurface` 固定外距
  `vertical: Style.sm`（可见栏体从 y=8 起），壳层返回按钮固定 `top: 4`（42 高）。
  同一毛玻璃材质下重叠区域自然融合，本轮不为 3px 偏移改共享组件。
- **范围口径**：本轮只动「会话行」（私信对话）。消息中心内「回复我的 / 艾特我的 /
  点赞我的 / 系统消息」是消息条目而非会话，行控件未改。
- 对话顶栏未放三点菜单/免打扰等会话级操作（未在需求内，如需再单批）。

## 六、总结

会话行把 `MiuixPressable` 从卡内提到卡外并用同形 squircle 遮罩，hover/press 从此覆盖
整条对话条（含卡底与出血区）；聊天页新增与消息中心同源的浮动毛玻璃顶栏，头像与昵称
由会话行直接下传（缓存兜底），消息可从顶栏后方穿过并被模糊透出。四关全绿
（analyze 0/0、test 285、debug √、release √），三文件改动，回滚点明确。

## 七、反馈轮 1：顶栏与返回按钮重叠（并列 / 同级 / 自适应）

**（本节推翻 §3.3 的顶栏几何，以本节为准。）**

### 7.1 现象

实机截图：壳层返回按钮（白色圆形毛玻璃）**压在**对话页顶栏左端 —— 圆钮一半在栏内、
一半在栏外，观感是「按钮浮在栏上」；同时顶栏横跨整个窗口。

CVO 要求：① 二者保持安全间距、**不再重叠**；② 二者**同级层级**；③ 顶栏宽度**自适应
屏幕宽度**（窄屏也能自适应）。

### 7.2 定因

旧实现把顶栏做成全宽浮动面板，仅在面板**内容**里为按钮预留 30px 槽位：
`AppTopBarSurface` 的栏体固定从 `x=16` 起（外距 16），而壳层返回按钮占 `x=8..50`
且**挂在 Navigator 之上**（壳层单实例，见 `global_back_button.dart`）。槽位只保证
「文字不被按钮压住」，栏体本身仍与按钮相交 ⇒ 必然叠层。

### 7.3 方案

顶栏改为与返回按钮**并列的同一行**（不再是「按钮 float 在面板上」）：

| 项 | 取值 | 说明 |
|---|---|---|
| 位置 | `Positioned(top: GlobalBackButton.defaultTop, left: _headerLeft, right: Style.lg, height: GlobalBackButton.boxSize)` | `_headerLeft = defaultLeft + boxSize + Style.sm` = **58**；与按钮同顶(4)、同高(42)、间距 8 |
| 圆角 | `borderRadius: GlobalBackButton.boxSize / 2` = 21 | 胶囊，与按钮的圆形同半径族 |
| 材质 | `MiuixFrostedSurface(color: AppTopBarSurface.barColor(surface), blurSigma: AppTopBarSurface.blurSigma, outline: false, shadow: false)` | **与壳层返回按钮逐项同源**（`FrostedCircleIconButton` 内部即本组件）⇒ 同一层级观感 |
| 宽度 | 只给 `left/right` | 栏宽恒 `窗口宽 − 58 − 16`，随窗口伸缩；最小窗口 640 下栏宽 ≥ 566，昵称 `Flexible + ellipsis` |
| 内容 | `SizedBox.expand` 撑满 42 高 → `Padding(horizontal 12)` → 头像 32 + 8 + 昵称 | 高度恒定后内容纵向居中 |
| 列表避让 | 常量 `_headerBottom(= defaultTop + boxSize = 46) + Style.sm` | 顶栏高度不再由内容自撑 ⇒ 删 `GlobalKey` 实测回填（`_headerKey/_headerHeight/_headerReserve/_measureHeader` 全删） |

不再使用 `AppTopBarSurface` 组件本体（其固定外距 16 + 固定内边距使栏体必然覆盖按钮位），
只复用其**材质常量**（`barColor` / `blurSigma`），材质口径仍单一来源。
