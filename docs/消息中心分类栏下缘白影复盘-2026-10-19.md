# 消息中心分类栏「下缘白影」复盘 — 面板自身投影被 BackdropFilter 自采样

- 日期：2026-10-19
- 快照基准：`refs/snapshots/latest` = `096fbe7`（改动前状态；回滚见第五节）
- 触发：CVO 实机反馈「消息中心的分类栏的下缘会向框架内发散白色阴影，导致各分类筛选看不清」，指令「修」

## 一、现象

CVO 截图（`uploads/1792391007534-5af9646b.png`）：分类栏**下缘向面板内发散白色阴影**，各筛选项看不清。

**取证限制（本轮硬约束）**：本会话无 `visual_question_answering` 工具，`read_file` 对 png 直接报错 ⇒ 看不到图。改为对两张上传图做**逐像素剖面**（Pillow/numpy）反推：

| 图 | 尺寸 | 实测 |
|---|---|---|
| 裁图（本次报障） | 972×71 | 面板内底色**平 231**；两条**全宽 1px 硬线 = 209**（分隔线）；chips 药丸 200、文字 32；下缘下方 y66–70 为**平 224** |
| 原图（同场景） | 2460×263 | 面板内部与页面底色**几乎同值（~250，看不出分离）**；面板底缘 250→238，**1~2px 硬跌** |

**两条结论**：① **不存在比面板更亮的「白晕」**（max 始终被封顶）；② 特征实为「**面板与其下背景几乎同值** + 下缘 1~2px 硬跌 + 紧邻一条略暗带」——现象是**边界/底色定义缺失**，不是多了一道白光。

## 二、定因

三条叠加，均有代码依据（`lib/common/widgets/miuix_frosted_surface.dart`、`lib/pages/whisper/view.dart`）：

1. **面板把自己画的投影也糊进去了**。面板档 = `Container(boxShadow: black α0.15 / blur 16 / offset (0,4)) → child = frosted`；`Container.decoration` 的投影在 child **之前**绘制、属 backdrop，于是 `_edgeSafeFrost` 里的 `BackdropFilter` **采样并模糊了面板自身的投影**，从下缘向上浸润约 σ(16)~3σ(48)px——**恰是分类栏所在行**。
2. **填充仅 α0.85**（`kMiuixSurfaceAlpha`）：可见色 = `0.85×base(EAEAEA) + 0.15×blur(其下像素)`。消息页该面板**背后与下缘外侧是空白页底**（上一轮 `_headerReserve = 171` 把列表推下去），blank 底色经 σ16 模糊**从下缘向内**浸入 ⇒ 这段「由背景决定、非面板自定义」的浸润带即白影。
3. **上一轮 `outline: false` + chips 紧贴面板底缘**（`SessionFilterBar` 仅 chips `top: 6`、几乎无底距）：去掉 1px 边线后下缘失去硬定义 ⇒ 白影「发散」；chips 正落在浸润最强带内 ⇒ 与面板底色对比被压低 ⇒ 看不清。

放大因素：`_headerReserve = 171` 是**预算常量**，与面板实际高度存在偏差 ⇒ 兼有「面板下方露白」与「chips 贴底」两向风险。

## 三、方案

对齐已被验收的首页合并栏口径（首页自绘毛玻璃：无投影、无描边、`Stack` 浮顶）：

1. **共享材质增投影开关**：`MiuixFrostedSurface({bool shadow = true})`——默认 true，其它调用方（弹层/菜单）**零影响**；面板档投影抽为局部 `shadows` 变量后按 `shadow` 取舍。
2. **消息页合并栏传 `shadow: false`**：消除根因 1（自采样）。
3. **分类栏末端加底距** `_filterBarBottomGap = 24`：把 chips 抬出下缘那条 ~3σ 浸润带（根因 2、3）。
4. **顶部避让由预算常量改实测**：`_headerKey`（`SizedBox` 包 `_buildFrostedHeader`）+ 首帧后 `_measureHeader()` 回填 `_headerHeight`，`topInset: _headerHeight ?? _headerReserve`；`_headerReserve` 退化为**首帧回退值**——顺带消除「面板高度与避让量不符」造成的首行遮挡/露白。
5. 有意不动：`outline: false`（首页口径）、`bleed = 3σ` 外扩（2026-10-16 已定，消除 clamp 渐变）。

## 总结

现象不是「多了一道白光」，而是**面板下缘那一条带的颜色不是面板自己定的**——它下边的背景（空白页底 + 它**自己的投影**）透过 α0.85 的填充、被 σ16 模糊从下缘向内浸出来；越靠下缘越虚，恰好压住分类栏。上一轮的 `bleed`（外扩 3σ）只搬走了模糊核的**边界夹断渐变**，**管不到「面板自身投影被自己采样」与「邻域背景混入」**。本轮三件事把这条带还给面板：① 关掉自采样（`shadow: false`）、② 把 chips 抬出 3σ 带（24px 底距）、③ 避让量改用实测高度。双编译均 √ Built，可一键回到 `096fbe7`。
