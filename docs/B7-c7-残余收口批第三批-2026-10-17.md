## 反馈轮（2026-10-17，实机）

**反馈**：滚动条未贴窗口右缘、间距偏大且疑似被遮挡；hover 视觉效果过弱。

**定因**（截图右缘采样 + 只读源码）：
- 截图（64×1000 右缘裁切）右侧 12px 纯背景实为内容 `SliverPadding(Style.safeSpace = 12)` 的内缩，滚动视图右缘 ≈ 窗口右缘（`MiuixScaffold` 在 Windows 的 content padding = `MediaQuery.paddingOf` = 0）——**非骨架留白**；
- 滑块绘制位置 = `size.width - thumbWidth - endPadding`，默认 `endPadding = 3.46` ⇒ 距边 3.5–7px；
- Miuix 把滚动条铺满**整个面板**，其内部 `MouseRegion` 覆盖面板 ⇒ 鼠标进入页面**任意处**即触发 hover；且 hover 仅 alpha 0.1→0.3、宽度 3.64→6 ⇒ 视觉偏弱。

**修法**（重写 `lib/common/widgets/app_scroll_bar.dart`，`StatelessWidget` → `StatefulWidget`）：
1. **贴边**：`endPadding = 1`（滑块右缘距面板右缘 1px）；
2. **hover 只作用于滑轨**：滚动条收进右侧 `hitThickness = 14` 窄条 `Positioned` 内，并在该窄条挂 `MouseRegion`——仅鼠标进入滑轨带才触发强化样式；
3. **强化 hover**：滑块 alpha 0.30 → 0.65；显示可见滑轨 `trackColor`（alpha 0 → 0.12）；叠加 Miuix 宽度动画 3.64 → 6；过渡用 `TweenAnimationBuilder`（140ms, easeOut）平滑。

**验证**：`dart analyze` **No issues found!** / `flutter test` **All tests passed! (+174)** / `windows --debug` **√ Built 31.9s** / `windows --release` **√ Built 82.9s**（release 因用户运行中实例占用 `WebView2Loader.dll` 触发 MSB3026 重试后成功；**未按进程名杀进程**）；闸门保持 **5**。

## 反馈轮 2（2026-10-17，实机）

**反馈**：滚动条仍画在**窗口内容之上**，未处于「内容区域」与「窗口边缘」**之间**。

**定因**（截图右缘采样 + 全仓排查）：
- 新截图（77×135 右缘裁切）读数：距右缘 0–11px = 背景 `(250,249,250)`；12–15px = 灰色滑块 `(225,224,225)`；16px 起 = 内容面 `(253,252,253)` ⇒ 滑块落在**内容边界处**，而非外侧空当。
- 性质判定：上一轮采用 **`Stack` + `Positioned(right: 0, width: 14)` 叠加**方案 —— 滚动条**盖在内容最右侧 14px 之上**。只要内容在该区域有任何绘制（全出血图/贴边卡片），即呈「在内容上方」。
- 全仓排查确认：`lib/` 内**只有** `bangumi_detail_page` 使用滚动条（`AppScrollBar` ×3，无其它 `Scrollbar`/`CupertinoScrollbar`/`RawScrollbar`）；`MainLayout`、`AppShell` 均**无右内边距**（仅有左侧 `AppNavRail`）⇒ 页面右缘 ≈ 窗口右缘，问题不出在外部内缩，而出在**叠加式定位本身**。

**修法**（重写 `lib/common/widgets/app_scroll_bar.dart` 布局层，`Stack` 叠加 → **预留独立通道**）：
- 竖向：`Row[ Expanded(child: 内容), SizedBox(width: laneThickness = 12, child: 滚动条) ]`（`crossAxisAlignment: stretch`）；
- 横向：`Column[ Expanded(child: 内容), SizedBox(height: laneThickness, child: 滚动条) ]`；
- 内容区经 `Expanded` **左移** 12px，滚动条**独占最外侧 12px 通道** ⇒ 处于「内容区域」与「窗口边缘」**之间**，**永不覆盖内容**；
- 通道即 hover 触发带（`laneThickness` 取代原 `hitThickness`）；保留 `endPadding = 1`（贴边）与强化 hover（alpha 0.30→0.65 + 可见滑轨 + 宽度动画 3.64→6 + 140ms easeOut）。
