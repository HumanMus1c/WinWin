# 播放器设置弹层常显与音量条统一弹层复盘（2026-10-21）

> 提交：`b074dbe`（代码 + 相关展示）　回滚点：`28a9251`

## 一、现象描述（CVO 反馈）

1. **设置弹层弹出时控制栏仍会消失**：播放器的某些设置弹层（音量弹层、章节面板、弹幕设置、
   字幕设置、发弹幕、画质/音轨/倍速菜单）打开后，控制栏仍会在约 3 秒后自动隐藏；这些弹层
   的锚定按钮就在控制栏上，控制栏一隐藏，弹层便失去依托。关闭弹层后也没有重置自动隐藏计时，
   控制栏不会重新停留一个完整周期。

2. **音量条外观与播放器其它弹层不统一**：音量弹层用旧的「黑色玻璃胶囊」（`GlassCapsule`）
   作底衬、底轨硬编码半透明白，与播放器其它弹层（投币 / 表情 / 弹幕样式面板所用的
   `MiuixOverlayPanel` 毛玻璃面板）明显不是一套；且**只有突现、没有关闭动画**，与
   「对角线弹出 / 收起」的统一弹层动效不符；音量条粗细固定，未随音量变化。

## 二、问题定因

**子任务 1（控制栏自动隐藏）：** 控制栏自动隐藏由 `_PlayerPanelState` 的 3s `_hideTimer` +
`_maybeAutoHide()` 实现，其放行（允许隐藏）条件当时只拦了两个布尔：

```
!_locked && c.playing.value && !_draggingProgress && !_volumePopupOpen && !_chapterPanelOpen
```

即只登记了「音量弹层」和「章节面板」。其余三类设置弹层**未登记**：

- 弹幕设置 / 字幕设置 → `showAppDialog`（`AppDialogRoute`，盖在 Navigator 之上）；
- 发弹幕 → `showAppSheet`（`AppSheetRoute`）；
- 画质 / 音轨 / 倍速 → `MiuixPopupMenu`（渲染在**根 Overlay**）。

这三类弹层打开时，`_hideTimer` 照常到期把控制栏隐藏，弹层与锚定按钮脱钩。关闭后也无任何
回调去重置计时器。

**子任务 2（音量条外观）：** 音量弹层用 `AppAnchoredPopup` + `GlassCapsule`。`
AppAnchoredPopup` 是**纯定位件**（`Positioned.fill` + `CustomSingleChildLayout`，只负责居中
锚定、翻转、夹边，**不含动画**）；音量弹层又在 Stack 里以 `if (_volumePopupOpen)
_buildVolumePopup()` **条件挂载**——打开即突现、关闭即卸载子树，天然没有关闭动画可播。
底衬 `GlassCapsule` 与其它弹层的 `MiuixOverlayPanel`/`MiuixFrostedSurface` 材质并非同源，
底轨 `AppColors.white24` 是旧黑色胶囊底衬的遗留口径；`MiuixSlider` 的 `height`（=轨道粗细，
同时决定拇指半径）当时未随音量变化，故粗细恒定。

## 三、修复方案

### 子任务 1：弹层挂起（`_popupSuspend` 计数）

- `_PlayerPanelState` 新增弹层打开计数 `int _popupSuspend = 0`：
  - `_beginPopupSuspend()`：计数 +1、取消 `_hideTimer`、保持 `_controlsVisible = true`；
  - `_endPopupSuspend()`：计数 -1，归零**且控制栏仍可见**时 `_resetHideTimer()`（重置为完整
    3s 周期）；控制栏已被隐藏则不强行弹出。
- `_openSuspending(Future<void> Function())`：把「打开即返回、关闭才完成」的弹层调用包在
  挂起区间内（`_beginPopupSuspend()` → `await open()` → `finally _endPopupSuspend()`）。
- 接线：
  - `_setVolumePopupOpen` / `_setChapterPanelOpen`（唯一出口）打开时 begin、关闭时 end；
  - 弹幕设置、字幕设置、发弹幕：三个 `showX` 由 `void` 改为返回 `Future`（`showAppDialog` /
    `showAppSheet` 本就返回 Future），调用点改用 `_openSuspending` 包裹；
  - `MiuixPopupMenu` 新增可选 `onOpenChanged` 回调（`_show` → true，`_close` → false），
    播放器经 `_onMenuOpenChanged` 挂起/恢复。
- `_maybeAutoHide` 的隐藏条件统一由 `_popupSuspend == 0` 把关（取代原两个布尔）。
- `_hideControlsNow`（鼠标移出）在「其它设置弹层打开」时保持显示；音量弹层自身仍随控制栏
  一并收起（否则鼠标移出播放器，音量弹层会悬空）。

### 子任务 2：音量条统一弹层样式 + 动态粗细

- 新增通用动画壳 `MiuixAnchoredPopup`（`lib/ui/components/app_anchored_popup.dart`）：在
  `AppAnchoredPopup` 的定位之上叠加**对角线** `Fade + Scale`（0.92→1，easeOutCubic，
  180ms 展开 / 140ms 收起，缩放原点取贴触发器一角 `Alignment.bottomRight`），由 `visible`
  驱动，收起动画播完再卸载为空子树。与表情面板 / 弹层菜单同一「对角线展开」范式。
- 音量弹层改用 `MiuixAnchoredPopup` + `MiuixOverlayPanel`（毛玻璃面板，与投币/表情/弹幕样式
  面板同源）。外层定宽 `264`、内容定宽 `232`、标签槽定宽 `72`——避免 `MiuixOverlayPanel`
  标题行（`MainAxisSize.max`）在锚定浮层的 loose 约束下被拉成整页宽，以及 `(增益)` 后缀导致
  弹层变宽、滑条/拇指横向瞬移。
- 强调色取**主题色** `AppThemeHost.of(context).colors.primary`（浅色即 #FA7298）；
  `>100%` 增益态仍用琥珀色 `amberAccent` 区分。底轨改用主题默认
  `MiuixSliderDefaults.sliderColors(context).backgroundColor`，不再硬编码半透明白。
- 音量条粗细**实时动态变化**：`MiuixSlider.height = lerpDouble(14, 28, (vol/100).clamp(0,1))`
  —— 0% 最细 14px、100% 最粗 28px（上限沿用 `MiuixSliderDefaults.minHeight`）。
- Stack 中音量弹层改为**常驻子树**（去掉 `if (_volumePopupOpen)` 条件挂载），使关闭动画得以播放。

## 五、遗留与踩坑

- **Git Bash 缺 `ProgramFiles(x86)` 环境变量**：直接 `flutter build windows` 在此环境会以
  `%PROGRAMFILES(X86)% environment variable not found.` 收尾并失败。解法：用
  `env "ProgramFiles(x86)=C:\Program Files (x86)" "ProgramFiles=C:\Program Files" flutter build ...`
  前缀补上（`bash` 变量名不能含括号）。
- **Release 构建被运行中实例占用 DLL**：`winwin.exe`（PID 17776）持有
  `runner\Release\WebView2Loader.dll`，MSBuild 复制重试 10 次后报 MSB3027/MSB3021 失败。
  按既有授权**仅按 PID** 结束该残留实例后重编即通过；本 Agent 严格遵守「按 PID、绝不经
  进程名/killall/重启运行时」的硬约束。
- **`MiuixSlider.height` 同时决定轨道粗细与拇指半径**（拇指半径 = height/2）：动态粗细会
  连带改变拇指大小。本轮按「音量条整体由细到粗」处理，观感一致；若后续要求「轨道变、拇指
  不变」，需改为自定义绘制或包裹缩放，代价较大。
- **音量弹层「常驻子树」的性能**：收起后 `MiuixAnchoredPopup` 返回 `SizedBox.shrink()`，不占
  布局、不参与命中，故常驻挂载的额外开销可忽略。
- **术语对齐**：「播放器统一抽象的弹层样式」在本项目落地为
  `MiuixOverlayPanel`（毛玻璃面板）+ 调用方侧的对角线 `Fade+Scale` + 主题强调色。此为按既有
  实现的一致性推定，若 CVO 指的是别的具体样式，请指出以便对齐。
