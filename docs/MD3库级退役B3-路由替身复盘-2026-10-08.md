# MD3 库级退役 B3（路由替身）复盘 — 2026-10-08

> 所属批次：MD3 库级/骨架层退役计划 · Part B · **B3（路由替身 + Material 转场主题体系退役）**
> 前置：L0（替身层）/ B1（应用壳）/ B2 全家（主题读取通道）已完成并推送。

## 1. 现象与背景（为什么需要 B3）

- 起源问题（已修复）：进出视频页时页面瞬间叠在沉浸标题条之上又瞬间恢复——根因是 material_ui 在
  Windows 的平台默认转场 `ZoomPageTransitionsBuilder` 会把路由内容**放大到视口之外**（push 旧页 1.05、
  pop 被弹出页 1.10），而应用壳的内容区是 Column（32px 标题条 + 路由区）且不裁剪子节点绘制。
- L0 阶段曾用过渡手段：`lib/theme/miuix_page_transitions.dart` 注册 `pageTransitionsTheme`
  （仅对 **Material 路由**生效）。只要页面仍用 `MaterialPageRoute`，就仍受 material 转场体系约束。
- **B3 目标**：把全部 `MaterialPageRoute` 切到自建 `AppRoute`（widgets 层 `PageRouteBuilder` + 统一
  `MiuixPageTransition` 转场核），并**彻底退役 Material 侧 `pageTransitionsTheme` 体系**，消除双轨歧义。

## 2. 定因与方案决策

| 决策 | 说明 |
| --- | --- |
| 替身选型 | `AppRoute<T>` 继承 **widgets 层** `PageRouteBuilder`（零 Material 依赖），转场复用 `MiuixPageTransition`（新页淡入 + 轻微上移 16px；**被覆盖页静止**，不读 `secondaryAnimation`） |
| 时长口径 | `kMiuixUiTransitionDuration`（300ms，与 L0 优化后的核一致），`transitionDuration` / `reverseTransitionDuration` 双设 |
| 参数兼容性核查 | 全库 127 处用法**仅使用 `builder:`**（`maintainState` / `allowSnapshotting` / `fullscreenDialog` / `settings:` 命中均为 0）→ 替换为纯机械替换，无参数缺口 |
| 转场主题退役 | 删除 `lib/theme/miuix_page_transitions.dart`（`kMiuixPageTransitions` / `MiuixPageTransitionsBuilder` / `kUseMiuixPageTransitions` / `kMiuixPageTransitionDuration`），并移除 `app_theme.dart` 中两处 `pageTransitionsTheme` 覆写与 import |
| 测试口径改写 | `test/immersive_title_bar_test.dart` 原断言"windows/linux/android/fuchsia → MiuixPageTransitionsBuilder、iOS/macOS → Cupertino"（依赖已退役的主题体系）→ 改为 **AppRoute 口径**：转场时长等于 `kMiuixTransitionDuration`、过渡期主题不再注册 Cupertino 覆写；两处测试路由也切到 `AppRoute` |
