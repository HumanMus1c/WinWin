# 视频播放页分P切换条（2026-11-13）

## 一、需求

视频详情页此前只播放 `pages.first`（首个分P），多分P稿件无法在页面内切换。本次在**弹幕发送栏下方**新增一行分P 切换组件：横向排列各分P 胶囊，点选即换源播放，当前分P 高亮标识。

## 二、方案

### 1. UI：弹幕发送栏下方一行（仅多分P稿件显示）

[detail_page.dart](file:///d:/Documents/GitHub/WinWin/lib/pages/video/detail_page.dart) 新增 `_buildPageSelector`：

- 仅当 `pages.length > 1` 时插入 `SliverToBoxAdapter`，位置紧贴 `SendDanmakuPanel` 之后，沿用 `kDetailContentPadding` 与播放器/弹幕条对齐；
- 左侧「分P」标签 + 右侧横向滚动 `ListView.separated`（`AppScrollController`，滚轮平滑）；
- 每个分P 为 `MiuixPressable` 胶囊（sink 0.98 按压反馈 + hover），文本为 `P{序号} {分P标题}`（标题最多 200px、单行省略，`AppTooltip` 悬浮显示完整标题），尾部附分P 时长；
- 选中态：`primaryContainer` 底色 + `onPrimaryContainer` 文字 + `AppIcons.play(active: true)` 实心播放图标；未选中为 `surfaceContainerHighest(α0.8)` + `onSurfaceVariant`；
- 当前项以 `playerController.cid` 比对，切换后随控制器重建自然刷新。

### 2. 换源：复用共享 player 的「新控制器替换旧控制器」路径

[detail_page.dart](file:///d:/Documents/GitHub/WinWin/lib/pages/video/detail_page.dart) 新增 `_switchPage(index)`：

- `_pageSwitching` 拦截快速连点，避免连续换源竞态；
- **先构造新 controller、再 dispose 旧 controller**：`WinWinPlayerController` 构造时递增共享 `mdk.Player` 引用计数，保证旧实例释放时计数不归零，不触发共享播放器的延迟销毁；
- 旧 controller 在 `dispose()` 内上报当前分P 观看进度（心跳 + 历史进度），随后释放；
- 新 controller 绑定 `aid`、重新挂 `completed` 监听，并置位 `userPlayRequested`（点选分P = 明确播放意图）；
- `_applyPlayInfo(ctrl, newCid, page.duration)` 按新 cid 拉取续播点/字幕/章节（与首次进入同路径），`load(gateForResume: true, autoplay: true)` 挂启动闸门加载，续播点返回后定位起播，避免 0 位闪帧；
- 「显示在线人数」开启时清空旧值并按新 cid 重拉。

### 3. 播放器面板：控制器替换时的监听迁移

[player_panel.dart](file:///d:/Documents/GitHub/WinWin/lib/pages/video/player_panel.dart) 新增 `didUpdateWidget`：controller 实例变化时，把 `userPlayRequested` 监听从旧实例迁移到新实例；若新实例已置位播放意图，同步解除「自动播放关闭」的封面兜底，避免封面残留。

弹幕层 `WinWinDanmaku` 以 `danmaku_${cid}` 为 Key，换源后自动重建为新 cid 的弹幕。

## 五、遗留与踩坑

1. **未做自动连播**：分P 播完不会自动切下一P；如需连播，可在 `completed` 监听内按 `pages` 顺序触发 `_switchPage`。
2. **进入页面仍默认 P1**：暂未根据历史记录恢复到上次观看的分P；单P 续播点已由 `playInfo.last_play_time`（按 cid）恢复。
3. **旧 controller 进度上报两次**：`_switchPage` 未显式调用 `reportCurrentProgress`，由 `dispose()` 统一上报一次，避免重复。
4. **切换期间禁用连点**：加载完成前其它分P 点击被忽略（不排队），保证同一时刻只有一次换源。
5. **未跑 `flutter test`**：本次改动为播放页 UI 与控制器生命周期接线，现有单测不覆盖该路径；以静态分析 + 双编译 + 实机验证为准。
