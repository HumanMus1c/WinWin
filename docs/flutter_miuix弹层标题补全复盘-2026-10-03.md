# flutter_miuix 弹层标题补全复盘 — 2026-10-03

> 五要素结构。触发：复测反馈"为无标题弹层补全标题（取触发控件的 tooltip/功能描述）"。

## 一、分析根因 / 现状取证

- 弹幕样式 / 表情面板（MiuixOverlayPanel 系）已有标题；
- 四个 `MiuixPopupMenu` 菜单（会话更多选项、播放器画质/音轨/倍速）**无标题行**，
  弹层内容靠条目自解释，易误判操作。

## 二、设计修复 / 实现

- `MiuixPopupMenu` 新增可选 **`title`**：面板顶部渲染标题行
  （`titleSmall` w600 + 内容色）+ 1.5 分隔线；列表置于标题之下并保持滚动
  （`Flexible` 约束）。
- 四处补全（均取既有 Tooltip 文案）：

  | 播放器音轨 | 音频设置 |
  | 播放器倍速 | 倍速 |
