# 图标全局反色 + 收藏面板关闭钮移除与搜索框 — 复盘（2026-10-21）

- 日期：2026-10-21
- 快照基准：`refs/snapshots/latest` = `3bd83d7`（改动前状态；回滚见第五节）
- 触发：CVO 实机反馈三点 —— ①「添加到收藏夹」面板左上角关闭 X 应移除；②该关闭钮与弹幕发送栏的「弹幕样式」钮**在浅色下是黑色、切到深色后仍是黑色、不随主题反色**；③收藏面板应加搜索框，按账户创建的收藏夹名直接过滤。指令：「直接做选项 B（根因·真正的『全局』）」。

## 一、现象

1. **两个控件不反色**：「添加到收藏夹」底部面板左上角的关闭 X、视频页弹幕发送栏右侧的「弹幕样式」钮（调色板图标），浅色主题下为黑色（看似正常）、**深色主题下仍是黑色**（与深色底同值，几乎不可辨）。
2. **面板形态待改**：收藏面板标题栏左侧多一个自绘关闭 X；且列表无搜索入口，收藏夹多时需手动翻找。

## 二、定因

### 1. 不反色（根因：图标色无随主题兜底）

`AppIcon` 取色规则为 `color ?? IconTheme.of(context).color`（`lib/theme/app_icons.dart:637-654`）。而 Flutter 的 `IconTheme.of` **永远返回具体值**：无 `IconTheme` 祖先时取 `IconThemeData.fallback()`，其 `color` 就是**纯黑 `0xFF000000`**（Flutter SDK `widgets/icon_theme.dart` `of()` + `icon_theme_data.dart` `IconThemeData.fallback()`）。因此只要「调用点不显式传色、且上层没有更近的 `IconTheme`」，图标就恒为黑 —— 亮色下"碰巧正常"，深色下不反色。

两个控件所在容器**都没有**随主题的 `IconTheme`：

- 收藏面板关闭钮：`lib/pages/fav/fav_page.dart`（`MiuixSmallTopAppBar` 的 `navigationIcon`）。`MiuixSmallTopAppBar` 把 `navigationIcon` **裸挂**、不注入图标色（`miuix_top_app_bar.dart`）；而面板路由 `AppSheetRoute` 只套 `AppTransparentHost`，它**只兜 `DefaultTextStyle`、不兜图标色**（`lib/core/shell/app_transparent_host.dart`；入口 `lib/core/shell/app_dialogs.dart`）。
- 弹幕样式钮：`lib/pages/video/send_danmaku_panel.dart`（`MiuixIconButton(child: AppIcon(AppIcons.palette(), size: 20))`），挂在 `CommentInputBar` 的裸 `Container` 上，同样无图标色来源。

对照**能反色**的控件 —— 均由某容器注入了随主题的 `IconTheme`：底栏 `miuix_navigation_bar.dart`（`IconThemeData(color: tint)`）、播放器控制条 `player_panel.dart`（`IconThemeData(color: effectiveColor)`）、项目自绘组件 `normal_item.dart` / `set_switch_item.dart` / `app_components.dart`。即：本项目**没有**"全局自动反色"总闸，是否反色取决于容器是否注入 `IconTheme`。

### 2. 面板关闭 X 与缺搜索

`_FavPanel` 标题栏用 `MiuixSmallTopAppBar` 且显式给了 `navigationIcon`（自绘关闭 X）；面板走底部弹层，其关闭本就有「取消」按钮 / 点击遮罩 / Esc 三条路径，自绘 X 属冗余（与「Esc 生效后移除自绘关闭 X」约定相悖）。列表直接铺 `_folders`，无过滤入口。

## 三、方案

1. **全局图标底色（选项 B，单一来源）**：在 `lib/core/shell/app_shell.dart` 的 `AppShell.build` 里，于 `AppThemeHost` 之下、`ScrollConfiguration` 之上注入 `IconTheme(data: IconThemeData(color: tokens.colors.onSurface))`。整树（含 Navigator、各路由、弹层）都是其后代 ⇒ 所有「未显式传色、且未被更近 `IconTheme` 覆盖」的 `AppIcon` 自动跟随明暗反色；更近的 `IconTheme`（导航栏 / 控制条 / 项目组件）仍按原样覆盖。
2. **移除关闭 X**：`_FavPanel` 的 `MiuixSmallTopAppBar` 去掉 `navigationIcon`，仅保留标题；因不再引用 `MiuixIconButton`，同步从其 `show` 列表删除该名。
3. **新增搜索框**：`_FavPanelState` 增 `TextEditingController _searchController` 与 `String _query`，标题栏与列表之间插 `AppCapsuleTextField`（`prefix: AppIcon(AppIcons.search())`，hint「搜索收藏夹」）；列表数据源改为 `_filteredFolders`（按 `title` 忽略大小写包含过滤），空结果显示「未找到收藏夹」。**关键约束**：`_submit()` 仍遍历**全量 `_folders`**，避免被搜索隐藏的收藏夹其勾选态被误删/漏加。

## 遗留与踩坑

- **`AppIcon` 不读 `MiuixContentColor`（既有缺陷，本轮未动）**：`MiuixButton` / `MiuixCard` / `MiuixSurface` / `MiuixBadge` 等向下传的是 `MiuixContentColor`，但 `AppIcon` 的取色优先级把 `IconTheme` 排在 `MiuixContentColor` 之前，且 `IconTheme.of` 兜底为黑 ⇒ 这些容器内的 `AppIcon` 此前同样落在兜底黑。本轮把它们由「兜底黑」改为「全局 `onSurface`」（深色下可见性净改善），但**仍未必等于容器自身 contentColor**（如主色实心按钮理想应为 `onPrimary`）。属更深一层的优先级问题，本轮按 CVO 选定范围未改 `AppIcon` 取色逻辑，留作后续按需显式传色。
- **选项 B 的爆炸半径**：会改变全库所有"落兜底黑"处的图标色。已审计：媒体叠加类（仅 6 处带 `shadows:`，`player_panel` / `bangumi_player_page`）全部显式传色或有更近 `IconTheme`（控制条）覆盖；`select_dialog.dart` 关闭钮、`danmaku_settings_panel.dart` 关闭钮等同类裸控件由全局兜底一并修正。
- **本仓未纳入 UI 用例**，未跑 `flutter test`（沙箱缺 `LOCALAPPDATA`，需注入环境变量方可跑）。

## 总结

两个不反色控件同因：`AppIcon` 无显式色时落到 Flutter 兜底黑，而其容器（`AppTransparentHost` / 裸 `Container`）都没注入随主题的 `IconTheme`；所谓"全局自动反色"其实不存在的总闸，本轮补上——在壳层根单点注入随主题的 `IconTheme`。同时把收藏面板的自绘关闭 X 移除（关闭收敛到 取消/遮罩/Esc 三条既有路径），并新增按名称过滤的搜索框（提交仍走全量集合，隐藏项勾选态不受影响）。`dart analyze` 0/0、Debug 与 Release 均 √ Built，可一键回到 `3bd83d7`。
