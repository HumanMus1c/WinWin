# 滚动条 reverse 方向映射修复复盘（2026-10-17）

> 范围：`AppScrollBar`（`lib/common/widgets/app_scroll_bar.dart`）+ 回归测试。
> 关联：本文件为「非 B7 项」审计轨迹，不计入 B7 批次；闸门（`lib` 内 `import 'package:material_ui` 文件数）保持 **5**。

## 一、现象

用户在**消息中心**（会话详情页）滚动会话消息时反馈：滚动态下滚动条滑块的运动方向「不符合常规」——
滑块**跟随内容方向**滑动（内容向上滚、滑块也向上），而常规应为滑块与内容滚动方向**相反**
（内容向上滚 ⇒ 滑块向下移动；内容下拉 ⇒ 滑块向上移动）。

- 影响面：所有 `reverse: true` 的滚动视图。当前项目内已知唯一用例 = 会话列表
  （`lib/pages/whisper/session/chat_detail_page.dart:247`）。
- 非 reverse 页面（首页 / 番剧 / 动态等）方向正常。

## 二、定因

- 会话列表为 `ListView(reverse: true)`：**最新消息在视觉底部**，`pixels == 0` 对应视觉**底部**，
  `pixels` 增大对应视口向视觉**上方**移动（看更旧消息）。
- 该滚动视图**未手动包裹** `AppScrollBar`，而由全局单一来源
  `AppScrollBehavior.buildScrollbar → AppScrollBar.attach` 自动接管。
- `AppScrollBar` 的滑块偏移 `_thumbOffset` 与拖拽/点击跳转 `_jumpToThumbOffset` 只做了
  `pixels / maxScrollExtent` 的**正向线性映射**，**未考虑 `ScrollPosition.axisDirection`**。
  对 reverse 列表（竖向 `reverse` ⇒ `AxisDirection.up`）：
  - `pixels == 0`（视觉底部）被错误映射为通道**上端**；
  - `pixels` 增大被映射为滑块**下移**（实应上移）。
  ⇒ 滑块方向与内容视觉方向**同向**，即用户所见的「跟随内容方向」。
- SDK 语义佐证：`ScrollView.getDirection` 对竖向取 `reverse ? AxisDirection.up : AxisDirection.down`；
  `ScrollPosition.axisDirection` 取自所属 `Scrollable`，可运行时读取。
- 边界澄清：本条与「位置空断言崩溃」（上一修复）**不同源**——那是「已挂载、未布局」的读值守卫问题；
  本条是**映射缺项**，`hasContentDimensions` 已就绪，只是比例换算方向错。

## 三、方案

- 在公开类 `AppScrollBar` 抽两个**纯静态函数**（`@visibleForTesting`），单点定义方向映射：
  - `thumbTravelFraction({pixels, maxScrollExtent, axisDirection})`：滚动像素 → 滑块沿通道的
    **视觉占比**（0 = 通道起点/上或左，1 = 末端/下或右）；reverse（`up`/`left`）取反。
  - `pixelsFractionForTravel({travelFraction, axisDirection})`：视觉占比 → 滚动像素比例
    （`thumbTravelFraction` 的**逆映射**）。
- `_thumbOffset` 改用前者、`_jumpToThumbOffset` 改用后者 ⇒ **绘制与拖拽/点击跳转方向一致**。
- 兼容面：非 reverse（`down`/`right`）行为与修复前**完全一致**（零回归）；横向 reverse 一并覆盖。
- 修复前已确认的隐患：抽纯函数前曾把映射内联在私有 `_AppScrollBarState`，测试无法引用；
  故将纯函数上移到公开类（属性/纯函数放公开类，状态/交互留 state）。

### 用户实机验证步骤

1. 打开**消息中心** → 进入任一**会话**；
2. 上下滚动消息列表，观察右侧滑块方向：
   - 内容向上滚（看更旧消息）→ 滑块应**向下**移动；
   - 内容下拉（看更新消息）→ 滑块应**向上**移动；
3. **拖动**滑块到通道**上端** → 应定位到**更旧**消息；拖到通道**下端** → 应定位到**最新**消息；
4. **点击**通道空白处，滑块中心跳至点击处并随之滚到对应位置。
