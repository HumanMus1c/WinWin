# 组件现代化改造复盘（2026-09-29）

**范围**：R1 字幕设置面板弃用修复与 M3 下拉、R2 全应用弹出菜单统一、R3 弹幕/字幕面板"恢复默认"。本文档按五要素记录（根因 / 方案 / 验证 / 总结 / 提交与回滚）。

## 一、分析根因（为什么改）

全库梳理结论（lib/ 274 个 dart 文件，`dart analyze` 实测）：

1. **R1 — 唯一漏网的弃用单选**：`subtitle_settings_panel.dart` 的 `RadioListTile.groupValue/onChanged` 自 Flutter 3.32 起弃用（官方要求由 `RadioGroup` 祖先托管），是全库最后一条组件级弃用 info；同项目 `select_dialog.dart` / `coin_dialog.dart` / `style_settings.dart` 三处早已采用 RadioGroup 范式，属一致性缺口。字重选择为全项目唯一 M2 风格 `DropdownButton`。
2. **R2 — M2 命令式弹出菜单**：`PopupMenuButton`×8（播放器×3、直播×3、登录×1、会员空间×1）+ `showMenu`×1（视频卡片光标位）。项目已有 M3 范式 `session_more_menu_button.dart`（MenuAnchor + MenuItemButton，注释明确"替代老旧的 PopupMenuButton"），其余 9 处未跟上；Flutter 3.47 的 MenuAnchor 具备视口自适应（越界翻侧 + 平移夹紧）与焦点链内层 Esc 消费（`app_escape_scope.dart` 注释已声明 MenuAnchor 菜单为内层消费者），无行为降级风险。
3. **R3 — 交互缺口**：对照本地参考库 PiliPlus（`lib/pages/video/widgets/header_mixin.dart` 的 `showSetDanmaku`、`header_control.dart` 的 `showSetSubtitle`，行级 `resetBtn` 带默认值 tooltip），WinWin 的弹幕/字幕面板全缺"恢复默认"，属已知交互差异。

## 二、设计修复计划与实现

### R1 字幕设置面板（`lib/pages/video/subtitle_settings_panel.dart`）
- `RadioListTile.groupValue/onChanged` → `RadioGroup<SubtitlePreference>` 祖先托管（对齐项目既有范式，保留 `activeColor: biliPink`，原 null 守卫语义不变）；
- 字重 `DropdownButton<int>` → `DropdownMenu<int>`（M3 最新下拉：`requestFocusOnTap: false` 点击即弹菜单、紧凑 `InputDecorationTheme`、9 个 w100–w900 条目）。

### R2 弹出菜单统一（player_panel / live_room_page / login_page / member_space_page）
- 8 处统一为 `MenuAnchor` + `MenuItemButton`，公共样式收敛为文件级常量/函数：
  - 播放器：`_darkMenuStyle()`（0xE61A1A1A + white12 描边 + radiusSm）与 `_darkMenuItemStyle`（hover 白 12%）；
  - 直播：`_menuStyle()`（0xE61E1E1E 同规格）与 `_menuItemStyle`；
- 保留：原 tooltip（Tooltip 包裹触发器）、选中态高亮（biliBlue / LightBlueAccent + check 图标、leadingIcon 占位保持行对齐）、音轨与响度均衡的 Divider 分组、登录冠码当前项 check 标记；
- 关键决策：`video_context_menu.dart` 的**光标位**上下文菜单保留 `showMenu`——其锚点语义是鼠标实时坐标（右键唤起），MenuAnchor 以 widget 为锚点无等价能力，且该 API 未被弃用；强行改造需引入不可见锚点 hack，得不偿失（如实记录，不作隐性降级）。

### R3 行级"恢复默认"（subtitle_settings_panel / danmaku_settings_panel）
- `_SliderRow` 新增可选 `onReset`，非空时行尾显示 `IconButton`（`AppIcons.refresh`，tooltip"恢复默认"，compact 28×28，outline 色）；
- 共 14 个滑块行接入；默认值口径与 `storage_pref.dart` 出厂默认完全一致：
  - 弹幕：不透明度 1.0、字号 1.4（窗口）/1.7（全屏）、显示区域 1.0、滚动时长 7.0s、静态时长 4.0s、描边 2.5、字重 6（w600）、行高 1.6、云屏蔽 0；
  - 字幕：字号 1.0（窗口）/1.5（全屏）、背景不透明度 0.67、描边 2.0、左右边距 24、底部边距 24；
- 点击即 setState + 落盘；弹幕侧同步 `danmakuEngine.updateOption` 与 `danmakuOpacity` notifier（复用原 onChangeEnd 行为）。

- 改动面：6 个代码文件（player_panel / live_room_page / login_page / member_space_page / subtitle_settings_panel / danmaku_settings_panel），合计 +601/-418 行；另有本文档。
