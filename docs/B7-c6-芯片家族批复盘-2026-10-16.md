## 2. 定因

Chip 家族是 `material_ui` 的**复合控件**：几何由私有 `RenderBox`（`_RenderChip`）
计算，配色由各形态的 `_XxxDefaultsM3`（`ChipThemeData` 子类）供给，勾选由自绘
`_paintCheck` 完成，按压依赖 `InkWell` 水波 + `Material` 祖先。项目**未覆写**
`chipTheme`，故最终观感 = M3 默认值。

## 3. 复刻依据（`material_ui` 1.5.0，全部只读）

- `lib/src/chip.dart`：`RawChip.build`（L1365-1554）、`_RenderChip._computeSizes`
  （L1983-2025）、`performLayout`（L2028+）、`_paintCheck`（L2160-2204）、
  `_buildDeleteIcon`（L1304-1362）、点击靶约束（L1525-1540）。
  常量：`_kChipHeight = 32.0`、`_kCheckmarkStrokeWidth = 2.0`、`_kCheckmarkAlpha = 0xde`、
  `_kSelectDuration = 195ms`、`_kDrawerDuration = 150ms`、`_kCheckmarkReverseDuration = 50ms`。
- `lib/src/generated/chip_defaults_m3.g.dart`、`filter_chip_defaults_m3.g.dart`、
  `action_chip_defaults_m3.g.dart`、`input_chip_defaults_m3.g.dart`、
  `choice_chip.dart` 内联的 `_ChoiceChipDefaultsM3`：各形态的
  `labelStyle / color / side / checkmarkColor / deleteIconColor / iconTheme /
  padding / labelPadding / shape(radius 8)`。
- Flutter SDK `material/theme_data.dart`：`VisualDensity.baseSizeAdjustment
  = Offset(horizontal, vertical) * 4`；`ThemeData.visualDensity` 未覆写 ⇒
  `defaultDensityForPlatform(platform)` ⇒ **桌面端 = `VisualDensity.compact`(-2,-2)**
  ⇒ `baseSizeAdjustment = (-8,-8)`。

### 关键推导（几何等价式）

`_RenderChip._computeSizes`：

```
content      = max(_kChipHeight - padding.vertical + labelPadding.vertical,
                   labelHeight + labelPadding.vertical)
densityAdj   = Offset(0, visualDensity.baseSizeAdjustment.dy / 2)     // compact ⇒ -4
总高          = content + densityAdj.dy + padding.vertical
标签纵向位置   = padding.top + (content - labelHeight + densityAdj.dy) / 2
```

代入 compact（`densityAdj.dy = -4`）、`padding = all(8)`、`labelHeight = 20.02`
（labelLarge 14 × 1.43）：

```
总高        = 20.02 - 4 + 16 = 32.02
标签 top    = 8 + (20.02 - 20.02 - 4)/2 = 6
```

即**等价于**「上下内边距各减 2、内容按自然高度」：`8-2 = 6`，总高 `20.02 + 12 = 32.02`。
故本替身用**内边距等价实现**（`top/bottom += densityAdj/2`），无需自研 `RenderBox`
即可逐像素一致。

## 4. 方案

新增 `lib/common/widgets/app_chip.dart`（零 material）：

| 替身 | 替代 | 形态差异（对齐 `_XxxDefaultsM3`） |
|---|---|---|
| `AppChoiceChip` | `ChoiceChip` | 选中底 `secondaryContainer` / 未选透明 + 1px `outlineVariant` 描边；label 选中 `onSecondaryContainer`、未选 `onSurfaceVariant`；勾选色同上 |
| `AppFilterChip` | `FilterChip` | 同 Choice（M3 下二者默认取值一致） |
| `AppActionChip` | `ActionChip` | 恒透明底 + 1px `outlineVariant` 描边；无选中态；label 恒 `onSurface` |
| `AppInputChip` | `InputChip` | 未选透明 + 描边；选中 `secondaryContainer`；可选 `deleteIcon`（槽位 `content²`） |

共用 `_AppChipCore`（`StatefulWidget` + `TickerProviderStateMixin`）：

- **两控制器**：`_select`（195ms，驱动背景色淡入淡出 `fastOutSlowIn`）与
  `_drawer`（进场 150ms / 退场 50ms，驱动勾选槽位宽度）。
- **勾选**：槽位 `宽 = content × 抽屉值`、`高 = content`；`OverflowBox` 让子件按
  `content²` 布局后由槽位宽度裁切（对齐 Material 的「子件按 content 布局、上报尺寸按
  动画值」）；绘制复刻 `_paintCheck`（尺寸 `0.75×content`、偏移 `0.125×content`、
  线宽 `2.0×content/24`、两段式描线 `t<0.5` 画 start→mid）；退场保持 `t=1` 整体淡出。
- **文案**：内联 `Typography.englishLike2021` 的 `labelLarge`（14 / w500 / ls 0.1 /
  h 1.43）—— 因项目 `AppTextStyles` 只携带墨色（B7-a 起为内联常量），字号/字重/行高
  仍由 Material `textTheme` 提供；本替身按「最终态」内联该基样式再叠加状态色
  （取自 `AppPalette`，与过渡期 `ColorScheme` 同源 ⇒ 零漂移）。
- **`labelPadding`**：`horizontal 8 → 4`（按 `scaler.scale(fontSize)/14` 线性收敛）。
- **点击靶**：`minWidth/minHeight = 48 + densityAdjustment` ⇒ compact 下 40×40。
- **密度**：新增 `AppChipDensity{standard, compact}`，默认 `compact`（= 本应用桌面端
  `ThemeData.visualDensity` 实际取值）；调用点原有的 `visualDensity: VisualDensity.compact`
  5 行随删（与默认等价，零行为变化）。

**唯一非机械点**：按压反馈由 Material `InkWell` 水波 → 全站统一 `MiuixPressable`
（`sink`，`sinkAmount: 0.98`），与 b7-c6-1b 的 `AppSimpleDialogOption` 及 `lib/` 内既有
73 处同规格 —— 属「全站 Miuix 化」既定目标态，非本批新引入的差异。

## 7. 遗留与踩坑

1. **`dart format` 全程未跑**（项目硬约束）。
2. 探针未触发脱库：7 个迁移文件均仍有其它 Material 符号，闸门持平 —— 预期内，
   真正脱库在 c6-3（`Scaffold`/`AppBar`）/ c6-4（`Scrollbar`/`Slider`/`TextField`）/
   c6-5（`Material(`）完成后一并发生。

   `onSecondaryContainer` / `surfaceContainerLow` / `surfaceContainerHigh`，取 M3 基线，
   与 `AppPalette` 常量一致）⇒ 用 `AppPalette` 供色零漂移。
4. `labelPadding` 的 `widget.labelStyle != null` 分支暂固定为 `horizontal 8`（未按
   覆盖后字号重算）—— 覆盖点仅 `video_context_menu`（`fontSize: 12`，其
   `textScaleRatio < 1` ⇒ 也为 8），实数一致；后续如需严格，改为按合并后字号重算。

## 8. 实机复验指导（建议 5 项）

1. 番剧详情「选集」分页 chip（`ChoiceChip`）与「季度」chip（`FilterChip`）选中态：
   底色转粉、勾选 150ms 描线进场、取消时 50ms 收缩淡出。
2. 用户空间：动态筛选 / 追番追剧切换 / 视频排序 chip（compact 密度，高 32）；配色主题
   切换 chip（`fontSize: 12`）。
3. 搜索页历史词 chip：点击搜索、点右侧 × 删除（删除靶 40×40 内可点）。
4. 弹幕设置「屏蔽类型」chip：选中底色为 B 站粉 25% + 勾选 B 站粉（自定义
   `selectedColor`/`checkmarkColor` 覆盖生效）。
5. 视频卡片「不感兴趣」原因 chip（`ActionChip`，`padding: horizontal 4`、
   `fontSize: 12`）：点击后弹窗关闭并上报；按压反馈为 2% 内缩（非水波）。
