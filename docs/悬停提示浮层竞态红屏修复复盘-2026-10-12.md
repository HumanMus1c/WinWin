## 1. 现象描述

2026-10-12 20:47–20:48 的 debug 版视频页会话（`.winwin_logs.json` L92–L133）
出现三类症状：

1. **异常雨**：悬停控制栏期间连续记录 70 条 `_OverlayEntryWidget` 相关异常
   （"setState() or markNeedsBuild() called during build"，均打在 DEFUNCT
   元素上）+ 10 条 "Looking up a deactivated widget's ancestor is unsafe"
   （20:47:21–20:48:33，共 73 秒）；
2. **99391px 溢出**：20:47:21 一条 `RenderFlex overflowed by 99391 pixels on
   the right` —— 实机表现为控制栏右端黄黑溢出条纹 + 红字（用户截图 2）；
   同一时刻用户观察到"字幕按钮重复"的异常渲染；
3. **红屏断言**：20:48:34 返回键 pop 视频页时，`InheritedElement.debugDeactivated`
   的 `assert(_dependents.isEmpty)` 失败（framework.dart:6281）→ 全窗红屏
   （用户截图 1）。

## 2. 根因

**根因链**：b7-b1 迁移后 `AppTooltip` 直接封装 flutter_miuix 1.3.0
`MiuixTooltipBox`，其浮层机制在"悬停 × 宿主高频重建/结构变化"下存在三处
竞态；视频页控制栏（每个按钮含 AppTooltip × 3 秒自动显隐 × 鼠标扫动悬停）
为满负载触发场：

1. **`didUpdateWidget` 向 DEFUNCT 条目 markNeedsBuild**（miuix_tooltip.dart:213）：
   宿主每次重建 → `_entry != null` 即无条件 `markNeedsBuild()`，不校验条目
   所属元素活性 → "setState during build"（栈：L93/L95/L105…，正在构建者均为
   AppTooltip）；
2. **`_syncVisibility` 的 mounted 守卫挡不住"已停用未卸载"元素**（:220→:230）：
   迟到鼠标 hover 事件在已 deactivate 的 element 闭包上触发 `show()` →
   `Overlay.maybeOf(已停用 context)` → "deactivated ancestor"（栈：L120/L132…）。
   `State.mounted` 对 inactive 元素仍为 true，`context.mounted` 才是准确守卫；
3. **异常帧级联**：每次异常打断当帧构建 → 被中断子树以 ErrorWidget 顶替
   （debug 下 `RenderErrorBox` 最小宽 100000px）→ 布局阶段报告
   `overflowed by 99391 ≈ 100000 − 609`（609px = 控制栏可用宽）——即 L94 与
   截图条纹来源；异常同时破坏 tooltip 状态机（`_active`/timer/entry 时序被
   中断），累积至路由 pop 的整树 deactivate 时残留依赖者未解绑 →
   `_dependents.isEmpty` 断言红屏。

**上游核验**：flutter_miuix 最新版即 1.3.0（pub.dev，13 天前发布）；
GitHub main 分支 `miuix_tooltip.dart` 与 1.3.0 逐行一致——上游未修复，
**不能依赖升级**，修复下沉至本项目垫层。

**时间线**：20:47:13 进入视频页 → 20:47:19 首帧 → 20:47:21 悬停异常雨起 →
20:48:34 返回键 → 红屏。

## 3. 修复方案

`lib/ui/components/app_tooltip.dart` 单点重写（API/类名不变，149 处调用零改动）：

| 设计点 | 口径 |
|---|---|
| 浮层生命周期 | `OverlayPortal` 由框架托管：宿主元素停用/卸载时浮层自动随动清理（从机制上消除悬挂条目类缺陷） |
| 活跃性守卫 | `_canTouch = mounted && context.mounted` 覆盖 show/dismiss/浮层构建全部入口 |
| 状态机 | 全局单活动槽（新泡接管先收旧泡）+ onExit 微任务复核 + 泡上悬停保持 + 1.5s 自动隐藏 |
| 定位 | 移植 flutter_miuix `_MiuixTooltipPositionDelegate` 语义：below 优先 → 空间不足翻 above → 两轴钳制视窗内（Apache-2.0，注明出处） |
| 视觉/动效 | 复用 `MiuixPlainTooltip` + `MiuixTheme` 捕获重包 + 180ms fade/scale(0.9→1, easeOutBack)；即时显示口径不变 |
| 兼容 | 类名/`message` 字段保留（3 个存量测试的 `byType(AppTooltip)` 谓词兼容）；长按显示保留 |

**同类站点统一排查**（lib 内直用 miuix tooltip 运行时的物化残留）：

| 站点 | 判定 |
|---|---|
| `lib/ui/components/app_tooltip.dart` | 唯一直接使用点 → 本次重写 |
| `glass_contrast_widgets.dart:241` 及全部约 149 处调用点 | 均经 AppTooltip，随修复收敛（零改动） |
| `MiuixTooltipBox` / `MiuixRichTooltipBox` / `MiuixTooltipState` 残留 | **0/0/0**（grep 全 lib 唯一命中为修复说明注释） |
| `MiuixPopupMenu`（自研壳） | dispose 已强制移除 entry，无同类缺陷，不修 |

## 6. 遗留与踩坑

- **"字幕按钮重复"**：判定为异常帧的重复渲染残影（与 L94 同秒同区），推定随
  本修复消失——已列入实机复验项；若实机仍复现，需补完整窗口截图另行下钻。
- **上游缺陷在库**：miuix 的 tooltip 三处竞态未修复（1.3.0 = main）；本修复为
  项目侧垫层。若上游后续修复，可评估回迁（保留此决策记录）。
- 环境踩坑：构建期 `clipshare` 进程曾占用 2.1 万 TCP 连接（本机动态端口共
  13977），导致 `flutter test` 无法监听本机端口（errno 10055）；非代码问题，
  连接回收后复跑即绿。
- 测试踩坑：单活动槽用例首版用纵向相邻布局，A 泡（below）恰好罩住 B 的悬停
  点导致 enter 被泡截获——改横向并排后通过（真实控制栏为横排，几何等价）。
