# 极验弹窗"无边框全屏"改造复盘（2026-10-02）

**范围**：将极验验证弹窗从「Dialog + 360×480 卡片」改为「无边框全屏覆盖层」（对齐 PiliPlus / BiliPai 手机端近全屏体验的桌面等价物）。
**立项依据**：用户指令 + Plans 面板批准的 `~/.commandcode/plans/极验弹窗无边框全屏改造计划.md`。

## 一、分析根因（为什么改、改成什么）

### 1.1 背景

诊断轮实机验证后，用户对承载形态提出疑问：为何需要矩形卡片承载（记忆中手机端没有）。经四处实现核对（PiliPlus 手机端 = `showDialog` + **全屏 WebView**；PiliPlus Linux = `AlertDialog` 300×400；BiliPai = 原生 `Dialog` 90%+ 近全屏；WinWin = 360×480 卡片——2026-08-09 引入的桌面适配），用户选择对齐手机端"无边框全屏"观感。

### 1.2 关键取证（可行性）

- `RawDialogRoute.buildPage`（SDK widgets/routes.dart:2593）对 builder 结果**不做尺寸限制**；
- `DialogRoute` 的 `SafeArea`（material_ui dialog.dart:1896）在桌面窗口无内边距、无影响；
- 即：`showDialog` 路由里装什么就显示什么 → 全屏层可行，且**模态/返回值/Esc 契约全部保持**（无需改调用点）。

### 1.3 被取代的旧形态

卡片形态的圆角裁剪修复（`b653bd2`，`clipBehavior: Clip.antiAlias`）随 `Dialog` 一同移除——**无卡片即无圆角问题，自然消解**；该提交保留于 git 历史，仅当未来回退卡片形态才需要恢复。

## 二、设计修复计划（关键决策）

| 决策 | 选择 | 理由 |
|---|---|---|
| 承载结构 | `SizedBox.expand` + `Material(color: Colors.white)` + `Stack(fit: StackFit.expand)` | 铺满整个应用窗口；白底与极验页面本体一致，加载 → 内容态无跳色 |
| 背景色 | **白色**（不随主题） | 极验页面本体恒为浅色（与手机端一致），主题色会导致"跳色" |
| 关闭按钮 | 保留**左上角浮层**（`Positioned(8,8)`） | 与 PiliPlus 手机端完全一致 |
| 尺寸 | **铺满窗口、不限宽** | 对齐手机端全屏；极验 JS 自行布局（如观感不佳可二次加限宽） |
| 错误视图 | 显式深色文字（`Colors.black87`）+ 整体居中 | 白底在深色主题下保证可读；全屏后避免左上角偏移 |
| 契约 | `showDialog` / `await` 返回值 / Esc layer1 / `barrierDismissible:false` **全部不变** | 类名与 `show()` 签名不变，调用点与诊断按钮零改动 |

移除项：`insetPadding`、`clipBehavior`（及圆角注释）、`SizedBox(360×480)` 固定尺寸。
