# B7-c3 补丁复盘：实机三问题修复（胶囊占位 / 直播光标 / 导航线条图标） — 2026-10-14

> 承接 b7-c3（`9ca845e`）实机抽查反馈（3 项），逐一定因修复。
> 回滚基准：`9ca845e`（b7-c3 提交；`git checkout .` 即撤销本补丁全部改动）。

## 1. 现象描述（用户反馈三则）

1. **搜索页输入框**：预留文本（占位）字体太大；输入时占位未即时隐藏、有滞后感。
2. **直播互动输入框**：点击聚焦无闪烁光标；与视频页评论输入框样式不统一——聚焦无边框变化。
3. **底栏导航图标**：未选中态仍呈填充（实心）而非线条（截图：历史=实心表盘、
   消息=实心气泡；动态=线条正常、我的=回退字形正常）。

## 2. 根因与设计（定因）

- **占位字号/滞后**：`AppCapsuleTextField` 此前将 hint 交给上游 `MiuixTextField`
  的 label 占位体系——其 label 字号常量为 **17px**（labelFontSizeNormal），
  且隐藏/浮动经 `_labelController` **动画过渡**（动画期间占位仍可见=滞后感）。
  上游无 hint 样式与时长参数 → **改为自绘占位层**（彻底绕开 label 体系）。
- **无光标 + 无边框**（同源）：上游源码 `final cursorColor = widget.cursorColor
  ?? colors.borderColor;`——b7-c3 给直播条/发弹幕面板的"透明档"传了
  `borderColor: 透明` → **光标色连带透明**（不可见）；且聚焦边框亦为透明
  （无边框变化）。→ 两处**恢复默认 borderColor**（光标=primary 回归、聚焦
  边框回归，与评论条行为统一）；`fillColor` 透明（外层容器样式）保持不变。
- **导航填充/线条**：`house/clock/chat_bubble_2` 字形全部映射到 Miuix extended
  的实心矢量（`home/recent/messages`）→ 未选中也渲染填充。**素材勘察**：
  extended/os4 两集均无这三组的线条版——渲染实测墨迹占比：实心 27-32%，
  线条参照（os4 notifications=用户确认的线条）仅 10.7%；`bell_fill` 亦无
  实心对应（os4 仅线条 notifications）。→ **未选中（线条）字形移出映射**，
  回退 Cupertino 线条字形；填充字形保留实心矢量映射。

## 3. 修复方案（改动面）

- **AppCapsuleTextField**：占位改自绘——`ValueListenableBuilder` 监听控制器
  （文本非空**即时隐藏**、无动画）；默认 13px `onSurfaceVariant`；新增
  `hintStyle` 参数（发弹幕面板保留 15px 口径）；prefix 以透明副本占位宽度
  实现与上游文本区精确对齐；`label` 传空串（不触发上游 label 体系）。
- **直播互动条 / 发弹幕面板（透明档）**：移除 `borderColor: 透明` →
  光标（primary）与聚焦边框回归；hintStyle 保留各自原口径（13/15px）。
- **app_icons.dart 映射表**：`CupertinoIcons.house / clock / chat_bubble_2 /
  bell_fill` 四条移出（带注释说明）；`house_fill / clock_fill /
  chat_bubble_2_fill / bell` 保留。
- **字形轮廓表补录**：`tools/glyph_outline_export.py` 的 CUPERTINO_WANTED
  增补 4 字形并重跑 → `test/tools/cupertino_glyph_paths.g.dart` +4（25→29）；
  `icon-sheet` 对照产物同步更新（docs/icon-sheets 21 文件）。
- **测试**：新增 `test/theme/app_icons_nav_fallback_test.dart`（未选中回退
  null / 选中保持映射的回归）；`miuix_adoption_test` 的 bell_fill 断言更新
  （isNotNull → isNull + bell 保持非空）。

## 5. 本轮修复总结

三条反馈全部闭环：占位脱离上游 label 体系（字号 13 恢复 + 即时隐藏）；
透明档不再牺牲光标与聚焦边框（直播条与评论条行为统一）；导航线条/填充
按字号回退分层（素材集缺线条版的字形统一走 Cupertino 回退，未选中=线条、
选中=实心）。字形轮廓与对照产物同步更新，新增回归测试锁定分层语义。

## 6. 遗留与踩坑

- **踩坑（素材勘察方法）**：Miuix 图标"线条/实心"无法从数据或命名分辨
  （集内命名无统一 Line/Fill 后缀规律）——**以渲染实测墨迹占比判定**
  （48px、白底、darkRatio；线条 ≈10-12%、实心 ≈27-32% 区分度高）；
  探针测试渲染 PNG 后像素分析（临时测试已删）。
- **遗留**：
  - `lock/lock_fill` 两态同映射（Miuix 'lock' 单矢量）——播放器锁/解锁
    图标状态区分待专项（登记，用户未报）；
  - `duration()`（clock 字形）随本次回退变线条表盘——语义合理（时长图标）；
  - 占位自绘与输入文本的垂直中心对齐（行高差异）——实机确认 ±1px 量级。
- **说明**：`chat_bubble`（弹幕开关）已由 art 层手绘线条（`_bubbleOutline`）
  接管，映射表 os4 条目被截胡（无害保留）——未做改动。
