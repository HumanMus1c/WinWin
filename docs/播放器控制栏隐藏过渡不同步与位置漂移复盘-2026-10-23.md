# 播放器控制栏隐藏过渡「不同步隐藏 + 位置漂移」复盘-2026-10-23

## 一、现象

播放器控制栏自动隐藏 / 呼出的 200ms 过渡动画中：

- **不同步隐藏**：时间文本与进度条比控制栏其余控件「抢跑」——在整体淡出刚开始的瞬间即消失，其余控件仍在渐变；
- **位置漂移**：出现与隐藏两个方向都会触发一次可见的布局位移（进度条、时间文本，以及时间文本右侧相邻的弹幕开关）。

## 二、定因

控制栏整体在 `lib/pages/video/player_panel.dart` 由一根 `AnimatedOpacity`（200ms，`_controlsVisible` 驱动）统一淡入淡出。但**在该整体淡出子树内部，时间文本与进度条各自又内置了一个非动画的「瞬切占位」短路**：

- `_buildTimeText()`：`if (!_controlsVisible.value) return const SizedBox(width: 80, height: 16);`
- `_buildProgressSlider()`：`if (!_controlsVisible.value && !_draggingProgress) return const SizedBox(height: 18);`

二者由提交 **809ee56（perf(player): optimize hardware decoding, codec priority, and canvas danmaku rendering）** 引入，本意是「隐藏时跳过重控件构建」的性能优化。其缺陷有两个叠加面：

1. **时序不同步**：`if` 在同一帧把整棵子树瞬时替换为占位，**不走任何动画**；而外层 `AnimatedOpacity` 需要 200ms 才 fade 到 0。于是这两个控件在淡出首帧即「消失」，与其余仍渐变的控件不同步。
2. **尺寸不匹配 → reflow 漂移**：
   - 进度条：真实高度 `RenderProgressBar._height() = max(2*max(thumbRadius=6, thumbGlowRadius=16), barHeight=3.5) = 32px`（见 `lib/common/widgets/progress_bar/audio_video_progress_bar.dart:475`），占位仅 `18px` → 切换瞬间行高瞬降 14px。控制栏是 `Positioned(bottom: 0)` 底边锚定，行高变化会重排其内部纵向位置。
   - 时间文本：真实宽度随「当前时间位数 / 是否带章节胶囊」变化（可远超 80px），占位写死 `80×16` → 同一 `Row` 内其右侧弹幕开关随之左右跳动。

`AnimatedOpacity`（RenderOpacity）本身不改布局，故**漂移的唯一来源即上述两处瞬切占位**；其余控件随整体一起渐隐，行为正常。

## 三、方案（方案 B）

把「隐藏时跳过构建」的目的**整体化**，同时让过渡期间真实控件在位：

1. 新增折叠标记 `bool _controlsCollapsed`；
2. 给整体 `AnimatedOpacity` 挂 `onEnd: _onControlsFadeEnd` —— **仅在淡出动画真正结束**（opacity=0、不可见）后才把折叠标记置真；
3. `_controlsVisible` 增加监听 `_onControlsVisibleChanged` —— 一旦控制栏重新显示且尚处折叠态，**立即复位折叠标记**（展开动作发生在淡入首帧 opacity≈0，不可见）；
4. 两处内部占位守卫的判据由 `!_controlsVisible.value` 改为 `_controlsCollapsed`。

效果：过渡期间真实时间文本/进度条在位 → 与整体同步淡出、**零布局重排**；完全隐藏后仍折叠重控件跳过构建（保留原性能意图，且整条控制栏始终挂载，不破坏音量弹层依赖的音量按钮锚点）。

## 五、遗留与踩坑

- 修复须覆盖「出现」方向：关键是**淡出完成才折叠、一显示即展开**，否则反向仍会漂移。
- 保持整条控制栏常挂载（不整体 `SizedBox.shrink()`），避免移除音量按钮锚点导致音量弹层收起动画期间锚点丢失。
- 本机构建坑：沙箱 shell 缺 `ProgramFiles(x86)` 会导致 `flutter build windows` 中断（与既有记忆里 `flutter test` 同源），需补齐环境变量后重跑。

## 六、总结

「部分控件不同步隐藏 + 位置漂移」是同一根因的两个表征：`809ee56` 在整体淡出子树里给时间文本与进度条各加了一个**非动画、且尺寸不符**的瞬时占位，既破坏了统一淡出时序，又引入了额外 reflow。修法是把「隐藏时省构建」从内部瞬切改为整体「淡出完成后再折叠」，使过渡同步且布局稳定。
