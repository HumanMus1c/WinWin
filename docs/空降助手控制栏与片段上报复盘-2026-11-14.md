# 空降助手控制栏与片段上报复盘（2026-11-14）

## 一、现象与目标

上一轮插件系统已把空降助手作为内置插件，但播放页只能被动自动跳过：

- 控制栏没有空降助手入口，无法在播放中开启/关闭；
- 无法把当前视频的广告片段上报到社区；
- 无法查看当前视频已加载的社区片段、跳过或投票。

本轮参考 PiliPlus 与 BiliPai 的播放页设计补齐上述能力。

## 二、二者设计核对

### PiliPlus

- 顶部控制栏：盾牌「提交片段」按钮 + 广告图标「片段信息」按钮；
- `PostPanel` 底部面板：可增删片段、编辑起止时间、选择类别与动作；
- 进度条绘制片段标记；
- 设置页独立 `SponsorBlockPage`：最短片段时长、类别开关、用户 ID、服务器、贡献统计。

### BiliPai

- 顶部控制栏「提交片段」按钮；插件未开启时点击弹出「开启空降助手」确认；
- 上报流程：标记开始 → 标记结束 → 审核对话框（类别/动作/确认提交）；
- 「片段信息」面板：片段列表、跳过、投票、更改类别；
- 设置页「社区与隐私」：社区服务器、上传跳过贡献（默认关）、
  提交片段（默认关，逐次确认）、匿名用户 ID。

### 本轮取舍

桌面端控制栏空间有限，不照搬两个独立图标，而是合并为**单个盾牌按钮 + 面板**：

- 图标双态：开启=实心盾牌 + 主题蓝；关闭=空心盾牌；
- 点击打开面板：开关、上报、片段列表三合一；
- 不新增进度条标记（后续可补）。

## 三、实现内容

### 3.1 控制栏入口

`lib/pages/video/player_panel.dart`：

- 右侧功能区新增 `_buildSponsorBlockButton()`，位于字幕 chip 与弹幕设置之间；
- 通过 `PluginManager.plugins` 监听插件状态，图标/提示/颜色随开关变化；
- 点击经 `_openSuspending` 打开面板，面板打开期间控制条不自动隐藏。

### 3.2 空降助手面板

`lib/pages/video/sponsor_block_panel.dart`：

- 顶部「空降助手」开关：直接启停插件并持久化；
- 「上报片段」：
  - 开始/结束时间输入（`mm:ss` / `hh:mm:ss`）；
  - 「取当前进度」按钮，可在视频继续播放时分别标记起止；
  - 片段类别 chips（sponsor/selfpromo/interaction/intro/outro/preview/filler/music_offtopic）；
  - 动作 chips（skip/mute/full，按类别限制）；
  - 「允许上报社区片段」开关（默认关闭）；
  - 提交按钮 + 提交中/成功/失败状态；
- 「社区片段」：
  - 加载/刷新当前视频片段；
  - 每条显示类别、时间范围、UUID 前缀；
  - 「跳过」定位到片段结尾；
  - 「有用 / 不准确」投票。

### 3.3 社区 API

`lib/core/player/sponsorblock_usecase.dart`：

- `submitSegment`：`POST /api/skipSegments`，请求体对齐 BiliPai
  （`videoID/cid/userID/videoDuration/userAgent/segments`）；
- `voteSegment`：`POST /api/voteOnSponsorTime`（`UUID/userID/type`）；
- 请求头：`origin: WinWin`、`x-ext-version` 取真实包版本、`User-Agent: WinWin/<version>`；
- 状态码映射：400 参数错误 / 403 自动审核拒绝 / 404 未找到 / 409 重复提交 /
  429 提交太快 / 500 服务器错误；
- 成功后控制器自动刷新片段列表。

### 3.4 插件配置

`lib/plugin/builtin/sponsor_block/sponsor_block_plugin.dart`：

- 新增 `communityContributionEnabled`（默认 false）；
- 首次使用自动生成 32 位匿名用户 ID 并持久化；
- 设置页新增「社区上报」区：允许上报、社区用户 ID、社区服务器。

### 3.5 控制器接口

`lib/pages/video/player_controller.dart`：

- `sponsorBlockSegments`：当前已加载片段；
- `refreshSponsorBlockSegments()`：重新拉取；
- `submitSponsorSegment()`：校验插件/上报开关/bvid/时间范围后提交，成功后刷新；
- `voteSponsorSegment()`：投票并返回错误文案。

## 五、实机验证步骤

1. 打开任意视频，控制栏右侧应出现盾牌按钮；
2. 点击盾牌，面板顶部「空降助手」开关默认开启（继承旧配置）；
3. 关闭开关：盾牌变为空心、自动跳过停止；再开启恢复；
4. 播放到广告开始处点击「取当前进度」填开始时间，广告结束处再点一次填结束时间；
5. 选择类别（如“赞助广告”）与动作（跳过），打开「允许上报社区片段」；
6. 点击「确认提交片段」，预期提示「已提交，等待社区审核」；
7. 在「社区片段」区点击「刷新」，确认列表出现新片段（审核通过后）；
8. 对已有片段点击「跳过」应跳转至片段结尾；点击「有用/不准确」应提示投票成功；
9. 回看 `D:\Documents\logs\runtime.log`，确认无 `SponsorBlock` / `PluginManager` 异常。

## 六、已知限制

- 片段拉取仍使用既有 `?bvid=` 兼容查询；上报使用 `videoID/cid`，两者均指向 bsbsb.top；
- `SponsorBlockSegment` 目前只解析 `[start,end,category,uuid]`，未解析 `actionType`/`votes`；
  因此列表中的静音/整段标记片段在手动“跳过”时按跳转处理；
- 未实现更改片段类别、撤销投票（type=20）与进度条标记；
- PGC 视频若无 bvid，上报按钮会提示“当前视频不支持片段上报”；
- 社区 API 需网络可达；服务端审核策略可能导致 403/409/429。
