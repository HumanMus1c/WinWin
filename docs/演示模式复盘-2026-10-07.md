## 1. 需求与定因

**需求**：为 README 增加"干净"的程序运行截图。在「设置-其它设置」新增「演示模式」开关：

1. 开启后，**所有从云端拉取的第三方内容**与**已登录账号数据**，在不被破坏的前提下，以占位符 / 未加载成功时的骨架替代显示；
2. 支持**热切换**（无需重启）；
3. 已加载内容**安全缓存**，关闭演示模式后**无损恢复**。

**评审修订（v2）**：

- 账号区仅**头像/昵称**替换为程序默认图标与程序名「WinWin」；经验/硬币/关注/粉丝/粉丝牌/等级牌/VIP 类型等**照常展示**；
- 上述元素在演示模式下**可即时编辑**：纯数字元素随意改值；标签/胶囊/等级牌/粉丝牌/VIP 类型点击下拉、在该控件支持的全部类型中任选切换；
- 自定义状态**持久化到本地缓存**，下次开启演示模式直接按保存值渲染（无需重新初始化）。

**方案定因**：否决"网络层拦截（Dio 伪造/挂起响应）"路线——需逐接口对齐伪造 schema、恢复需重放请求，且极易波及登录/签名/WBI 等关键链路；采用**显示层隔离**：真实数据全程不销毁，只切换"显示什么"。

## 2. 方案与关键决策

**四层显示隔离**：

| 层 | 机制 | 说明 |
|---|---|---|
| 开关层 | `Pref.demoModeNotifier`（ValueNotifier + Hive 持久化） | 热切换；构造期不读 Hive，bootstrap 后 `refreshDemoMode()` 恢复 |
| 页面内容层 | `DemoMask` / 各页条件分支 | 演示开启 → 整块替换为该页现有骨架（无骨架页面用通用 `DemoListSkeleton` / 新绘小骨架）；含错误态一律骨架 |
| 图片层 | `NetworkImgLayer` 演示分支 | 直接输出灰块/灰圆占位，不构建图片、不发起加载 |
| 账号层 | `AccountService.displayUserInfo` + `DemoOverrides` + `DemoEditableNumber/Choice` | 仅替换头像/昵称；其余真实值展示；编辑值写 `localCache.demoOverrides` |

**关键性质**：

- **不破坏**：不动网络层、登录链路（cookie/access_key/签名/WBI）、`Pref.userInfoCache`、播放器播放状态；overrides 绝不写回真实数据路径。
- **无损恢复**：关闭开关 → ValueNotifier 通知 → 各遮罩/组件立即重建显示真实内容，零重新请求；已加载数据（Controller/State/图片缓存）全程保留。
- **播放器遮罩**：`DemoVideoOverlay` 覆盖视频帧与弹幕，`IgnorePointer` 纯视觉、不暂停、不改播放状态；视频详情 / 番剧播放 / 直播间（含全屏）均覆盖。
- **编辑（仅演示模式可用）**：数字 → 弹层输入（非负整数校验）；枚举 → 下拉任选；均含「恢复默认」（清单项覆盖值）；设置页提供「重置演示自定义」一键清空。

**覆盖范围与例外（决策记录）**：

- 全部内容页接入：首页 5 tab（推荐/关注/热门/番剧/直播）、动态、动态详情、历史、稍后再看、收藏（列表+详情）、搜索主页（热搜骨架/联想隐藏/他人头像行隐藏）、搜索结果、成员空间（自己空间替换+编辑/他人空间头部骨架+各 tab 骨架）、视频详情（分区骨架+播放器遮罩）、番剧详情、番剧播放、直播间、消息（主页/会话列表/聊天/回复我/艾特我/点赞我/系统消息/点赞详情）、关系页、专栏页、合集系列页、个人页账号区与其下内容板块。
- **不遮罩**：设置页（需可操作）、登录页、用户协议；**下载页**（离线缓存管理页，仅目录/空间/清理，无云端内容展示）；**弹幕屏蔽规则页**（用户自身配置管理，非第三方内容展示）。

## 7. 第二轮实机反馈修复（同日迭代）

**反馈现象**：

1. 内容页加载态骨架**不可交互**：无法左键点进视频播放页的演示界面，右键「更多选项」菜单也不弹出；且演示模式下动态页骨架的扫光动画对视觉有干扰。要求改为"**可交互的无云端数据的静态占位控件**"。
2. 「我的」页面「离线缓存」区域显示为一大片灰色占位（离线缓存属本地数据，不应被演示骨架替换）。
3. 消息页会话**无法点进**；要求会话可进入聊天，且聊天内视频卡片消息显示为静态骨架卡。

**根因**：

1. 第一版采用「整页 DemoMask」策略：演示开启即用骨架替换整块内容区，卡片/列表项的 InkWell、右键菜单、跳转等交互被整体卸载；骨架默认带扫光动画。
2. 离线缓存为本地目录统计（无云端数据），其内容区被错误替换为轮廓骨架。
3. 会话列表与聊天内容同样被整块骨架替换，交互被卸载。

**修复方案**：

- **卡片级静态占位（核心转变）**：恢复列表真实渲染，`VideoCardV/H` 按演示开关把标题/UP 名/时长/统计角标替换为**静态灰条**（`SkeletonLine`，无动画），封面走 `NetworkImgLayer` 占位；**保留全部交互**（左键进详情、右键/长按"更多选项"、UP 链接、"…"菜单）；菜单内 BV 号/UP 名文案脱敏、隐藏「查看/保存封面」（云端素材）。
- **全局**：`Skeleton` 扫光动画在演示模式下自动退化为静态（一处修改覆盖全部骨架）。
- **动态页**：视频/追番/瀑布流网格逐项渲染"静态占位卡 + 真实点击导航"（点进对应视频/番剧/动态详情演示页）。
- **首页推荐/热门/关注、视频详情相关推荐、历史、稍后再看**：全部恢复真实列表渲染（交互保留、文本脱敏）。
- **「我的」页**：离线缓存恢复本地内容展示（仅收藏/历史/稍后再看内容区保留演示占位）。
- **消息**：会话列表恢复真实渲染（头像默认占位，昵称/预览/时间/未读角标脱敏），正常点进聊天；聊天气泡按类型显示静态占位（文本→灰条气泡；**视频卡片消息→静态骨架视频卡**）。

## 8. 第三轮实机反馈修复（同日迭代 · v3 演示内容本地化）

**反馈与修复**：

1. **「我的」页顶部（离线缓存上方）超大灰色区域** —— 根因：`AppActionTile` 内部返回 `Flexible`，被演示外壳多层包裹后触发 ParentDataWidget 断言，Release 下渲染为灰色错误块（位置恰为统计行）。
   修复：`AppActionTile` 新增 `flexible` 开关（默认 true，不影响既有调用方）；统计行改由调用方在最外层提供 `Flexible`。
2. **演示模式仍真实播放视频（与正常数据互相影响）** —— 修复：视频详情页演示下**完全隔离**：跳过详情/相关/标签/评论加载与播放器创建（不拉流、不播放、不发 playurl 请求），视频区域为**灰色静态占位符**；进入演示即暂停播放，退出演示自动恢复云端加载与播放器初始化（番剧播放页/直播间同规则：不创建播放器/不连接直播流，灰占位+暂停，退出恢复）。
