## 一、现象描述

- 第一批收口后，B7 残余面停在 **19 文件**。其中三类是**结构替换型残点**（非美术、非主题架构）：
  - **容器族 7 文件**：残留 `Material(color: transparent, ...)`（`MaterialType.transparency`）包裹层 —— `app_scaffold` / `app_dialogs` / `miuix_overlay_panel` / `image_gallery_viewer` / `live/view` / `pgc/view` / `geetest_webview_dialog`。

- 本轮目标：清完上述 **13 文件**，把容器/对话/文本三族从 material 依赖中摘除。

## 二、问题根因

- 这三族的替身**通道早已存在**，只是尚未套用：
  - 透明容器：material `Material(type: transparency)` 的语义 = 提供 `DefaultTextStyle`（bodyMedium）+ 可选裁剪，**不绘制任何东西**（无 ink 消费者）。项目内可用零 material 等价件复刻。
  - `Dialog`：项目自建 `AppDialogShell` / `AppAlertDialog`（`lib/common/widgets/app_dialog_shell.dart`），其默认参数（insetPadding 40/24、minWidth 280、底色 `surfaceContainerHigh`、radius 16）与 material `Dialog` 默认**逐项一致**。
  - 内联 `TextField`：widgets 层 `EditableText` 可直接承载，配 Miuix 选择控件与右键菜单即可。

## 三、修复方法（13 文件 + 1 新增）

### 1. 新增零 material 替身 `lib/core/shell/app_transparent_host.dart`

`AppTransparentHost({bool hardClip = false, required Widget child})` = 外层 `DefaultTextStyle(tokens.text.bodyMedium ?? TextStyle())` + 可选内层 `ClipRect()`。

**复刻依据**（`material_ui` 1.5.0 `material.dart` L445–560 `_MaterialState.build`，只读源码）：子树依次为
`AnimatedDefaultTextStyle(style: widget.textStyle ?? Theme.of(context).textTheme.bodyMedium!)` → `NotificationListener<LayoutChangedNotification>` + `_InkFeatures` → `ClipPath(ShapeBorderClipper(RoundedRectangleBorder()), clipBehavior)` + `_ShapeBorderPaint`（transparency shape 为矩形、不描边 → 不绘制）。
- ink 层：自 B6 起全站 `InkWell`/`ListTile` 已 Miuix 化，**已无消费者** ⇒ 不迁移 ink。
- 文本基底：`AppTextStyles.bodyMedium`（`app_theme_host.dart`）= `_inkLight`/`_inkDark` = `TextStyle(color: miuixLight/DarkOnSurface, decoration: none, decorationColor: 同色)`，**无 fontSize** —— 与 material `Theme.of(context).textTheme.bodyMedium` 逐字段一致（同属 B7-a 零漂移派生）。
- 裁剪：`ClipRect()` 默认 `hardEdge`，等价于 transparency shape 的矩形裁剪；`image_gallery_viewer` 原用 `Clip.hardEdge` ⇒ 传 `hardClip: true`。

### 2. 容器族（7 文件）→ 套用 `AppTransparentHost`

| 文件 | 原 `Material(transparency)` 位置 | 替换 |
|---|---|---|
| `core/shell/app_scaffold.dart` | `Widget materialOf(child) => Material(type: transparency, child: child)` | `AppTransparentHost(child: child)` |
| `core/shell/app_dialogs.dart` | ① `buildPage` 包裹 ② sheet 表面壳 | ① `AppTransparentHost(child: builder(context))`；② `ClipRRect(vertical top 28)` + `ColoredBox(backgroundColor ?? surfaceContainerLow)` + `AppTransparentHost` |
| `common/widgets/miuix_overlay_panel.dart` | `Material(color: transparent, child: ...)` | `AppTransparentHost` |
| `common/widgets/image/image_gallery_viewer.dart` | `Material(color: transparent, child: Clip.hardEdge ...)` | `AppTransparentHost(hardClip: true)` |
| `pages/live/view.dart` | `Material(color: transparent, child: MiuixPressable)` | `AppTransparentHost` |
| `pages/pgc/view.dart` | 同上 | `AppTransparentHost` |
| `pages/login/geetest_webview_dialog.dart` | `Material(color: transparent, child: Stack)` | `AppTransparentHost` |

> `app_dialogs` 的 sheet 表面原由 `Material(type: transparency)` 提供文本基底与圆角承载，替换后由显式 `ClipRRect`（顶圆角 28）+ `ColoredBox`（底色）+ `AppTransparentHost`（文本基底）三件拼回，逐项等价。

### 5. 导入替换规则（本批生效，供后续复用）

- 裸 `import 'package:material_ui/material_ui.dart';` → `import 'package:flutter/widgets.dart';`。
- 若文件用到 services 层符号（`HapticFeedback` / `Clipboard` / `ClipboardData` / `TextInputType` / `FilteringTextInputFormatter` / `SystemMouseCursors` / `LogicalKeyboardKey` / `KeyEvent` 等）则**必须**同时/改用 `import 'package:flutter/services.dart';`。
- 关键事实：`package:flutter/widgets.dart` **不**导出 `services.dart`；`Clip` 枚举亦未在 widgets/rendering/painting 的 export 中命中 ⇒ **避免显式引用 `Clip`**，改用 `ClipRect()` / `ClipRRect()` 默认值。
