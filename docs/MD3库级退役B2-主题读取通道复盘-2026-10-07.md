## 二、2a 设计与实现（关键决策）

1. **新增项目调色板 `AppPalette`**（`lib/core/shell/app_theme_host.dart`）：
   - 字段名与 Material `ColorScheme` **一一对齐**（primary/onPrimary/primaryContainer/
     secondary/secondaryContainer/tertiary/tertiaryContainer/surface/surfaceContainerLow/
     surfaceContainer/surfaceContainerHighest/onSurface/onSurfaceVariant/outline/
     outlineVariant/background/onBackground/error/onError/inverseSurface/onInverseSurface/scrim）
     → 迁移可做**纯机械替换**：`Theme.of(c).colorScheme.X` → `AppThemeHost.of(c).colors.X`；
   - **取值全部来自项目调色板常量**（`theme/colors.dart` 的 `miuixLight*/miuixDark*`，
     即过渡期 ThemeData 的 ColorScheme 来源）→ **零视觉漂移**；
   - 两个项目未覆写、迁移前取 `ColorScheme` 默认值的字段，显式补 M3 基线值并注明：
     `surfaceContainerLow`（浅 0xFFF7F2FA / 深 0xFF1D1B20）、`onError`（浅白 / 深黑）；
   - `inverseSurface` / `onInverseSurface` 按既有语义映射（亮色主题用深色反色卡、暗色反之）。
2. **`AppTokens` 结构定稿**：`brightness` / `colors`（AppPalette）/ `miuix`（MiuixColors
   专有语义入口，如 `windowDimming`）/ `shapes` / `typography` / `chrome`；`isDark` 便捷位。
3. **读取通道统一为 `AppThemeHost.of(context)`**：
   - `extension<AppShapes>() ?? AppShapes.miuix` → `tokens.shapes`（其余两个同理）——
     fallback 分支自然消失（宿主未挂载时 `of()` 内部按平台亮度回退）；
   - `titlebar` 条带底色由 `theme.scaffoldBackgroundColor` 改 `tokens.colors.background`
     （生产取值相同：`AppTheme.lightFor()` 的 scaffoldBackgroundColor 即 `miuixLightBackground`）。
4. **迁移方式**：脚本化替换（12 文件）+ `dart analyze` 兜底 + 逐点人工复核。
