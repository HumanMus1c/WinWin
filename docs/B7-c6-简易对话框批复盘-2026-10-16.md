# B7-c6-1b 简易对话框批复盘（2026-10-16）

> 批次：b7-c6（杂项残点批）第二子批 —— 简易对话框家族（`SimpleDialog` / `SimpleDialogOption`）。
> 目标：把这族 Material 符号换为**零-material 自绘替身**，并向"闸门 lib=0"推进。

## 1. 现象与目标

b7-c6-1a 完成 `AlertDialog` 全族切替后，残留的对话框家族符号集中在
`SimpleDialog` 一族（词边界实测：5 处 `SimpleDialog(` + 8 处 `SimpleDialogOption(` = 13 处），
分布于 5 个文件：

| 文件 | 形态 |
|---|---|
| `lib/common/widgets/demo_editable.dart` | 数字/选择编辑弹窗（`SimpleDialog` + `SimpleDialogOption`） |
| `lib/common/widgets/video_card/video_context_menu.dart` | 不感兴趣理由（`SimpleDialog`，内容为 Chip 网格） |

## 2. 定因与复刻依据

**上游真值**（`material_ui` 1.5.0 `lib/src/dialog.dart`）：

- `SimpleDialogOption`（L1086-1117）= `InkWell(onTap) → Padding(default 8/24) → child`；
- `SimpleDialog.build`（L1310-1419）：
  `IntrinsicWidth(stepWidth: 56)` → `Column(mainAxisSize.min, crossAxisAlignment.stretch)`
  = `[title?, Flexible(content)]` → `Dialog(...)`；
  - title：`titlePadding` 默认 `fromLTRB(24,24,24,0)`，四边乘 `paddingScaleFactor`，但**有 children 时 bottom 不缩放**；
  - content：`Flexible(SingleChildScrollView(padding: contentPadding 默认 fromLTRB(0,12,0,16), child: DefaultTextStyle(ListBody(children))))`，**无 title 时 top 参与缩放**；
  - 标题样式 = `titleTextStyle ?? dialogTheme.titleTextStyle ?? textTheme.titleLarge`；内容样式 M3 默认 = `textTheme.bodyMedium`。

**项目最终态对齐**（零视觉变化口径）：

- `app_theme.dart` 的 `dialogTheme` **未覆写** `titleTextStyle` / `contentTextStyle` ⇒ 取
  `AppTextStyles.titleLarge` / `AppTextStyles.bodyMedium`（B2-t1 零漂移派生，仅携带 color/decoration）；
- `dialogTheme` = `elevation 0` + `RoundedRectangleBorder(_miuixRadiusLarge = 14×1.15 → 16)`
  （与 `AppShapes.miuix.large` 同值）+ 背景 `surfaceContainerHigh` ⇒ 外层复用
  b7-c6-1a 的 `AppDialogShell`（默认 40/24 + `minWidth 280`）。

**唯一非机械点**：`SimpleDialogOption` 的 `InkWell` 是 Material 符号。零-material 应对取全站
统一按压件 `MiuixPressable`（`feedbackType: sink, sinkAmount: 0.98`，`lib/` 内 **73 处**同规格）。
此为全站 Miuix 化的**既定目标态**（与 b7-c4/b7-c5 已迁移的 26 处按压件一致），非本批新引入的差异。

**顺带发现**：`AlertDialog` 用**无** `stepWidth` 的 `IntrinsicWidth`（dialog.dart L952），
而 `SimpleDialog` 用 `stepWidth: 56.0`（L1389）——b7-c6-1a 的 `AppAlertDialog` 取无 stepWidth 版本正确；
本批 `AppSimpleDialog` 按上游保留 `stepWidth: 56.0`。

## 5. 遗留与踩坑

1. **`kToolbarHeight` 尚余 3 处**（`pages/video/detail_page.dart`）：同属 Material 常量，
   已在 `Style.toolbarHeight` 备好对等常量，待该文件其余 Material 符号（`Scaffold`/`Divider`/`ThemeData`）
   清理时一并替换（归 c6-3 / c6-4）。
2. **`MiuixPressable` 替代 `InkWell`** 属观感变更（水波 → 2% 扁平内缩），已在 §2 定性为全站目标态；
   实机复验时如有异议可回退为 `feedbackType: none`（但会失去按压反馈）。
3. **`AppSimpleDialog` 为零视觉变化自绘复刻**：`stepWidth: 56` / 段内边距缩放规则 / `titleLarge`·`bodyMedium`
   样式均已逐条对齐，仍需实机复验（5 处弹窗 + 密度观感）。
4. **Release 构建的环境依赖**：桌面端有实例在跑时，Release 产物拷贝必然失败（DLL 被占用）；
   正确处置是**先关实例再复跑**，而不是强杀进程。
