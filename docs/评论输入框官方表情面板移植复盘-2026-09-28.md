## 1. 分析根因（现状与需求分析）

### 1.1 现象与事实调查

- 全历史取证（`git log --all -S/-G` 全引用检索 + 334KB 全量 diff 复核 + 15 个 stash 快照 + compose 分支 + backup 标签）：
  **视频/番剧/专栏/动态的评论输入框从未有过官方表情面板**，不存在"被某次修改删除"的提交。
- 直播页底部互动条自 2026-09-13（`1cc7db8`）起拥有官方表情面板（`live_room_page.dart::_buildEmotePickerButton`），
  按钮位于输入框左侧，弹层为 6 列官方表情网格，点击将 `[xxx]` 插入光标处——即用户所指的"官方表情面板"。

### 1.2 评论区四项现状缺口（根因链）

```
直播页表情面板为页面私有方法（不可复用）
  → 4 个评论输入入口全部没有表情按钮【缺口1】
  → 专栏文章页 / 动态详情页 连评论输入栏都没有（只有评论列表）【缺口2】
  → VideoHttp.replyAdd 的 type 写死为 1，非视频评论区无法复用发送【缺口3】
  → 官方表情包接口 ReplyHttp.getEmoteList（/x/emote/user/panel/web）
    自 2026-08-08 预留后全历史无任何调用方【缺口4，本次按需预留】
```

- 渲染侧闭环已就绪：`631cd87` 已实现评论 `[xxx]` → 表情图片渲染（`ReplyContentView`），
  发送纯文本编码即可由服务端解析、客户端渲染，**无需任何请求/渲染层改动**。

### 1.3 弹幕可行性分析（任务②，结论：不支持）

| 证据 | 结论 |
|---|---|
| `business=danmaku` 调官方表情面板接口 → `-400 请求错误`（同期 `business=reply` 未登录返回 `code:0`） | 平台无"弹幕表情面板"数据源 |
| `DanmakuElem` proto 全字段无表情位；`/x/v2/dm/post` 全参数无表情位 | 协议层无表情语义 |
| PiliPlus / BiliPai / Bili.Copilot 三家成熟客户端的视频弹幕均无表情（发送与渲染皆无）；BiliPai 的"表情弹幕位图"实现仅服务直播链路（`DanmakuEmoticonMapper` 注释即"直播弹幕表情映射器"） | 第三方生态一致认定视频弹幕无表情能力 |
| 实测真实弹幕（BV1GJ411x7h7 1200 条 + 教程视频 120 条）：`[doge]`×2、`[Ohh]`×45 等方括号文本，但拼写变体泛滥（`[ohhh]`/`[(OHH)]`/`[[ohh]`），形态为**用户手打文本**；官方"你被骗了/跳伞"属关键词触发的特效彩蛋弹幕，与官方表情图片体系无关 | 弹幕中的 `[xxx]` 无表情图渲染标准 |
| 本项目弹幕引擎（vendored canvas_danmaku）为纯文本 `ui.Paragraph` 渲染，无内联图片能力 | 本机无渲染能力 |

**结论**：官方弹幕不存在"发送官方表情"能力（无数据源、无协议字段、无渲染标准），按任务约定**不新增**弹幕表情面板；
若未来官方开放（如新增 danmaku 业务或协议字段）再评估。

## 4. 本轮修复总结

- **改动面**：8 文件（2 新增 + 6 修改）——
  - `lib/common/widgets/comment/emote_picker.dart`（新增）：`OfficialEmotePickerButton` 共享表情面板按钮；
  - `lib/common/widgets/comment/comment_input_bar.dart`（新增）：`SimpleCommentInputBar` 专栏/动态共用输入栏；
  - `lib/pages/video/detail_page.dart`：输入栏接入表情按钮 + 焦点节点（+11 行）；
  - `lib/pages/bangumi/bangumi_player_page.dart`：同款接入（+11 行）；
  - `lib/pages/article/article_page.dart`：新增输入栏/发送/dispose（+64 行）；
  - `lib/pages/dynamics/detail_page.dart`：同款（+64 行）；
  - `lib/pages/live/live_room_page.dart`：删除私有面板方法、切换共享组件（-96/+30 行）；
  - `lib/http/video.dart`：`replyAdd` 增加 `type` 参数（默认 1，零回归）。
- **行为预期**：四处评论输入框左侧均出现直播同款官方表情面板，插入 `[xxx]` 后发送，评论以官方表情图片渲染
  （服务端解析 + 既有 `ReplyContentView`）；直播页外观与行为保持不变。
- **遗留项**：
  1. 面板数据源为内置 28 个高频表情（与直播一致）；如需官方全量表情包（小黄脸全量/热词系列/用户已购），
     可后续启用已预留的 `ReplyHttp.getEmoteList(business)` 升级为多分页面板（本次按"严格移植直播面板"执行）；
  2. 专栏/动态新输入栏仅支持一级评论（对应列表暂无楼中楼入口）；
  3. 动态关闭评论（`input_disable`）场景由服务端报错提示兜底，未做输入栏置灰。
