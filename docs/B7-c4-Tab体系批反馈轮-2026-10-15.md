## 一、现象描述

用户在实机复验 Tab 体系批（`1bd48c2`）后提出 5 项缺失：

1. **搜索结果页顶部缺失搜索输入框**：分类标签条上方没有输入框，用户无法在结果页改关键词。
2. **用户空间分类标签条没有吸顶**，排在顶部按钮行下方；要求**把标签条收缩宽度后放进顶部按钮行**，并让**该按钮行复用标签条的背景样式**。
3. Tab 体系**缺失 HOVER 效果与点击效果**。
4. Tab 栏**背景不支持毛玻璃**（要求对齐 `MiuixOverlayPanel` 的模糊效果）。
5. 所有 Tab 栏都**叠在滚动区域之上**，滚动时内容会出现在 Tab 栏后方。

## 二、问题根因

- **3 / 4 属库能力缺口**：`flutter_miuix 1.3.0` 的 `miuix_tab_row.dart` 中，`_TabItem` 仅有
  `GestureDetector(behavior: opaque, onTap:)`，**没有任何 hover / 按压视觉**；条形底色由
  `_TabRowBase` 的 `ColoredBox(colors.background(false))` **不透明**填充，**结构上无法承载模糊**。
  库为 pub 外部依赖（`pub cache`），不可改，只能在 `AppTabBar` 层外挂指针层与自绘材质。
- **5 属骨架事实**：`MiuixScaffold` 把 `topBar` 作为布局槽位（内容高度 = 布局高 − topBar 高），
  **topBar 不是叠加层**，故 `AppScaffold.topBar` 类页面本就不会出现"内容滚到栏后"；
  真正叠在滚动区之上的是**空间页**（自绘 `SliverAppBar` + 内容 `NestedScrollView`）与
  `SliverPersistentHeader` 场景 —— 这两处才是毛玻璃材质要覆盖的目标。
- **1 属历史回退**：`git log` 该文件显示 B5-3「去标题栏」([`4dd1b4d`]) 把
  `MiuixSmallTopAppBar(navigationIcon/title/bottomContent: TabBar)` 整块换成
  `topBar: TabBar`，**输入框随标题栏一起被移除**，此后再未补回。
- **2 属结构问题**：空间页标签条是独立 `SliverPersistentHeader(pinned: true)`，
  落在头图卡片**下方**，与"按钮行在同一行"不符。

## 三、修复方法

### 3.1 `lib/ui/components/app_tab_view.dart`（AppTabBar 改造）

- `AppTabBar` 由 `StatelessWidget` 改为 `StatefulWidget`，新增：
  - **指针几何**：`LayoutBuilder` 取可用宽 → 复刻库内私有 `_calculateTabWidth(count, min, max, spacing, available)` 算单项宽与节距 → `MouseRegion.onHover` / `Listener.onPointerDown` 的 `localPosition` 反查命中索引（落在标签间距的缝隙里返回 `null`）。库不暴露单项矩形，命中判定只能自算；函数已注释声明**与库版本绑定**，升级 flutter_miuix 后需复核。
  - **hover / 按压反馈**：在库组件**下层**画圆角高亮（未选标签项自身透明，可透出）：hover = `onSurface` α0.06，按压 = α0.12 加深；高亮常驻、靠透明度切换以获得淡入淡出（120ms `easeOut`）。按压另按项目既有口径 `sinkAmount 0.98` 做整条轻微微缩（90ms）——库内 item 无法单独包裹，只能整条下沉，已在注释声明。
  - **毛玻璃底**：`blurBackground`（默认 true）时把库内底色透传为透明，外层套共享件 `MiuixFrostedSurface`；`blurBackground: false` 时保持库原底色（调用方自带背景）。
  - **滚动横向滚动条**：把自有 `ScrollController` 注入库（库只在自建时才 dispose），以便读取 `offset` 平移高亮层，并在滚动时重建。
  - **`fittedWidth(count, ...)`** 静态方法：按"单项最大宽 × 数量 + 间距"估算收缩宽度，收敛在 240~420，供把标签条塞进按钮行/工具栏时取定宽。
- `AppTabController` / `AppTabBody` / `AppTabView` 未改（联动语义不变）。

### 3.2 `lib/common/widgets/miuix_frosted_surface.dart`（新增）

抽出与 `miuix_overlay_panel.dart` 同材质的**可复用底**（半透明底 `#EAEAEA`/`#262626` ×
`kMiuixSurfaceAlpha` + `BackdropFilter(blur 16)` + 1px 描边 + 圆角 12 + 4px 下投影），两档：

- **面板档**（默认 `borderRadius = 12`）：四边描边 + 下投影，用于悬浮标签条；
- **全宽档**（`borderRadius = 0`）：无圆角无投影、仅底部 1px 描边，用于通栏按钮行。

标签条与该按钮行**共用同一材质定义**（P4：一个概念只定义一处），不做两处各写一份。

### 3.3 `lib/pages/search/search_result_page.dart`

- 顶部恢复**搜索输入条**：`AppCapsuleTextField`（放大镜前缀 + 清除按钮后缀，非空才显示）+
  `MiuixTextButton('搜索')`，与 `search_page.dart` 的入口条同口径；标签条在其**下一行**。
- 页内二次搜索：`_submit` 去空格 → 记入历史 → 关键词变化则 `setState` 重建各分类
  `SearchPanel`（`key: ValueKey('$_keyword-${t.name}')`，面板在 `initState` 发起请求）。
- 移除 `material_ui` import（本文件已无 Material 符号）→ **闸门 66 → 65**。

### 3.4 `lib/pages/search/search_history_service.dart` + `search_page.dart`

- 新增 `SearchKeywordHistory`（单点承载关键词历史：`storageKey` / `maxEntries = 20` /
  `load` / `push` / `remove` / `clear`）；`search_page.dart` 的 4 处 `GStorage` 直写改为调用它，
  结果页写入同一口径，避免两处各写一份存储规则（同时 `search_page` 的 `storage.dart` import 转为未用并移除）。

### 3.5 `lib/pages/member/member_space_page.dart`

- `SliverAppBar.actions` **首项**插入收缩宽度的 `AppTabBar`（`width = AppTabBar.fittedWidth(tabs.length)`，
  再用窗口宽 50% 封顶），其后为分享/更多按钮。
- **删除**原独立 `SliverPersistentHeader(pinned)` 标签条与仅服务于它的
  `_SliverAppBarDelegate` 委托类；`_buildSpaceContent` 内的 `tokens` 局部随之移除。
- `flexibleSpace` 改为 `Stack`：`FlexibleSpaceBar(头图)` + 顶部 56px 高的
  `MiuixFrostedSurface(borderRadius: 0)` 通栏毛玻璃带 → **按钮行复用标签条材质**，
  头图/内容滚动时从行后经过呈模糊。

## 五、遗留与踩坑

**遗留**

- **观感裁决待实机**：标签条仍是 Miuix 胶囊（承接上一批），与用户期望的下划线样式差异未决；可回退为自绘下划线头（`AppTabBody` 不动）。
- 空间页标签条宽度上限为 **420 / 窗口一半**（`AppTabBar.fittedWidth` 参数可调）；标签数很多时仍可能偏窄。
- 全宽档毛玻璃（空间页按钮行）叠在头图上，若观感"发灰"可调 `kMiuixSurfaceAlpha` 或 blur 半径。
- **命名冲突**：`b7-c4` 被"输入条统一共享批"与"Tab 体系批"两处复用，封板前建议统一改号（输入条→`b7-c4a`、Tab→`b7-c4b`），待定夺。
- 本批**未做** UI 自动化操控（用户机器规则），故"实机 UI 正确性"未经 Agent 亲验。

**踩坑**

- **`edit_file` 删除类时误留占位类**：先用占位类替换 `_SliverAppBarDelegate`、再想删除时，第二次替换误把类声明写成
  `class _MemberSpacePageState extends State<MemberSpacePage> {`，造成**重复类名 + 悬空大括号**；当即读现场修正。
  教训：**删除一个类应直接用空 `new_string` 一次删净**，不要"先占位再删"。
- 顶部换成 `flutter/widgets.dart` 后，`TextInputAction` 不再随 `material_ui` 可用 → 需显式
  `import 'package:flutter/services.dart';`（analyze 首轮报 `undefined_identifier`）。
- 抽走材质后 `dart:ui show ImageFilter`、`kMiuixSurfaceAlpha` 在 `app_tab_view.dart` 变为未用；把历史写作抽成
  `SearchKeywordHistory` 后 `search_page.dart` 的 `storage.dart` 也变为未用 —— 三处均按 analyze 提示清理。

## 六、总结

本批把"Tab 体系批"实机暴露的 5 项缺失一次收口：**库能力缺口（hover/按压/模糊）在替身层补齐**，
**历史回退（结果页输入框）按搜索入口页口径补回**，**空间页标签条从独立 pinned 行收进按钮行并复用标签条材质**。
过程中新增了 `MiuixFrostedSurface` 共享材质件与 `SearchKeywordHistory` 共享存储口径，为后续批次提供复用点；
`dart analyze` 0/0、全量测试 172/172、debug/release 双编译 0 警告，闸门数字再降 1（66 → 65）。
Tab 头观感（胶囊 vs 下划线）与空间页宽度上限仍待用户实机裁决。
