# 视频分P云端记忆恢复与「选集」弹层（2026-11-13）

## 一、现象与需求

1. 多分P稿件在播放过其它分P后重新进入，页面仍从 P1 开始；且云端记录的「上次观看分P进度」会被错误套用到 P1 上——即看起来「没有记忆播放到的分P及其进度」。
2. 分P 胶囊组末尾需要一个**不跟随横向滚动**的展开按钮，点击打开类似「添加到收藏夹」的「选集」弹层：以行列（宫格）展示全部分P，顶部提供同款搜索；若云端无分P 搜索接口则本地按标题过滤。

## 二、定因

### 1. 上报端没有缺失，缺口在恢复端

- 心跳（`/x/click-interface/web/heartbeat`）与历史进度上报（`/x/v2/history/report`）均携带 `cid`、`progress`、`duration`，云端本就按分P 记录；
- `_applyPlayInfo` 只读取 `last_play_time` 并直接套到当前 cid，**完全未使用 `last_play_cid`**：
  - 无法得知上次观看的是哪个分P，永远从默认 P1 起播；
  - B 站 `last_play_time` 绑定 `last_play_cid`（参照 BiliPai `PlayerInfoData.resumePositionMs(cid)`：仅当 `last_play_cid == cid` 时才返回进度），因此 P1 会被错误定位到其它分P 的进度。

### 2. 选集搜索无需云端接口

稿件详情接口（`/x/web-interface/view`）一次返回全量 `pages`（cid / 序号 / 标题 / 时长），打开弹层即可本地建立标题索引，无需额外搜索接口。

## 三、方案

### 1. 分P 云端记忆恢复（[detail_page.dart](file:///d:/Documents/GitHub/WinWin/lib/pages/video/detail_page.dart)）

- 新增 `_resolveResumePage`：多分P 且已登录时，先用默认 cid（P1）请求一次 playInfo（**最多等 2 秒**，超时/失败回退默认分P，避免弱网卡住整页加载），读取 `last_play_cid`：
  - 命中其它分P 且存在于 `pages` → 直接以该 cid 创建播放器起播（其字幕/章节按新 cid 正常拉取）；
  - 与默认分P一致 → 复用本次 playInfo 响应（`prefetched`），省一次请求。
- `_applyPlayInfo` 增加进度归属判定：
  - 单P（`pageCount <= 1`）沿用原口径直接恢复；
  - 多P 仅在 `last_play_cid == 当前 cid` 时恢复，否则放闸从 0 起播（`other-part-progress`），杜绝跨分P 误定位；
  - 新增 `ctrl.disposed` 守卫，避免快速切换分P 后旧请求回写已释放的控制器。
- 当前分P 进度上报仍由 `WinWinPlayerController.dispose()` 统一完成（切分P / 离开页面时携带该 cid 上报心跳与历史）。

### 2. 固定「选集」按钮 + 宫格弹层

- 分P 胶囊行结构改为：`分P` 标签 + 横向滚动胶囊 `Expanded` + **固定「选集」按钮**（不参与横向滚动）；
- `_PageSelectorSheet` 对齐「添加到收藏夹」弹层：
  - `MiuixSmallTopAppBar('选集')` + `AppCapsuleTextField('搜索分P')`；
  - `GridView` 行列展示全部 `P序号 / 标题 / 时长`，当前分P 高亮，点击即切换并关闭；
  - 搜索完全本地执行（`P序号 + 标题` 大小写不敏感包含匹配），空结果显示「未找到分P」；
  - 首次布局后按列数/行高估算目标行，自动滚动到当前分P（宫格懒构建，GlobalKey 无法命中远处项）。

## 六、遗留与踩坑

1. **记忆依赖登录与云端数据**：未登录时不做分P 预检；`last_play_cid` 依赖心跳/历史上报成功，若上报被弱网吞掉则回退默认分P。
2. **多P 预检增加一次请求**：仅登录 + 多P 时发生，最多 2 秒；同分P 时复用响应，不额外请求。
3. **未做播完自动下一P**：分P 结束仍停在本P，自动连播可后续在 `completed` 监听内扩展。
4. **选集搜索为本地全量索引**：分P 数量来自详情响应，无需分页/云端搜索。

## 七、总结

云端上报本就带分P 与进度，真正的缺口是恢复端未使用 `last_play_cid`，并把上次分P 的 `last_play_time` 误套到 P1。本次按 BiliPai 的归属语义修正进度恢复，并在多P 且登录时自动回到上次观看分P；同时在分P 胶囊组末尾加入固定「选集」按钮与可搜索的宫格弹层（本地标题索引）。静态分析零问题、Windows debug/release 双编译通过，待实机验证跨会话记忆与选集切换。
