# 转场改用 Miuix 动效规范 + 标题条内容区裁剪兜底 复盘（2026-10-07）

- 日期：2026-10-07
- 类型：界面回归修复（页面转场主题换代 + 沉浸标题栏壳层裁剪兜底）
- 诉求：**进出视频播放页时页面会瞬间叠在标题条之上，又瞬间恢复**
- 相关：`docs/沉浸式透明标题栏改造复盘-2026-10-06.md`（10-06 沉浸标题栏改造，本次问题的前置条件）

---

## 一、分析根因（现象 · 取证证据 · 根因链）

### 1.1 现象

进出视频播放页（push/pop）时，页面内容瞬间覆盖到顶部 32px 标题条上——WinWin 名称与右上三键被盖住，
随后瞬间恢复；过程极快（数百毫秒内出现又消失）。

### 1.2 取证（逐帧像素探针，非推测）

临时探针（`flutter test`，1200×800，DPR 1.0）复刻"沉浸壳层 + 路由 push/pop"，逐 40ms 抓取整窗画面并
采样标题条 x=600 处的颜色（`00ff00`=壳层底色 / `ff0000`=旧页 / `0000ff`=新页）：

| 阶段 | 实测像素（现状：materials_ui 默认 Zoom 转场 + 无裁剪） |
| --- | --- |
| push +40ms | y28=ff0000、y31=ff0000（标题条下部开始被覆盖） |
| push +80~280ms | y16~y31=ff0000（覆盖标题条中下部，持续） |
| push +320ms | 全部恢复 `00ff00` |
| pop +40ms | y10~y31=ff0000（几乎盖满整条） |
| pop +40~160ms | 覆盖范围逐步收缩，直至恢复 |

对照组（内容区加 `ClipRect`）：push/pop 全程所有采样点恒为 `00ff00`——零覆盖。

### 1.3 根因链

1. **转场**：Windows 平台使用 material_ui 1.5.0 平台默认
   `TargetPlatform.windows → ZoomPageTransitionsBuilder`；该转场为"居中缩放"：
   - push：旧页 `1.00 → 1.05`（新页 0.85 → 1.0）；
   - pop：被弹出页 `1.00 → 1.10`，下层页 `1.10 → 1.00`。
   缩放使页面绘制范围**超出路由视口**（视口上下各溢出 2.5%~5% 高度）。
2. **壳层**：`ImmersiveTitleBarShell` 为 `Column`（32px 标题条在上 / 路由内容区在下），内容区
   **未做裁剪**；Flutter 不裁剪子节点绘制，于是溢出内容直接画到标题条上（含三键与名称）。
3. **瞬时性**：转场结束缩放回到 `1.0`，溢出消失 → 表现为"瞬间叠上又瞬间恢复"。

### 1.4 为什么此前没暴露（用户提问：MD3 都已退役，为何还在用 material_ui 默认转场？）

| 层面 | 状态 | 证据 |
| --- | --- | --- |
| 样式级退役（M3 分支/枚举/Token/图标映射） | ✅ 已清零（−2900 行） | `docs/MD3退役进度追踪-2026-10-04.md`（L1~L5） |
| **库级 material_ui** | ⛔ 明确暂缓（"自建 WidgetsApp 壳 + 迁移 141 文件骨架/主题面"独立立项） | 同上，L4-0 分级结论 / 阶段5d 收官遗留项 |
| `pageTransitionsTheme` | **从未覆写（lib 全库 0 处）** | `grep "PageTransitionsTheme\|PageTransitionsBuilder" lib/` 无命中 |

→ 转场主题属"骨架 + 主题面"，一直吃 material_ui 的平台默认值。且**不是 1.5.0 升级引入**：
material_ui `1.0.0` 与 `1.5.0` 的 `_defaultBuilders` 完全一致（Windows 同为 Zoom，两版源码逐行核对）。
10-06 沉浸标题栏改造前，路由内容在 Flutter 视图之外、被原生客户区物理裁掉；沉浸化把 32px 条带纳入
Flutter 视图且未裁剪，才让该溢出显现。

## 二、设计修复计划（方案与关键决策/取舍）

### 2.1 转场来源检索（移植优先原则）

- **本地/包源码**：`flutter_miuix-1.3.0/lib` 共 107 个 dart 文件，`PageTransitionsBuilder |
  PageTransitionsTheme | pageTransition | PageRouteBuilder | RouteTransition | MaterialPageRoute`
  **0 命中**；包出口 `miuix.dart` 无页面转场组件 → **flutter_miuix 无现成转场可移植**；
- **全网**：flutter_miuix（ChuxinNeko/flutter_miuix）与 Miuix 上游组件清单同样无页面转场实现；
- **可用的是动效规范**：`MiuixMotion`（源自 compose-miuix-ui 的 `anim/`）：
  `standardDecelerate`（标准缓出，进场/出现）、`standardAccelerate`（标准缓入，退场/消失）、
  `sinOut`、`folmeSpring`；`MiuixGlassMotion`（弹层/对话框 spring 与时长表）。

→ 结论：**按其规范落地自研转场构建器**（不引第三方转场包、不沿用 material_ui 默认动效）。

### 2.2 主方案：`MiuixPageTransitionsBuilder`

新增 `lib/theme/miuix_page_transitions.dart`；动效参数全部取自 `MiuixMotion`。
**关键不变量：所有缩放 ≤ 1.0 且锚点 `Alignment.topCenter`** —— 绘制范围恒不超出路由视口，
结构上不可能覆盖标题条；且顶边始终贴合内容区上缘，转场期间标题条正下方不出现缝隙/背景色环。

| 角色 | 动画（进场缓出 / 退场缓入） |
| --- | --- |
| 进场新页 | `opacity 0→1`（前 45% 完成）+ `scale 0.94→1.0` |
| 被覆盖旧页 | `scale 1.0→0.96`（无淡出），pop 后回弹复原 |
| 退场弹出页 | 曲线反向：`opacity 1→0` + `scale 1.0→0.94` |

- 时长 `300ms`（与替换前观感一致，`kMiuixPageTransitionDuration` 可调）；
- 注册（`app_theme.dart` 浅/深两处 `ThemeData`）：windows/linux/android/fuchsia → Miuix；
  **iOS/macOS 显式保留 Cupertino**（侧滑返回手势语义不被破坏，不依赖上传兜底表）；
- 影响面：全部 `MaterialPageRoute`（112 处调用点自动生效）；`showDialog` 等 `PopupRoute` 不经过
  该 builder，弹窗/极验覆盖层动效不变。

### 2.3 兜底备用（用户确认：双层）

1. **配置层一键回退**：`kUseMiuixPageTransitions`（默认 true）——置 false 即回退 material_ui 默认
   转场，无需改结构；
2. **渲染层物理防线**：壳层内容区 `Expanded(child: ClipRect(child: widget.child))` —— 语义等价于
   恢复"系统原生标题栏时代"的客户区边界（当时 Flutter 视图不含标题栏，内容物理上画不进去）；
   任何转场/浮层越界绘制均不得覆盖标题条。

### 2.4 取舍与备选

- 备选 1（未采用）：仅加 `ClipRect`、不动转场——观感零变化，但不满足"改用 Miuix 转场"的诉求；
- 备选 2（未采用）：仅换转场、不加裁剪——将来任何溢出型转场/浮层会再次污染标题条；
- 采用：**换转场（治本）+ 裁剪（兜底）**，两层叠加。

## 八、补充轮（2026-10-07 实机反馈：当前页不加特效 + 转场卡顿优化）

### 8.1 反馈

1. **不要对"当前页"（被覆盖的旧页）加任何转场特效，只给新页加**；
2. 当前转场过渡**视觉帧率低、性能不好**。

### 8.2 根因（每帧合成开销）

| 层 | 旧实现 | 开销 |
| --- | --- | --- |
| **被覆盖的当前页** | `ScaleTransition 1.0→0.96` | 整页（含视频页的 **D3D11 外部纹理**、弹幕画布）**每帧缩放重采样** → 掉帧主因 |
| 新页 | `ScaleTransition 0.94→1.0` + `FadeTransition` | 缩放使新页每帧按新比例**重新光栅化**（含纹理），另叠一个透明度层 |

即一帧内叠了 **2 个全屏变换层 + 1 个透明度层**，其中纹理路径（FVP/mdk 解码表面）代价最高。

### 8.3 处置（转场核重构）

- **被覆盖页完全静止**：转场核不再读取 `secondaryAnimation`（并用注释明确"勿再补回"），
  当前页零变换、零透明度层；
- **新页改为「淡入 + 轻微上移」**：位移 2%（≈16px@800 高），**彻底不做缩放**——
  纯平移只是图层偏移，不触发重光栅化/过滤采样；
- 淡入窗口 0.45 → **0.4**：缩短"双页混合"时间窗，降低填充率压力；
- 不变量保持：位移在视口内 + 壳层 `ClipRect` 物理防线 ⇒ 标题条仍不可能被覆盖。
