## 一、现象

设置页「显示托盘图标」「退出时最小化到托盘」两项**开/关均无任何效果**：

- 托盘图标从不出现（任务栏通知区无图标）；
- 开启「退出时最小化到托盘」后点关闭按钮，程序仍直接退出。

## 二、定因

沿"设置写入端 ↔ 读取消费端"逐层核对：

1. 两项属调查中的 **A 类断裂**——只有 `SettingBoxKey.showTrayIcon` / `minimizeOnExit` 常量 + 设置页 `setKey`，`storage_pref.dart` **连 `Pref` getter 都没有**；
2. 全库 `grep` 确认 **无任何托盘实现**：`pubspec.yaml` 无 `tray_manager` 等依赖，`windows/runner` 无 `Shell_NotifyIcon` 调用。

即：WinWin 桌面化改造时，PiliPlus 设置页骨架被搬过来，但"桌面系统托盘"这一整个消费端从未落地。

## 三、方案（按 CVO 决策：纯原生）

> 决策依据：CVO 明确「托盘纯原生实现」，不引入第三方包。

**原生侧（C++）**
- 新增 `windows/runner/tray_icon.{h,cc}`：封装 `Shell_NotifyIconW`，消息宿主复用主窗口 `HWND`，`uCallbackMessage = WM_WINWIN_TRAY (WM_APP+1)`；右键弹 `TrackPopupMenu`（显示主窗口 / 退出 WinWin）；已显示时走 `NIM_MODIFY` 防幽灵图标。
- `windows/runner/flutter_window.{h,cpp}`：注册 `winwin/tray` MethodChannel（`setTrayVisible` / `isTrayVisible`）；`MessageHandler` 转发 `WM_WINWIN_TRAY`；`OnDestroy` 清理托盘。
- `windows/runner/CMakeLists.txt`：加入 `tray_icon.cc`。

**Dart 侧**
- 新增 `lib/core/window/native_tray.dart`：`MethodChannel('winwin/tray')` 桥，接收原生 `onTrayEvent("show"/"exit")`。
- 新增 `lib/core/window/tray_controller.dart`：`init()` 按 `Pref.showTrayIcon` 建/销图标；`refresh()` 供设置热生效；`isReallyExiting` 供关闭逻辑判断。
- `lib/core/storage/storage_pref.dart`：补 `showTrayIcon` / `minimizeOnExit` getter。
- `lib/main.dart`：`WindowStateController.startListening()` 后 `TrayController.instance.init()`。
- `lib/core/window/window_state_controller.dart`：`startListening` 加 `setPreventClose(true)`；`onWindowClose` 拦截——托盘可用则 `hide()`，否则 `destroy()`。
- `lib/pages/setting/models/style_settings.dart`：「显示托盘图标」改热生效（`onChanged → TrayController.refresh()`），去掉 `needReboot`。

## 六、遗留与踩坑

**构建踩坑（2 个，已解）**
1. 沙箱 shell 缺 `ProgramFiles(x86)` → `flutter build windows` 报 `%PROGRAMFILES(X86)% environment variable not found.` 并非代码问题；解法：构建前 `env` 补齐 `LOCALAPPDATA/APPDATA/USERPROFILE/ProgramFiles(x86)/HOME`（同 `flutter test` 已知解法）。
2. `flutter_window.cpp` 用 `IDI_APP_ICON` 但未包含 `resource.h` → `error C2065: 未声明的标识符`；解法：补 `#include "resource.h"`（`tray_icon.cc` 已含）。**注意：C++ 侧 MSVC 报错信息经 GBK 输出为乱码，需结合行号定位。**

**遗留**
1. 托盘图标按 `SM_CXSMICON` 加载；高 DPI 多屏下的图标清晰度需实机确认。
2. 「托盘隐藏」是否等同「窗口最小化」，需在**批次 4**（后台播放 / 暂停时最小化）统一口径。
3. 非 Windows 平台（未来）`setVisible` 静默降级，尚无对应托盘方案。
