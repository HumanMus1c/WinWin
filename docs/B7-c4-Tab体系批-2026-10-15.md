## 一、现象描述

`material_ui` 库级退役进入收尾后，**Tab 体系**是 lib 内最后一批仍有真实 Material 专有符号的 UI 控件族之一。实测（真实 `Tab` API 命中，非字符串/注释假阳性）共 **6 个文件**：

| 文件 | 原用法 | 落位形态 |
|---|---|---|
| `lib/pages/dynamics/view.dart` | `TabController` + `AppScaffold(topBar: TabBar)` + `body: TabBarView`；4 tab（全部/视频/追番/专栏） | 头、体分落两槽位 |
| `lib/pages/search/search_result_page.dart` | `TabController` + `topBar: TabBar`（`isScrollable`）+ `body: TabBarView`；N=`SearchType.values` | 头、体分落两槽位 |

## 二、问题根因

- 项目 UI 唯一风格为 **Miuix**，而 `TabBar` / `TabBarView` / `TabController` 是 Material 专有符号；**flutter_miuix 1.3.0 只提供 `MiuixTabRow`（胶囊分段控件）**，没有配套的内容 View，也没有等价于 `TabController` 的共享控制器——即"头"与"体"必须自行绑定同一选中态。
- 因库层无配套件，各页只能直引 Material 三元组，形成对 `material_ui` 的**结构性依赖**：只要这些文件还用 Tab，就无法摘除该 import。
- 落位形态**不统一**（topBar 槽 / SliverPersistentHeader / Column 内嵌三种），因此**单个合成控件无法一次性替换**——这是本批设计的核心约束。

## 三、修复方法

### 1. 新增通用替身 `lib/ui/components/app_tab_view.dart`（246 行，零 material_ui 依赖）

拆成**两个可独立落位的部件 + 一个共享控制器**（对位 Material 的 `TabBar`/`TabBarView`/`TabController`）：

- **`AppTabController extends ChangeNotifier`**：取代 `TabController`，只保留项目实际用到的表面——`length` / `index` / `animateTo(int)`；另有内部 `_setIndexFromView`（主体滑动回写，不触发主体再动画）。刻意**不接受 `vsync`**（用 `PageView` 而非 `AnimationController` 驱动），因此各处 `*TickerProviderStateMixin` 均可拆除。
- **`AppTabBar`**：头部标签栏，薄封装 `MiuixTabRow`（`ListenableBuilder` 监听控制器；点击经 `controller.animateTo` 驱动主体切页）；额外暴露 `preferredHeight`（=`height ?? MiuixTabRowDefaults.tabRowHeight`=42），供 Sliver 委托取固定 extent。
- **`AppTabBody`**：主体内容，薄封装 `PageView`（保留原有左右滑动切换语义）；监听控制器做 `animateToPage`，手势滑动经 `onPageChanged` 回写控制器；以 `_animating` 守卫抑制程序化动画途中的中间页回报，避免头部指示器来回跳。
- **`AppTabView`**：`AppTabBar + Expanded(AppTabBody)` 的纵向便捷组合（头体直接上下并列时使用）。

### 2. 六文件迁移

- 控制器：`TabController(length: n, vsync: this)` → `AppTabController(length: n)`；成员空间 `_syncTabController` 重建路径同步为 `AppTabController(length: tabs.length, initialIndex: oldIndex.clamp(...))`，`_pendingDisposeControllers` 类型同步（`ChangeNotifier.dispose` 语义不变）。
- 头部：`TabBar(...)` → `AppTabBar(controller:, tabs: <String>)`；**原下划线样式参数（`labelColor`/`indicatorColor`/`indicatorSize`/`dividerHeight`/`labelPadding`/`isScrollable`/`tabAlignment`）按方案 A 收敛为 Miuix 胶囊口径**（观感演进，见 §五）。
- 主体：`TabBarView(...)` → `AppTabBody(...)`，`KeyedSubtree(key: ValueKey(t))` 包裹保持不变。
- **两个 Sliver 委托**（`member_space_page.dart::_SliverAppBarDelegate`、`bangumi_player_page.dart::_SliverTabBarDelegate`）：字段 `TabBar` → `AppTabBar`，`minExtent/maxExtent` 由 `tabBar.preferredSize.height` 改 `tabBar.preferredHeight`（TabBar 默认含分隔线高度，42 为头部净高，差异须实机核对）。
- 拆除 4 处已无用的 ticker mixin：`dynamics`/`search_result`/`danmaku_block` 的 `SingleTickerProviderStateMixin`、`member_space`/`bangumi_player` 的 `TickerProviderStateMixin`、`video/detail` 混入列表中的 `SingleTickerProviderStateMixin`。
- `video/detail_page.dart::_buildRightColumn` 顺带移除因样式参数消失而失效的局部变量 `tokens`。
