# B7-b2 补丁：发送按钮紧凑口径 — 2026-10-10

> 承接 `docs/B7-b2-按钮族全量Miuix化-2026-10-10.md`（`d000a5e`）：
> 发送类按钮的观感尺寸问题（实机反馈，含直播间裁切截图）。

## 1. 现象描述

Miuix 化后各"发送"按钮相对低矮输入条**过大**，视觉不和谐；**直播间的互动发送
按钮甚至被容器裁切**（截图实锤：按钮上下越出输入条）。

## 2. 根因

- `AppPrimaryButton` 原为 Miuix 默认尺寸直通：`minHeight 40` + `insideMargin 16×13`
  → 内容高约 46–50px；
- 各发送栏高度远低于此：评论输入条 ≈34px、弹幕内联条 ≈40px、直播间为
  `SizedBox(height: barItemHeight = 40)` **紧约束**——按钮内容溢出，被外层容器裁切。

## 3. 修复方案

- `AppPrimaryButton` 扩展**可选** `minWidth / minHeight / insideMargin / cornerRadius`
  透传（null = Miuix 默认，其它调用点不受影响）；
- 五处发送键按各自栏高收敛：

| 站点 | 参数 |
|---|---|
| 评论文输入条（comment_input_bar） | 56 / 34 / (14, 6) / 圆角 10 |
| 番剧播放页评论条 | 56 / 34 / (14, 6) / 圆角 10 |
| 直播间互动发送（40 紧约束） | 64 / 40 / (12, 8) / **圆角 20**（还原设计注记"同款 20px 圆角"） |
| 弹幕面板-内联发送 | 60 / 36 / (14, 7) / 圆角 10 |
| 弹幕面板-全宽发送（48px 槽） | 仅内边距 (16, 10)（其余默认，48 内不再溢出） |
