# 上游采纳批次 A：数据正确性与观看进度（2026-11-05）

> 口径：PiliPlus 基线 `bb2d86ca2`（2026-10-15）→ `c7ff9683c`；BiliPai 基线 `70a6eeccb`（2026-10-11）→ `4f32bba`。本轮只落地「改动小、线上可感知」的数据正确性项。

## 一、现象

1. 用户选择 Akamai CDN 时，播放地址被改写为其它宿主，原签名（`hdnts`）失效，表现为 403 / 播放失败。
2. 画质列表缺少 `129 HDR Vivid`、`100 智能修复`、`6 240P 极速`，接口下发这些 code 时设置页与标签显示「未知 (xxx)」。
3. 搜索请求未带 PC UA，更易触发风控；服务端下发 `v_voucher` 时只透出原始 message，无可读提示。
4. 推荐流反复推送已看过的视频：观看进度只走心跳，`/x/v2/history/report` 调用不完整（无 duration、看完不报 -1），心跳也缺时长/最大进度字段。
5. DRM 番剧解析失败时只返回笼统错误信息。

## 二、定因与上游依据

| 项 | 上游提交 | 定因 |
|---|---|---|
| Akamai 403 | PiliPlus `5b33aa18a` | `CdnPolicy` 对官方镜像无条件替换宿主；Akamai 地址自带签名，换宿主即签名错误 |
| 画质缺失 | PiliPlus `936072449` | 画质表未收录 100/129/6 三档 |
| 搜索风控 | PiliPlus `9f8f49a87` | `searchByType` 只带 origin/referer，缺 `user-agent` |
| 已看过重复推荐 | BiliPai `c8292ffd6` | 官方以 `history/report` 为「已看过」主信号；本项此前只在结束/退出时上报且始终传 0，心跳缺 `video_duration`/`last_play_progress_time`/`max_play_progress_time`/`session` |
| DRM 提示 | PiliPlus `979b06418` | WinWin 已直接使用上游定义的 fallback 端点（`/pgc/player/web/v2/playurl`），无更旧端点可降级；仅补 `arc.is_drm` 明确提示 |

## 三、方案（逐文件）

- `lib/core/policy/cdn_policy.dart`：`resolveAllUrls` 新增 Akamai 早退分支——当偏好为 Akamai 且未开启「音频不改写」时，仅返回 host 精确匹配 `upos-hz-mirrorakam.akamaized.net` 的原始 URL；无匹配则原样返回列表。
- `lib/pages/setting/models/video_settings.dart`：画质表补 `(129, HDR Vivid)`、`(100, 智能修复)`、`(6, 240P 极速)`。
- `lib/http/search.dart`：`searchByType` 增加 `user-agent: BrowserUa.pc`；`data.v_voucher` 非空时返回「触发风控，请稍后重试」。
- `lib/http/video.dart`：
  - `heartBeat` 新增 `startTsSec/videoDurationSec/lastProgressSec/maxProgressSec/session` 参数并按官方口径写入表单；
  - `reportHistory` 重写为 `progressMs + durationMs + startTsSec + scene` 契约，字段补 `source/duration/type/device_ts/start_ts/scene`，剩最后 5 秒上报 `progress=-1`，时长未知直接跳过。
- `lib/pages/video/player_controller.dart`：
  - 新增会话状态：`_heartbeatSessionStartTs`、`_maxPlayProgressSec`、`_lastReportedHistoryMs`、`_historyReportFinished`，`_startHeartBeat` 时重置；
  - 心跳与暂停事件带会话起点、时长、最大进度；
  - 新增 `_reportHistoryProgress`：暂停/退出/切集/播完统一入口，进度变化 ≤1 秒去重、看完只报一次；
  - 播放结束与 `reportCurrentProgress` 改用该入口。
- `lib/http/pgc.dart`：`video_info` 缺失且 `result.arc.is_drm == true` 时返回「该内容受 DRM 版权保护，当前版本暂不支持播放」。

## 六、遗留与踩坑

1. **DRM 回退不适用**：WinWin 原本就调用上游的 fallback 端点（`/pgc/player/web/v2/playurl`），不存在可再降级的旧接口，因此 `979b06418` 只落地「DRM 明确提示」；若未来切到 `/ogv/player/playview` 主端点，再补 `fallback=true` 重试链路。
2. **搜索风控轮询未移植**：上游 `2d78923a9` 的 loading/定时器依赖 `SmartDialog` 宿主，WinWin 无对应体系，只做 `v_voucher` 文案提示。
3. **心跳字段未全量补齐**：`total_time/actual_played_time/realtime/dt/outer` 暂未加，避免与服务端既有统计口径冲突；现有 `real_time` 保留。
4. **观看进度上报仅 UGC**：`history/report` 需要 aid，番剧/课堂暂不参与（与上游主信号一致）；若需番剧也进入「已看过」需另评估 epid 场景。
5. **暂停上报时机**：复用心跳 5s 定时器的状态变化分支（非播放器事件即时回调，最长延迟 5s），与现有心跳体系保持一致。
