# 视频详情页滚动条隔离带与简介展开复盘（2026-11-02）

轮次：详情页布局收口（非退役批次，闸门 0→0）
改动文件：`lib/pages/video/detail_page.dart`、
`lib/common/widgets/comment/comment_input_bar.dart`

## 一、现象

视频详情页宽屏双栏布局存在三处观感问题：

1. 左栏滚动条贴着左栏右缘绘制，且离信息卡片只有 8px（`Style.cardSpace`），
   滚动条通道（12px）实际压住卡片右缘 4px；左右两栏之间也没有独立留白，
   滚动条视觉上直接贴住右栏内容。
2. 播放器画面与弹幕发送栏横向撑满左栏，左侧直接贴窗口/页面边框，与下方的
   圆角信息卡片不齐平。
3. 右栏评论区底部的评论发送栏横向撑满整个右栏，与评论卡片不等宽，且沿用
   「顶部 0.5 描边 + 直角」的贴底条形态；用户要求改为与卡片同宽、左上/右上
   圆角。
4. 简介卡片默认只显示 3 行，点击简介文本或「展开/收起」按钮才能切换；
   用户要求禁用点击展开并移除按钮行，所有视频简介默认完整展开。

## 二、定因

- 左栏 `CustomScrollView` 的视口宽度等于整个左栏宽度，全局 `AppScrollBar`
  的通道固定覆盖视口最右侧 12px；卡片 `SliverPadding` 右内边距只有 8px，
  通道必然压住卡片 4px。双栏 `Row` 中两栏直接相邻，没有为滚动条预留任何
  独立空间。
- `VideoHeader` 直接作为 sliver 放入 `CustomScrollView`，没有横向
  `SliverPadding`；播放器高度又按整个视口宽度乘 9/16 计算，因此视频天然
  从页面左缘铺到左栏右缘。
- 评论发送栏沿用共享 `CommentInputBar` 的默认「贴底条」容器：水平内边距
  直接写在容器内部、容器横向撑满父级，且装饰是「surface 底 + 仅顶部
  0.5px 描边」。非均匀边框（只有 top）与 `borderRadius` 在 Flutter 中会触发
  「A borderRadius can only be given on borders with uniform colors」断言，
  所以原实现无法直接圆角化。
- 简介卡片有 `_descExpanded` 状态、`maxLines: 3`、`MiuixPressable` 点击区和
  `MiuixTextButton` 展开按钮，属于三处联动 UI。

## 三、方案

| 项 | 改动 | 说明 |
|---|---|---|
| 滚动条通道 | 新增 `kDetailScrollBarLane = AppScrollBar.laneThickness + Style.xs`（16px），左栏所有内容（视频、弹幕条、信息/简介/标签/评论）右内边距统一改为该值 | 滚动条仍绘制在视口最右侧 12px，但完全落在 16px 留白内，不再覆盖卡片 |
| 双栏隔离带 | `Row` 的两栏之间插入 `SizedBox(width: kDetailColumnGutter)`（8px） | 左栏通道 + 隔离带形成连续留白，滚动条不贴右栏内容 |
| 视频/弹幕条内边距 | 新增 `kDetailContentPadding`（左 `Style.safeSpace` 12 / 右 16），`VideoHeader` 与 `SendDanmakuPanel` 外套同一 `SliverPadding` | 视频左侧不再贴页面边框，并与下方卡片左缘对齐；右缘让位滚动条 |
| 播放器高度 | `maxExtent` 改为「左栏宽度 − 水平内边距」× 9/16 | 保证 16:9 画面按内缩后的实际宽度计算，不出现上下黑边 |
| 评论发送栏 | `CommentInputBar` 新增可选 `borderRadius`；详情页按所在列表内边距（右栏 8/12、窄屏 12/16）外包 `Padding`，并传顶部圆角 12 | 发送栏容器宽度与评论卡片一致；指定圆角时去掉仅顶部描边（规避非均匀边框断言），按卡片口径呈现 |
| 简介 | 删除 `_descExpanded`、`MiuixPressable` 点击区、「展开/收起」按钮与 `maxLines` | 简介始终完整展开，文本本身不可点击 |

## 五、遗留与踩坑

- `CommentInputBar` 圆角模式**不能再保留仅顶部描边**：Flutter 对「非均匀
  `Border` + 非零 `borderRadius`」直接断言失败。当前圆角模式使用 `surface`
  纯色底、无描边；深色主题下 `surface` 与 `background` 同为 `0xFF131316`，
  圆角轮廓对比度很低，若实机观感不足，可再评估给发送栏换
  `surfaceContainer` 或补同色系描边（需另行确认，不与本轮一起改）。
- 本轮把视频内缩后，视频顶部仍与页面顶端齐平（只加左右内边距，未加顶部
  内边距）；若希望四边都像卡片一样留白/圆角，可再开一轮调整。
- 窄屏单列布局同步采用了「左 12 / 右 16」内边距，滚动条同样不再压卡片；
  但窄屏没有双栏隔离带（`appendRelated` 时不插入 `SizedBox`）。
- 全屏 / 应用内全屏布局不经过 `_buildLeftColumn`，本轮改动不影响全屏播放器。
- 构建前结束用户正在运行的 Release 实例属于 AGENTS 规则 5 的自动动作；
  本轮已按 PID 关闭 `17232`，再编译、再启动 `21996`。

## 六、总结

详情页左栏为滚动条让出 16px 独立通道，双栏之间增加 8px 隔离带；视频与弹幕
条统一按卡片口径内缩，播放器高度随实际画面宽度重算；评论发送栏与评论卡片
等宽并顶部圆角；简介默认完整展开且不再可点击/无展开按钮。静态分析、全量
测试与 Windows debug/release 双编译均通过。
