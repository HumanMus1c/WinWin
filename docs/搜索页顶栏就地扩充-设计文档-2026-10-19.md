# 搜索页顶栏就地扩充 — 设计文档 v3

> 一句话：**把"搜索"从单独一页，改成首页顶栏原地"往上长高一块"，长出来的地方放搜索历史和热搜。**
> v2 变更（按 CVO 4 条修正）：①提交即进结果页；②搜索态沿用首页滚动 + 压暗背景；③全文改白话；④顶栏扩充设最大高度、超出则末尾缩略。
> v3 定案（CVO）：①搜索态**把首页"首页"标题行一起压暗**（需要）；②上游"搜索发现（rcmd）/历史导入导出"**本期不做**。

---

## 一、我们到底要做什么（白话版）

**以前**：点首页顶栏的搜索框 → 跳到"另一个页面"去搜（二级页面）。
**现在**：点首页顶栏的搜索框 → **哪也不去**，就在这个顶栏上把它**长高一点**，长出来的地方显示"搜索历史"和"热搜"。

几个容易搞混的点，先说清楚：

1. **长高的是"整块顶栏"，不是那一行搜索框。**
   搜索框那一行（圆角输入条）**高度一直是 38，不变**；变的是它外面那层毛玻璃顶栏容器的高度。
2. **展开时，首页那排分类标签（推荐 / 关注 / 热门 / 番剧 / 直播）先收起来。**
   收起搜索态时，它们原样回来（位置和当前选中项都不变）。
3. **输入词后，点"搜索"按钮或直接回车 → 直接进搜索结果页**（搜索态随之收起）。
4. **长出来的地方不能顶出屏幕。** 先给它一个"最大高度"上限；万一内容真的太多装不下，就把**排在最后面的内容压缩/省略掉**（不是让它溢出屏幕，也不是硬塞滚动条）。
5. **顶栏把后面的内容压暗**（加一层半透明暗色遮罩）——**连首页最上面那条"首页"标题行一起压暗**；点这层暗色就能收起搜索态。
6. **搜索态沿用首页本来那套滚动**（就是首页顶栏/底栏随滚动收起的那套），不另做一套滚动。
7. **搜索历史里的"词"和"点过的用户胶囊"两条都要原样保留，一个都不丢。**（详见 §七）

## 二、现状（现在是什么样）

### 2.1 首页顶栏 —— 要改的地方

文件：`lib/ui/home/home_page.dart`

- 顶栏是浮在首页内容上方的一层毛玻璃（材质来自 `AppTopBarSurface`，全项目只有这一处定义，消息中心也共用）。
- 顶栏里从上到下是两块：
  - **第一行：搜索框**，高 38 的圆角条，左边一个搜索图标，文案"搜索视频、UP主..."；右边一个设置按钮。
    **现在的动作是：点它 → 跳到搜索页面（`Navigator.push(SearchPage)`）。← 就是要改掉这行。**
  - **第二行：分类标签**，高 32，5 个胶囊（推荐/关注/热门/番剧/直播）。

### 2.2 搜索页（现在的二级页面）

文件：`lib/pages/search/search_page.dart`

- 顶部一行搜索框 + 返回键 + "搜索"按钮。
- 下面依次是：搜索历史（词胶囊，可删）→ 点过的用户胶囊（头像 + 名字，点进空间、长按删）→ "大家都在搜"（热搜，**旧排版：带 1/2/3 序号的三行列表**）。
- 演示模式下用骨架占位（不跑真实数据）。

**注意**：这页现在的热搜是"序号 + 标题 + 推荐理由"的列表；**上游已经把热搜的排版重新设计过**，本次要换成上游那版（见 §三）。

### 2.3 数据存哪（本次**只换显示位置，数据一点不动**）

| 数据 | 文件 | 存在哪 | 规矩 |
|------|------|--------|------|
| 搜索历史**词** | `search_history_service.dart` → `SearchKeywordHistory` | 本地缓存键 `searchHistory` | 最多 20 条，重复的提到最前 |
| 点过的**用户胶囊** | 同上 → `SearchHistoryService` | 本地缓存键 `searchHistoryUsers` | 最多 20 个，存 `mid/name/face/timestamp`，重复的提到最前 |

## 三、参考：热搜的新排版（上游已重设计，照抄思路）

来源：PiliPlus 的 `lib/pages/search/widgets/hot_keyword.dart`

白话翻译：

- **两列小格子**：一行摆两个，左右格子间距 5，上下行间距 0.4。
- **每个格子里**：先是关键词名字（14 号字，太长就省略号），名字后面**最多跟一样东西**，按顺序：
  - 如果有图标 → 跟一个小图标（高 15）；
  - 否则如果是直播 → 跟一个"直播"小标（48×15）；
  - 否则如果有推荐理由 → 跟一段小字（灰色）。
- **不再显示 1/2/3 序号**（和现在不一样）。
- **顶上一行标题**："大家都在搜" + "完整榜单 ›" + "刷新"按钮。

> 搬过来时要做"去 Material 化"：上游用的 `InkWell` 换成项目的 `MiuixPressable`，颜色从项目的 `AppThemeHost.colors` 取（本项目应用侧已零 Material 消费）。
> 热搜数据模型要多解析两个字段：`show_name`（名字）和 `show_live_icon`（是否直播）。

## 四、改造后的样子（线框图）

**常态（没在搜索）：**

```
┌────────────────────────────────────────────┐
│ 首页                        ← AppScaffold 标题行（随滚动收起）
├────────────────────────────────────────────┤
│ ┌────────────────────────────────────────┐ │
│ │ ⌕ 搜索视频、UP主...                 ⚙ │ │  第一行 搜索框（38，不变）
│ │ (推荐) 关注 热门 番剧 直播             │ │  第二行 分类标签（32）
│ └────────────────────────────────────────┘ │
│  首页内容（推荐流等）                       │
└────────────────────────────────────────────┘
```

**搜索态（顶栏就地长高；分类标签收起；搜索框行不变）：**

```
┌────────────────────────────────────────────┐
│ 首页                        ← 标题行（一起压暗）
├────────────────────────────────────────────┤
│ ┌────────────────────────────────────────┐ │
│ │ ⌕ 搜索视频、UP主...                 ✕ ⚙ │ │  第一行 搜索框（38，不变）
│ │ ┌──────── 长出来的一块（≤ 屏幕高度）──┐ │ │
│ │ │ 搜索历史                         🗑 │ │ │  ← 标题 + 清空
│ │ │ (词A ✕)(词B ✕)(词C ✕) …            │ │ │  ← 历史词胶囊
│ │ │ (◉用户A)(◉用户B) …                 │ │ │  ← 点过的用户胶囊（一个不丢）
│ │ │ 大家都在搜        完整榜单 ›    ⟳ │ │ │  ← 热搜标题行
│ │ │  词A  🔥        词B  ·理由          │ │ │  ← 两列网格（上游新排版，无序号）

│ │ └────────────────────────────────────┘ │ │
│ └────────────────────────────────────────┘ │
│ ░░░░░░░ 半透明暗色遮罩（点一下收起搜索态）░░ │
│  首页内容（被压暗）                          │
└────────────────────────────────────────────┘
```

- **输入非空时**：长出来的那块换成"搜索联想建议"（和现在搜索页一致），历史/热搜暂时藏起来。

## 五、怎么操作（交互流程）

| 你做什么 | 结果 |
|----------|------|
| 点首页搜索框 | 进入搜索态：顶栏长高、分类标签收起、自动聚焦、背景压暗、加载历史 + 热搜 |
| 输入词 + 点"搜索"/回车 | 保存到历史 → **收起搜索态 → 进搜索结果页** |
| 点历史词 / 点热搜词 | 保存/置顶历史 → 进搜索结果页 |
| 点用户胶囊 | 进该用户空间（`MemberSpacePage`） |
| 点历史词上的 ✕ | 删掉这条历史 |
| 长按用户胶囊 | 删掉这个用户 |
| 点"清空" | 清空历史词 + 点过的用户（和现在一样） |
| 按 `Esc` / 点暗色遮罩 / 点返回 | 收起搜索态（`Esc` 先取消输入焦点，再收起；恢复分类标签） |

## 六、两条硬约束（本次重点）

### 6.1 滚动：沿用首页那套，不另做

- 搜索态的滚动**继续用首页原来的滚动与联动机制**（顶栏/底栏随滚动的那套，`AppScrollBehavior` + `MainLayout` 的联动）。
- 搜索态展开的顶栏**浮在内容上方**，它后面就是首页内容（**含顶部"首页"标题行**）——**一起压暗**（加一层半透明暗色遮罩，点击遮罩收起）。

### 6.2 高度上限 + 末尾缩略（不允许顶出屏幕）

- 给长出来的那块设一个**最大高度**：不能超过**当前窗口可用高度**（要避开系统标题栏/安全区，留一点边距）。
- **优先级**：先显示"搜索历史"，再显示"热搜"。
- 如果内容加起来**真的超过这个上限**：**把排在末尾的内容缩略/省略**（比如热搜只显示得下的那几行），**不允许溢出屏幕，也不靠滚动条硬塞**。
- 简言之：**宁可少显示最后几条，也不能长出屏幕。**

## 七、历史与用户胶囊：一个都不丢（硬性契约）

CVO 原话："直接从历史搜索访问的用户胶囊需要和搜索历史词要完整继承和保留。"
本次**只换显示的位置**（从二级页挪到顶栏长出来的那块），**数据的读/写/去重/上限/顺序全部照旧**。

| 项目 | 改造前 | 改造后（要求） |
|------|--------|----------------|
| 历史词存储键 | `searchHistory` | 不变 |
| 历史词最多 | 20 | 不变 |
| 历史词去重/提到最前 | 有 | 不变 |
| 用户胶囊存储键 | `searchHistoryUsers` | 不变 |
| 用户胶囊最多 | 20 | 不变 |
| 用户胶囊字段 | `mid/name/face/timestamp` | **四个字段一个不丢** |
| 点用户胶囊 | 进空间 | 不变 |
| 长按用户胶囊 | 删掉它 | 不变 |
| 清空 | 词 + 用户一起清 | 不变 |
| 用户从哪来 | 搜完点视频/用户卡时记录 | 不变 |

- **不用做数据迁移**：新旧用的是同一个缓存键，改造后第一次进搜索态就能看到老数据。

## 九、动画与观感

- **动画**用项目现成的顶栏节奏：`MiuixMotion.standardDecelerate`，约 220 毫秒（和首页标题行收起一个手感）。
- **搜索框行**高度 38 恒定，不参与动画。
- **分类标签**：从 32 收到 0（淡出 + 收高）。
- **遮罩**：淡入淡出，颜色取项目 `colors.scrim` 一类的暗色。
- 字号间距照上游热搜：14 号字、列间距 5、行间距 0.4。
- 新加的图标一律走 `AppIcon(AppIcons.语义方法())`，**不能加 const**。

## 十、边界与兼容

1. **演示模式**（`Pref.demoMode`）：保持现在的骨架/占位行为，**不跑真实历史/热搜**。
2. **宽屏 / 窄屏**：宽屏有侧边栏、窄屏有底栏，顶栏两种都要一致。
3. **输入焦点**：Windows 桌面进入搜索态自动聚焦；`Esc` 先取消聚焦再收起。
4. **零 Material**：新代码不许引 `material_ui`（统一 `AppIcon` / `MiuixPressable` / `AppThemeHost`）。
