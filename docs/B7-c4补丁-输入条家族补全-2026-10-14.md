## 一、现象描述

批次 1（`72516a4`）只把「视频页 / 直播页 / 专栏 / 动态」并入共享 `CommentInputBar`；底部输入条家族仍有**三处私有实现**未共享：

- **番剧页评论条**（`bangumi_player_page.dart` `_buildCommentInputBar`）：容器底色 `background`、下留白 `Style.safeSpace`、字段 `insideMargin` 为 `lg/sm` —— 与评论条口径（surface / `xs` / 默认）不一致。
- **弹幕内联条**（`send_danmaku_panel.dart` `_buildInline`）：无表情钮、额外「弹幕样式」设置钮、字段带长度格式化器与文本样式，发送键为独立私有实现。
- **私信会话输入条**（`whisper/session/chat_detail_page.dart` `_buildInputBar`）：容器底色 `background`、上/下留白 `sm`、边框 α0.4，聊天多行 + 图标式发送键。

## 二、问题根因

与批次 1 同源：`CommentInputBar` 虽已建立，但**未覆盖这三类差异场景**——缺少「附加控件槽 / 字段格式化器 / 文本样式 / 多行 / 字段填充色 / 发送键覆盖」等 hook，导致相关页面只能继续各自拼装容器骨架。

## 三、修复方法

1. 给 `CommentInputBar` 补齐 8 个可选 hook：`inputFormatters`、`textStyle`、`onChanged`、`minLines`、`maxLines`、`fillColor`、`trailing`（输入框与发送键之间的附加控件）、`sendButton`（发送键整体覆盖）。
2. **番剧页**：`_buildCommentInputBar(cs)` → `_buildCommentInputBar()`，返回 `CommentInputBar`（容器口径对齐评论条；保留回复取消 suffix）。
3. **弹幕内联条**：`_buildInline` → `CommentInputBar`（`showEmote:false` + `requireText:true` + `trailing: 弹幕样式设置钮` + `inputFormatters`/`textStyle`；`sending` 用 `ValueListenableBuilder(_sending)` 包裹）；删除随之废弃的 `_buildInlineSendButton`。
4. **私信会话条**：`_buildInputBar` → `CommentInputBar`（`showEmote:false` + 多行 1..4 + `fillColor: surfaceContainerHighest` + `sendButton: 原图标发送键`）。
5. 导入清理：番剧页移除失效 `emote_picker`、`app_components`（2 处）。
