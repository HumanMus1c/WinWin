# 收藏夹面板样式破坏修复复盘 — 2026-10-08

> 回归来源：**B4（弹窗与浮层替身）**；本修复属于 B4 的回归收口。

## 1. 现象描述

用户实机验证 B4 构建时发现：**视频互动「收藏」→「添加到收藏夹」面板样式被破坏**——

- 面板区域**大面积透明**：后面的视频画面直接透出（本应是不透明面板底色）；
- 布局塌陷：面板标题栏（× + "添加到收藏夹"）与「取消 / 完成」按钮被挤到屏幕**最底部**，
  中间的收藏夹列表（`ListView`）区域高度塌成 0。

## 2. 定因（根因链）

该面板由 `lib/pages/fav/fav_page.dart` 的 `showFavPanel()` → `showAppSheet(isScrollControlled: true)` 弹出，
内容 `_FavPanel` 的根节点是 `Column(children: [标题, Expanded(ListView), Divider, 按钮栏])`。

对照 Material 的 `showModalBottomSheet` 实现，`lib/core/shell/app_dialogs.dart` 的 `AppSheetRoute` 缺失两件事：

| # | 缺失项 | 后果 |
| --- | --- | --- |
| 1 | **表面背景**（Material 会给内容套一层 `Material`，M3 默认色 `surfaceContainerLow` + 顶部 28 圆角） | 内容透明 → 视频透出（症状 A） |
| 2 | **有界高度上限**：`isScrollControlled: true` 时 Material 给的是**整屏高度**，而替身写成了 `double.infinity` | `Column` 收到无界高度 → `Expanded` 的 flex 子项无高度可分，内容塌陷并被 `Align(bottomCenter)` 压到底部（症状 B） |

补充：非滚动受控时的上限偏 Material 默认值为 **9/16 屏高**（`scrollControlDisabledMaxHeightRatio`），
替身原写 0.9 亦属偏差（本修复一并对齐）。

## 3. 修复方案

`AppSheetRoute.buildPage` 重写为（对齐 Material 语义）：

```dart
final screenHeight = MediaQuery.sizeOf(context).height;
final maxHeight = isScrollControlled ? screenHeight : screenHeight * 9 / 16;
final sheetColor = backgroundColor ?? AppThemeHost.of(context).colors.surfaceContainerLow;
return Align(
  alignment: Alignment.bottomCenter,
  child: ConstrainedBox(
    constraints: BoxConstraints(maxHeight: maxHeight),
    child: ClipRRect(
      borderRadius: const BorderRadius.vertical(top: Radius.circular(28)),
      child: ColoredBox(color: sheetColor, child: builder(context)),
    ),
  ),
);
```

取舍说明：
- 显式传 `backgroundColor`（现有 2 处传 `Colors.transparent`：图片查看器 / 发送弹幕面板）时按传入值着色 →
  这两处行为不变；未传时按 M3 默认面板色 → 收藏夹面板等恢复不透明表面。
- 圆角/裁剪用固定 28（M3 默认）而非可配 `shape`（全库无调用点，避免过度设计）。
- **新增回归用例**（`test/core/shell/app_shell_layer_test.dart`）：以"标题 + `Expanded(ListView)` + 底栏"
  复刻面板结构，断言 `tester.takeException() == null`（无界高度会抛布局异常）且已绘制
  `surfaceContainerLow` 底色 —— 修复前该用例必失败。
