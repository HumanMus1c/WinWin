# 图标尺寸口径收敛复盘-2026-10-20

> 主题：把「图标 + 文本标签」行控件的图标尺寸**统一由相邻标签字号推导**（复用既有 `appRowIconSize` 口径），消除同排图标与标签字号不一致的观感。
> 归属：承接 2026-10-19 `docs/行式选项图标随标签字号复盘-2026-10-19.md`（当时已把该口径拉齐 9 文件 12 处），本轮为**余量收敛的第一批**。
> 方案：CVO 于 2026-10-20 拍板「**先做甲，后续继续评估乙方案**」。甲 = 只收敛「与 Text 邻接、语义等于图标+标签」的子集；乙（图标尺寸 token 表全量归位）留待后续评估。

---

## 一、现象

CVO 追问：「为什么不把**未纳入按钮内的 icon+label**，以及那些 **icon 和 label 字体大小不一致的控件**统一处理呢？」

即：`2026-10-19` 那轮只收敛了行式选项（设置行 / 菜单壳 / `AppListItem` 等 12 处）——**同一约定 `appRowIconSize` 早已存在，但覆盖不全**；大量非按钮的「图标 + 文本标签」行（评论互动行、元信息行、UP 行、各页 meta 行…）仍以**硬编码 `size:` 字面量**绘制，图标与同行标签字号脱钩。

## 二、定因（根因链）

1. **单一口径已定义**：`lib/theme/app_icons.dart:591` 的
   `double appRowIconSize(BuildContext context, [double? labelFontSize])` —— 名义取 `labelFontSize ?? headline1(17)`，再经 `MediaQuery.textScalerOf(context).scale(...)` 返回**实际渲染字号**；语义即「图标尺寸 = 该行标签字号」。约定见 `coding-conventions.md` L23「图标尺寸跟随相邻文本字号」。
2. **落地不全**：全仓（非 demo）带 `size:` 字面量的图标位点约 **220 处**（含装饰/角标/媒体叠加/空态/头像/纯图标按钮）。真正属「图标 + 文本标签」横排行者仅其中一部分，且这些位点**各自复述了一个拍脑袋的字面量**（12/13/14/15/16/18/20/24…），与同行标签字号无一致关系 ⇒ 视觉上「图标比标签大/小」。
3. **为何不并入 10-19 那轮**：10-19 那轮聚焦「行式**选项**」（继承根 `DefaultTextStyle(14)` 的菜单/设置行）；本轮是**页面正文里的** icon+label 行，位点分散、行标签字号各异，属「迁移收尾欠账」，非同一批。
4. **不能无差别统一**：装饰/角标（`video_cover_stat_badge` 11）、媒体叠加（播放/时长）、空态大图标（48/56）、头像、纯图标按钮、**竖排操作条**（`video_action_row` 图标 24 在计数 11 之上——非横向 icon+label）**不应**跟随标签字号。

## 三、方案（甲：只收敛「图标 + 文本标签」横排行）

- **口径**：`size: <字面量>` → `size: appRowIconSize(context, <该行标签名义字号>)`。
- **范围（本批「甲·第1批」= 视频详情页）**：`lib/pages/video/detail_page.dart`，**15 处**：
  - 评论互动行（点赞计数 / 点踩 / 回复 / 展开）：标签 12 → `appRowIconSize(context, 12)`；其中**点踩为独立图标**（无文本），但**与同排点赞成对**，取同行口径 12 以保持一致。
  - 元信息行（播放 / 弹幕 / 时长）：标签 `grayStyle`(12) → 12。
  - 回复项互动行（赞 / 踩 / 回复 / 展开）：标签 12 → 12。
  - 子回复互动行（赞 / 踩 / 回复）：标签 11.5 → 11.5。
  - UP 行（头像图标 + 昵称）：标签 13 → 13。
- **本批明确排除**（据实声明）：
  1. **按钮部件内部**手写 icon+label（`MiuixButton` / `AppPrimaryButton`，如「查看更多回复」「关注」「保存」——用户原话即限定「未纳入按钮内」）→ 归**后续批**；
  2. **竖排操作条** `video_action_row`（图标 24 在计数 11 之上，非横向 icon+label）；
  3. 装饰 / 角标 / 媒体叠加 / 空态 / 头像 / 纯图标按钮。

> 采用**逐部件小步**落地：本批只动 `detail_page.dart` 一个文件（不重复动同一代码），后续按「视频模块其余文件 → 番剧 → 动态+文章 → 成员空间/收藏/历史/稍后看/直播 → 按钮类」分批推进（见 §五）。

## 六、总结

- **性质**：不是 bug，是**「图标尺寸口径」这一概念落地不全**（同 P4 精神：一个概念一处定义，但消费端各自复述字面量）。甲 = 把「图标 + 文本标签」行的消费端**接回唯一口径 `appRowIconSize`**。
