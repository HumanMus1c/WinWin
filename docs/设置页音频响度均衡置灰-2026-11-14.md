# 设置页音频响度均衡置灰（2026-11-14）

## 一、现象与需求

1. 设置 →「音视频」→「音频响度均衡」仍可选择「禁用 / 智能响度均衡 (loudnorm) / 动态压缩 (dynaudnorm)」。
2. 上一轮已将播放器控制条的均衡入口替换为音质切换，该设置项成为唯一入口，但功能本身尚未达到可用标准。
3. 需求：默认值改为「禁用」；整个设置项灰色禁用、不可点击；标题文本后方加一个红色胶囊，文案「尚未实现」。

## 二、定因与背景

1. 响度均衡最初使用 FFmpeg 动态滤镜（loudnorm/dynaudnorm），需要前瞻缓冲，在实时双实例链路上会导致音频滞后甚至无声（见《音频响度均衡修复回滚复盘-2026-09-30》），现仅保留按 B 站响度元数据计算的静态增益。
2. 设置页 `NormalItem` 过去只以 `onTap == null` 判断是否可点，没有独立「禁用态」；`MiuixBasicComponent` 的 `title` 只接受字符串，也无法在标题后内嵌角标。

## 三、方案

1. **默认禁用**（[storage_pref.dart](file:///d:/Documents/GitHub/WinWin/lib/core/storage/storage_pref.dart)）：`Pref.audioNormalization` 默认值由 `'2'`（loudnorm）改为 `'0'`（禁用）。
2. **设置行禁用态与标题角标**（[normal_item.dart](file:///d:/Documents/GitHub/WinWin/lib/pages/setting/widgets/normal_item.dart)、[settings_model.dart](file:///d:/Documents/GitHub/WinWin/lib/pages/setting/models/settings_model.dart)）：
   - `NormalItem` / `NormalModel` 新增 `enabled`（默认 `true`）与 `titleTrailing`；
   - `enabled: false` 时：标题/副标题使用 Miuix 禁用色、leading 图标改用 `outline` 色、`onClick` 置空（悬停/点击均无反馈）；
   - `titleTrailing` 非空时改用 `MiuixBasicComponent.content` 自绘标题行，字号/字重/颜色解析口径与内置 title/summary 一致，标题后间隔 6px 放置角标，标题过长自动省略。
3. **设置项接线**（[video_settings.dart](file:///d:/Documents/GitHub/WinWin/lib/pages/setting/models/video_settings.dart)）：音频响度均衡项设 `enabled: false`，`titleTrailing` 复用现有 `PBadge`（红底 `#F44336` + 白字、字号 11、全圆角胶囊），文案「尚未实现」。

## 六、遗留与踩坑

1. 本次只改默认值：若旧版本中手动选过 loudnorm/dynaudnorm，Hive 中已存的 `'1'/'2'` 仍会保留（UI 已不可修改）。如需全量统一为禁用，可在后续启动迁移中重置该键。
2. `titleTrailing` 是设置行首次引入的标题内联角标能力，后续其他「未实现/实验性」设置项可直接复用。
3. 播放器侧静态增益逻辑与 `voice_balance` 请求参数保持不变；`Pref.audioNormalization == '0'` 时增益为 1.0、滤镜为空，便于功能完善后恢复。
4. Release 编译前需确认无运行中的 `winwin.exe`，否则会因 `WebView2Loader.dll` 被占用而失败。

## 七、总结

「音频响度均衡」设置项已默认「禁用」，整行置灰且不可点击，标题右侧显示红色「尚未实现」胶囊；`NormalItem` 同时获得通用禁用态与标题尾随角标能力。静态分析零问题，Windows debug/release 双编译及设置行单测均通过。
