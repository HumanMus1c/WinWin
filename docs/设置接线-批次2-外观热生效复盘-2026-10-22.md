## 一、现象

设置页三项"外观"开关/滑条**开/关均无效果**：

- 「纯黑主题」开启后深色背景仍是 `#131316`，非纯黑；
- 「字体大小」拖到 0.8x / 1.4x，界面文字大小不变；
- 「界面缩放」拖到 0.8x / 1.5x，界面整体不变。

滑动/开关后弹「重启生效」提示，但重启后亦无变化。

## 二、定因

- 三项均属调查中的 **A 类断裂**——只有 `SettingBoxKey` 常量 + 设置页写入，`storage_pref.dart` 无对应 getter，全库无消费者：
  - `isPureBlackTheme`：连 `Pref` getter 都没有；
  - `defaultTextScale`：getter 已存在但**零调用方**（B 类）；
  - `uiScale`：无 getter（A 类）。
- 壳层 `AppShell` 的 `tokensFor(brightness)` 从不感知"纯黑"；`build` 也未施加任何 `textScaler` / 整树缩放。

## 三、方案（按 CVO：整树缩放·方案 A + 热生效）

**新增通知器**
- `lib/pages/setting/appearance_notifier.dart`：`isPureBlack` / `textScale` / `uiScale` 三个 `ValueNotifier` + `refresh()`（与 `ThemeNotifier` 同模式）。

**纯黑主题**
- `app_theme_host.dart`：新增 `AppPalette.darkPureBlack`（background/surface 压 `#000000`，容器色保留层级）；`tokensFor(brightness, {pureBlack})` 在深色 + 纯黑时切换该调色板。

**字体大小（仅文字）**
- `app_shell.dart`：`build` 内以 `MediaQuery.copyWith(textScaler: TextScaler.linear(textScale))` 施加全局文字缩放。

**界面缩放（整树·方案 A）**
- `app_shell.dart`：`LayoutBuilder` 取可用尺寸 → 覆盖 `MediaQuery.size` 为 `constraints / uiScale`（让子树按缩放后的逻辑空间布局）→ 外层 `Transform.scale(scale: uiScale, alignment: topLeft)` 视觉放大；`uiScale == 1.0` 时短路不加壳。

**接线与热生效**
- `main.dart`：`WinWinApp` 由"两层 ValueListenableBuilder"改 `ListenableBuilder(listenable: Listenable.merge([...五路...]))`，把 `pureBlack/textScale/uiScale` 传给 `AppShell`；`ensureBootstrap` 与 `AgreementGate._load` 均补 `AppearanceNotifier.refresh()`。
- `storage_pref.dart`：补 `isPureBlackTheme` / `uiScale` getter。
- `style_settings.dart`：三项去 `needReboot`；纯黑走 `onChanged: AppearanceNotifier.setPureBlack`，字体/缩放 `onTap` 内回写 `AppearanceNotifier.setTextScale/setUiScale`，提示文案「重启生效」→「已生效」。

## 六、遗留与踩坑

**关键设计点（方案 A）**
1. 整树缩放**必须同时覆盖 `MediaQuery.size`**：`Transform.scale` 只改变视觉与命中测试，若不同步缩小 `MediaQuery.size`，子树仍按原始尺寸布局 → 缩放不生效/错位。这是方案 A 与"简单 `Transform.scale` 包裹"的本质区别。

**工具踩坑**
2. 同一文件在一轮内多次 `edit_file` 后，再次编辑会命中"modified externally since last read"，需先 `read_file` 再改（本批 `app_shell`/`main`/`style_settings` 多次触发）。
3. 沙箱 shell 缺 `ProgramFiles(x86)` → `flutter build windows` 报环境变量缺失（非代码问题）；沿用 `env` 补齐解法。

**遗留**
4. 缩放的极端值（0.8x / 1.5x）下的布局溢出、滚动范围、输入法候选框定位，需实机确认。
5. 纯黑主题当前只压 `background/surface`，`surfaceContainer*` 保留原色；是否进一步压黑待 CVO 视觉定夺。
6. `textScale` 与 `uiScale` 叠加（如字体 1.4x + 界面 1.5x）后的视觉上限未设钳制。
