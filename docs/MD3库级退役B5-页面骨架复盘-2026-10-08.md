## 1. 背景与目标

- 页面骨架是 MD3 的最后一块"结构性"依赖：`Scaffold`（Material 骨架）与 `AppBar`（Material 顶栏）
  决定了页面的窗口内边距、背景、顶栏质感。
- L0 已备替身 `lib/core/shell/app_scaffold.dart`（基于 flutter_miuix `MiuixScaffold`，自带
  topBar/bottomBar/FAB/snackbarHost/popupHost 槽位与窗口内边距换算，`content(EdgeInsets)` 回调）——
  **本批首次把它接入真实页面**（此前项目零使用 `MiuixScaffold`/`MiuixTopAppBar`）。
- 范围（全量）：`Scaffold(` **37 处 / 33 文件**；含 `AppBar` 的页面 **25 文件**。

映射规则（对齐语义，不追求逐字段等价）：

| Material | Miuix 替身 | 说明 |
| --- | --- | --- |
| `Scaffold(appBar:, body:, backgroundColor:, floatingActionButton:)` | `AppScaffold(topBar:, body:, backgroundColor:, floatingActionButton:)` | `body` 由 scaffold 的窗口内边距自动套 `Padding` |
| `AppBar(title: const Text('X'))` | `MiuixTopAppBar(title: 'X')` | Miuix 顶栏 `title` 为 **String** |
| `AppBar(leading: Widget)` | `MiuixTopAppBar(navigationIcon: Widget)` | 参数改名 |
| `AppBar(actions: [...])` | `MiuixTopAppBar(actions: [...])` | 同名 |
| `scrolledUnderElevation` / `elevation` | —— | Miuix 顶栏无海拔体系，直接丢弃 |
| `AppBar(bottom: TabBar(...))` | `MiuixTopAppBar(bottomContent: ...)` | 本批未涉及，留后批 |

**本批踩到并修正的两类坑**（记录备查）：
1. **跨行 `title: Text(...)`**：首轮正则只匹配单行，导致 `title:` 仍是 `Text` 组件（类型不符）→ 改为
   跨行容错正则 + 逐点人工确认；同时脚本对已改写行重复加前缀（`MiuixTopMiuixTopAppBar`）已修复。
2. **误伤对话框**：全局 `title: const Text('X')` → `title: 'X'` 也命中了 `AlertDialog(title:)`（其 `title`
   要求 Widget）→ 由 analyzer 捕获 2 处并回退为 `const Text(...)`。**教训：按"控件类型"限定的替换要
   带上父级上下文，不能只按参数名匹配。**

## 6. 补充：顶栏形态修正（大标题 → 小顶栏）

**用户抽验反馈**：「消息」页标题占据行高过高，要求与当前历史页 / 动态页的标题条高度一致。

**定因**：flutter_miuix 提供两种顶栏 ——

| 形态 | 组件 | 高度口径 | 适用 |
| --- | --- | --- | --- |
| 大标题（可折叠） | `MiuixTopAppBar` | 大标题布局，约 115px（含折叠动效） | 一级首页（Home）等 |
| **紧凑** | `MiuixSmallTopAppBar` | 居中高度 50px（`MiuixTopAppBarDefaults.smallTopAppBarCenterHeight`），参数集与大标题版基本相同（title/navigationIcon/actions/subtitle/bottomContent…，无 largeTitle 系列） | 二级页面（本次场景） |

首批**误用了大标题形态** → 消息等二级页标题条过高。

**修复**：首批 **12 处**顶栏统一换为 `MiuixSmallTopAppBar`（`import ... show MiuixSmallTopAppBar` 同步）；
B5-2 迁其余页面时**一律采用小顶栏**（除非某页设计上确需大标题）。

**验证**：`MiuixSmallTopAppBar(` = **12**，残留 `MiuixTopAppBar(` = **0**；`dart analyze` 0；
`flutter test` **164/164**；双构建 Debug 34.5s / Release 77.0s。
提交：`fe7b27b`（[fix](shell)）+ `3bb2e42`（[docs]，已推送 origin/main）。

**过程小记**：该批替换首次用正则负向后行断言（`(?<!Small)`）未生效（PS 5.1 环境差异），
改为"朴素替换 + 去重"两步后落实 —— 结论：本项目脚本尽量用 `.Replace`，需要排除时用两步替换。
