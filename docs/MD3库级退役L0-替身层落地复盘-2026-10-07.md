## 一、分析根因（为什么样式级退役后仍需库级替身）

1. 样式级退役（L1~L5，−2900 行）清掉了 M3 分支/枚举/Token/图标，但**库级 material_ui
   按 L4-0 分级结论暂缓**：`MaterialApp`/`ThemeData`/`Scaffold`/`MaterialPageRoute`/
   `showDialog` 等骨架面仍是 material 类型；
2. 直接后果之一即 Part A 的"转场溢出覆盖标题条"——平台默认转场（Zoom）从未被覆写；
3. L4-0 曾结论"库级移除=极高成本，需自建 WidgetsApp 壳…独立立项"；
   本批把该立项**拆成可独立交付的批次**，先落地替身层。

**本轮侦察（只读）结论（用于确定替身边界）**：

| 事实 | 证据 |
| --- | --- |
| flutter_miuix 依赖 **SDK 冻结 material**，不依赖 material_ui | 包内 69/107 文件 `import 'package:flutter/material.dart'`；`material_ui`=0；`cupertino_ui`=0 |
| flutter_miuix 组件**不读** Material `Theme.of` | 包内 `\bTheme\.of\(` = 0 |
| 其 SDK-material 面薄且集中 | 13 文件 44 处（`miuix_theme.dart` 22、`miuix_date_picker` 6、`popup_presenter` 2…） |
| `MiuixScaffold` 为纯 widgets 层实现 | `miuix_scaffold.dart` 仅 import `flutter/widgets.dart` + 内部文件；槽位 topBar/bottomBar/FAB/floatingToolbar/snackbarHost/popupHost |
| `WidgetsApp` 必须自带路由工厂 | SDK `widgets/app.dart` 断言"home/routes 与 pageRouteBuilder 必须同时提供" |
| 旧桥 uses Global* 本地化 | `material_ui/src/migration_utility.dart` → `flutter_localizations` |

## 二、设计修复计划（替身层设计与关键决策）

| 替身 | 决策 | 关键取舍 |
| --- | --- | --- |
| **主题通道** `AppTokens`/`AppThemeHost` | InheritedWidget 供给明暗 + `MiuixColors` + Token；未挂宿主时按平台亮度回退 | **零 material 依赖**（不采用 ThemeExtension，避免把替身绑死在 Material 类型上）；B2 分批切换 675 处读取点 |
| **转场核** `MiuixPageTransition` | 从 `theme/miuix_page_transitions.dart` 原样迁出到 `core/shell/app_transition.dart` | Material 侧 Builder 与 `AppRoute` **共用同一核**（观感一致、单一事实源）；B7 只删 Builder 文件 |
| **路由** `AppRoute` | 基于 widgets 层 `PageRouteBuilder`，内嵌转场核，300ms | 不复制 MaterialPageRoute 的其它语义（不需要）；`appPageRouteBuilder` 满足 WidgetsApp 契约 |
| **页面骨架** `AppScaffold` | 薄封装 flutter_miuix `MiuixScaffold`，背景取 Token | 不自研骨架（上游已具备槽位与窗口内边距换算）；`SimpleScaffold`（0 调用、能力缺）留待 B5 收编 |
| **对话框** `AppDialogRoute`/`AppSheetRoute` | 自建 Route，**保持 `PopupRoute` 子类型** | 让 `AppEscapeScope` 的 Esc 分层判定（`hasPopupOnTop`）零改动继续生效；barrier/返回值契约对齐 `showDialog` |
| **兼容桥** `MiuixCompat` | SDK `Theme`（由 Token 构造）+ `Localizations.override` + 透明 `Material` | 仅服务 flutter_miuix 内部 SDK TextField；无 Localizations 祖先时退化独立 `Localizations`（防断言崩溃） |
| **应用壳** `AppShell` | `WidgetsApp` + `ScrollConfiguration` + 既有 builder 链 + **显式 DefaultTextStyle** | WidgetsApp 默认文本基底是"黄绿双下划线"错误样式（项目已两次踩坑）；`ThemeMode` 由 `isDark` 取代 |
