# 消息中心会话行卡片化复盘（2026-10-20）

轮次：B8（消息中心视觉升级）
改动文件：`lib/pages/whisper/session/session_list_section.dart`（`_SessionTile`）

## 一、现象

用户要求：**将消息中心的每个对话的行控件改为现代化的圆角长条的 Miuix 卡片**。

改造前实机观感：消息页（`WhisperPage`）私信会话列表每一行是一段**无背景的透明行**
（`MiuixBasicComponent`，仅按压反馈 `none`），行与行之间只靠 12px 水平内距分隔，
视觉上是一条**无缝列表**，与项目其它已卡片化的列表（历史 `history_page.dart`、
收藏 `fav_page.dart`、动态 `dynamics/view.dart` —— 均用 `MiuixCard` 承载条目）
风格不统一。

## 二、问题根因

`_SessionTile.build` 直接返回 `MiuixBasicComponent`：

- `MiuixBasicComponent` 是 Miuix 的**基础行**组件（对应 Compose `BasicComponent`），
  本身**不带容器装饰**——无背景色、无圆角、无卡片外壳（见库源码
  `miuix_basic_component.dart`：body 只有 `Padding(insideMargin)` + `MiuixPressable(none)`）。
- 因此会话行呈现为「全宽无缝列表行」，而不是「卡片」。
- 卡片语言在本项目已是既定视觉模式（`MiuixCard` = squircle 圆角 16 +
  `surfaceContainer` 底色 + `onSurfaceContainer` 内容色），会话列表是少数未接入该模式的列表。

## 三、方案

`_SessionTile` 由 `MiuixBasicComponent` 改为 **`MiuixCard` 圆角长条卡片**：

| 项 | 取值 | 说明 |
|---|---|---|
| 卡片组件 | `MiuixCard` | 不传 `cornerRadius`，走库默认 `MiuixCardDefaults.cornerRadius`（16，squircle 圆角） |
| 卡片内距 | `EdgeInsets.symmetric(horizontal: Style.md, vertical: Style.sm)` | 12×8，长条内呼吸 |
| 卡间/出血 | 外层 `Padding` 横向 `Style.md`(12) + 纵向 `Style.xs`(4) | 左右出血让卡片从页面背景浮出；纵向 4 + 卡片无外距 = 卡间视觉 8px |
| 点击反馈 | `MiuixPressable(feedbackType: sink, sinkAmount: 0.98)` | 项目既定「整卡轻下沉微缩」，替代整卡变暗/波纹；`borderRadius` 与卡片圆角同步（`MiuixCardDefaults.cornerRadius`） |
| 行内布局 | 自绘 `Row`：头像 Stack（含未读角标）→ 12px → `Expanded(Column[姓名行, 4px, 预览行])` → 8px → `Row[时间, 更多按钮]` | 替代 `BasicComponent` 的 2:5:3 测量槽位；姓名行与预览行间距 4px |
| 保留语义 | 点击进 `showChatDetailPage`；右键 `onSecondaryTapUp` 与三点 `SessionMoreMenuButton` 共用「更多选项」；置顶/特别关注/免打扰标记；未读角标；演示模式骨架占位；`has_more` 加载更多指示器 | 控件替换不抹掉原有交互语义 |

**未采用**：`MiuixCard(onPressed:)` 直连点击 —— 该路径不暴露 `sinkAmount`，无法沿用
项目 0.98 的口径；故按既有范式（历史/收藏卡片）用 `MiuixCard` + 内层 `MiuixPressable`。

## 五、遗留与踩坑

- **范围口径**：本次只改「会话列表行」（私信对话 = 用户所述「对话」）。
  `msg_feed` 四个子页（回复我的 / 艾特我的 / 点赞我的 / 系统消息）的行控件是**消息条目**
  而非会话，未纳入本次改动；若 CVO 认为同属「消息中心的行」需一并卡片化，作为后续轮次处理。
- **卡片底色对比度**：卡片取库默认 `surfaceContainer`；若实机觉得与页面背景区分不足，
  可改用 `tokens.colors.surfaceContainerHigh` 并注释声明（本轮按「与其它列表卡片同源」处理）。
- **卡间视觉间距**：由外层纵向 4px + 卡片自身 0 外边距构成 8px 视觉间距；若实机偏挤，
  调外层纵向至 `Style.sm` 即可（单点常量，P4 单处定义）。
- **未运行 `dart format`**（项目约定禁止：既有文件有漂移，格式化会产生无关重排）。
