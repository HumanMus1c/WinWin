# 纯展示文本可选中能力补齐复盘（2026-11-05）

## 一、现象

视频标题/播放数据/简介、番剧标题/评分/元信息、评论正文、私信文本消息、直播弹幕、合集/系列头部说明、登录与 Cookie 说明、用户协议文案、关于页版本信息、下载页缓存路径等「只显示文字、本身没有交互」的区域，此前鼠标无法拖选、无法右键复制。可选中的只有少数已接入点：文章正文、动态详情、番剧简介、用户签名、视频卡片菜单里的简介。

## 二、定因与上游依据

| 位置 | 上游实现 | 结论 |
|---|---|---|
| PiliPlus | `lib/common/widgets/selection_text.dart`：`SelectionArea` 包单段 `Text`，统一 `openUrlMenuBuilder`；`pages/article/view.dart`：页面级 `SelectionArea` + `SelectionContainer.disabled` 排除交互区；`lib/scripts/text_selection.patch`、`selectable_region.patch` | 采用「区域级/块级包裹」，不做全应用根节点包裹；框架补丁只解决移动端触摸拖选与列表滚动冲突，Windows 鼠标+滚轮环境不适用，不移植 |
| BiliPai | `core/ui/common/TextSelectionHost.kt`：Compose `SelectionContainer` + 自定义 `TextToolbar`（复制/全选/分享），交互区用 `DisableSelection` 排除 | 触屏悬浮条形态不照搬；「局部容器 + 排除交互区」思路一致 |
| WinWin | 已有 `AppSelectableText`（widgets 层 `SelectableRegion` + 桌面 Handle 控件 + Miuix 右键菜单） | 缺区域级组件，只能逐个 `Text` 替换；本轮新增 `AppSelectionArea` |

- 根因：Flutter `Text` 默认不可选中；已有 `AppSelectableText` 只能包单段文本，内容区里成组的标题/元信息/说明文字没有统一入口，逐段替换成本高且跨段不能连选。
- 口径：严格按「没有交互事件」筛选——按钮、可点击卡片/行、长按删除行、标签 chip 等交互容器内的文本不纳入。

## 三、方案（逐文件）

基础设施：

- `lib/ui/components/app_selectable_text.dart`：新增 `AppSelectionArea`。直接用 widgets 层 `SelectableRegion`（等价于 material `SelectionArea` 的底层），复用 `cupertinoDesktopTextSelectionHandleControls` + `buildMiuixTextSelectionContextMenu`，支持子树内跨 `Text` 连选；不引入 `package:flutter/material.dart`，保持 material 零消费门槛。

接入（纯展示区域）：

- `lib/pages/video/detail_page.dart`：标题+播放数据子列、简介卡片、稿件加载失败卡片。
- `lib/pages/bangumi/bangumi_detail_page.dart`：标题/副标题/评分/统计整块（原 `AppSelectableText` 改回 `Text` 避免嵌套）；元信息区（风格标签/开播/声优/制作，元信息值同改回 `Text`）。
- `lib/common/widgets/comment/reply_content_view.dart`：评论正文 `Text.rich`。该组件被视频详情、番剧播放、动态详情、文章页四处共用，一次覆盖全部评论区。
- `lib/pages/whisper/session/chat_detail_page.dart`：普通文本气泡与兜底文本气泡。
- `lib/pages/live/live_room_page.dart`：主播名/房间号/分区/热度区、实时互动面板每条弹幕正文。
- `lib/pages/member/season_series_detail_page.dart`：合集/系列头部标题、视频数量、简介。
- `lib/pages/setting/about_page.dart`：品牌名、副标题、版本号。
- `lib/pages/onboarding/user_agreement_page.dart`：欢迎语与说明、底部提示、只读条款组（关于页「开源协议」入口）。
- `lib/pages/login/login_page.dart`：密码登录说明、短信登录说明、扫码状态与剩余时间、Cookie 登录说明。
- `lib/pages/download/download_page.dart`：缓存占用与存放路径。

## 六、遗留与踩坑

1. **交互容器内文本按口径未纳入**：通知/消息行（长按删除）、会话/列表卡片、标签 chip、按钮文字、私信卡片消息（可点开视频）等保持原样；若后续要「拖选与点击共存」，需逐页回归点击命中。
2. **`AppListItem` subtitle 无法单独包**：`AppListItem.subtitle` 为 `String` 并交给 Miuix 组件渲染（关于页「项目说明」），要可选需扩展组件契约（如 `subtitleWidget`），本轮未动。
3. **番剧播放页简介未改**：简介文本位于 `MiuixPressable` 展开/收起容器内（交互容器），且声优/制作已在原实现中可选。
4. **嵌套约束**：`AppSelectableText` 与 `AppSelectionArea` 都是 `SelectableRegion`。已区域化的块内部若再走 `AppSelectableText` 会形成嵌套，本轮回改为普通 `Text`（番剧标题与元信息值）。后续接入须遵守「同一块只用一层」。
5. **不移植 PiliPlus 框架补丁**：`text_selection.patch` / `selectable_region.patch` 解决的是触摸拖选与列表滚动冲突，Windows 鼠标+滚轮无此问题；且对 SDK 打补丁会破坏官方 stable 构建口径。

## 七、总结

新增区域级 `AppSelectionArea`，按「只包无交互区域」口径覆盖 11 个文件的纯展示文本；评论正文因共用 `ReplyContentView` 一次覆盖视频/番剧/动态/文章四处；交互容器与低价值空状态保持不可选。静态分析、285 项测试与 Windows 双分支构建全部通过。
