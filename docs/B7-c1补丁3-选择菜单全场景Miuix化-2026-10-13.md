# B7-c1 补丁#3 复盘：文本选择菜单全场景 Miuix 化 — 2026-10-13

> 承接补丁#2（`bb2bbff`）：复测反馈"文本选择菜单样式仍然不对"——全库排查
> 确认**范围漏网**（此前仅修专栏文章页正文单点），本补丁把全部文本选择站点
> 统一到同一套 Miuix 菜单组合。
> 快照：`7ba7a7ba207cfb303b9baa79ca0bfeca360be25b`。

## 1. 现象描述

补丁#2 后复测：文本选择右键菜单仍为默认英文工具栏（"Copy / Select all"）。
全库扫描发现：项目共有 **12 处"会产生文本选择菜单"的站点**，此前仅文章页正文
1 处完成 Miuix 化；其余 11 处（**动态详情页的 material `SelectionArea`** +
10 处 `SelectableText`：动态正文×2、番剧标题/meta/简介×3、番剧演员/制作×2、
用户空间签名/demo UID/信息行×3、视频卡封面标题×1）全部仍走各自默认工具栏。
——用户复测命中的精确站点虽未能定位（页面级无日志标签），但**范围漏网**本身
即为缺陷：选择菜单未做到"同类一次修完"。

## 2. 根因与设计

- 机制面（上轮已钉死）：两套选择体系（`SelectableRegion` 与 EditableText/
  `SelectableText`）均**仅在 selectionControls 为 Handle 版**时采用
  `contextMenuBuilder`（`text_selection.dart:471` 对 EditableText 同款实证）；
  否则回退各自默认工具栏（桌面 = 英文 "Copy/Select all"）。
- 范围面：文本选择站点分散在 5 个页面/组件、两种体系——必须全量清点统一。

## 3. 修复方案

- `miuix_context_menu.dart`：把菜单部件泛化为 `_MiuixSelectionMenu`
  （`items` / `anchor` / `onHide` 三参数），对外提供两个接入构建器：
  `buildMiuixTextSelectionContextMenu`（SelectableRegion）与
  **`buildMiuixEditableTextContextMenu`（SelectableText / EditableText）**；
- **11 处站点统一接入**（脚本机械插入；Dart 2.17+ 命名/位置参数混排合法）：
  - 动态详情页：外层 material `SelectionArea` → `SelectableRegion`
    （Handle 版 + 区域菜单）；页内 2 处 `SelectableText` 接入 EditableText 菜单；
  - 番剧详情 3 处、番剧播放页 2 处、用户空间 3 处、视频卡封面标题 1 处：
    `SelectableText` 统一加 `selectionControls:
    cupertinoDesktopTextSelectionHandleControls` +
    `contextMenuBuilder: buildMiuixEditableTextContextMenu`；
- 回归测试扩展：新增 **SelectableText 场景**（拖选 + 右键断言 Miuix 菜单、
  无默认工具栏），与既有 SelectableRegion 场景并列。

## 7. 实机复测指导

以下**任一页面**的**任一可选中文本**处右键，均应出现 Miuix 毛玻璃面板
（"文本操作" + 复制/全选，行 hover/按压反馈；Esc/点外关闭）：

1. **动态详情页**（个人动态/关注流点开一条长文动态）：正文右键；
2. **专栏文章页**：正文右键；
3. **番剧详情页**：标题 / meta 行（声优/制作）/ 简介 右键；
4. **番剧播放页**：展开"演员 / 制作人员"后右键；
5. **用户空间**：个性签名 / 基本信息栏（UID 等）右键；
6. **视频卡"查看封面"弹窗**：标题右键；
7. 全场景均**不应再出现英文 "Copy / Select all"**。
