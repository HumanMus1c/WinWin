## 一、现象描述

用户实机复验反馈轮 1 的交付后，提出 4 条：

1. 搜索结果页的全局返回按钮应放在**搜索框行的最左侧**，与上级搜索页对齐（当时返回键仍在壳层"顶部安全行"里，位于标签栏之下）。
2. Tab 栏容器存在**不必要的上下细微边框线**。
3. 用户空间顶栏的分类器按钮**收缩得太狠**，分类文本被缩略；应按"容纳进此行、均匀分布"给出每格最大尺寸。
4. 目前 Tab 栏似乎还有**额外的容器**，观感不好，请去除。

## 二、问题根因

- **R1（返回键位置）**：结果页走 `AppScaffold` 默认 `reserveTopStrip: true`，返回键由壳层安全行的 `FloatingBackButton` 渲染，落在 `topBar`（输入行+标签栏）**之下**；上级搜索页则是 `AppBar(leading: const AppBackButton(), titleSpacing: 0)`，返回键在 56 宽 leading 槽内（图标中心 x≈28）。两者不同行、不左对齐。
- **R2（细线 + 额外容器）**：两处叠加。
  - 库 `miuix_tab_row.dart` 的 `_TabItem`：`if (!contour && !selected)` 用 `CustomPaint(foregroundPainter: _InsetSquircleBorderPainter(color: outlineColor))` 画 1px insetsquircle 描边，`outlineColor = MiuixTheme.of(context).colors.outline`（`_TabRowBase.build` 内写死，**库未暴露开关**）；该项 `Container(height: double.infinity)` 撑满 42 → 每格一圈方框，相邻格上下边连成整行细线 = 用户所说的"额外的容器 + 不必要的上下边框线"。
  - 反馈轮 1 新增的 `lib/common/widgets/miuix_frosted_surface.dart` 面板档带 `Border.all(1px)` → 面板自身四边线（上下最显眼）。
- **R3（分类器按钮被缩略）**：反馈轮 1 把标签条放进 `SliverAppBar.actions` 首项，宽度 = `AppTabBar.fittedWidth(n)`（clamp 240~420）**再被窗口 50% 封顶**。5 个标签时 `available = 420`，`contentWidth = 420 − 4×9 = 384`，`idealWidth = 76.8`（< maxWidth 98 → 库返回 76.8），减非 contour 项左右各 `itemHorizontalPadding = 12` → 文本可用宽 ≈ **52.8px**，小于"投稿 (123)"实宽 → 库 `MiuixText(maxLines: 1, overflow: TextOverflow.ellipsis)` 触发省略。即根因是**宽度被 420 与窗口 50% 双重封顶**；库内算法在宽度充裕时本会拉伸铺满（`ideal > maxWidth` 且 `totalMaxWidth < available` → 返回 `ideal`），备注：上一批之前的全宽标签条正是这样不缩略的。

## 三、修复方法

1. `lib/common/widgets/miuix_frosted_surface.dart`（共享件，P4 单点定义）
   - 新增 `outline`（默认 `true`）；置 `false` 时不画描边（面板档与全宽档同时生效），只保留毛玻璃与投影。
   - 文档同步：面板档/全宽档的描边描述标注为"`outline` 为 true 时"。
2. `lib/ui/components/app_tab_view.dart`
   - `AppTabBar` 新增 `outline`（默认 `true`），**Tab 栏调用方传 `false`** → 去掉面板四边细线。
   - `_buildRow` 用**局部 `MiuixTheme` 覆盖**关掉库的逐格描边：`theme.copyWith(colors: theme.colors.copy(outline: AppColors.transparent))`；只影响本子树，不动全局主题与库。
   - 库内条底色**恒置透明**（原先仅 `blurBackground == true` 时置透明），并让 `widget.colors` 覆盖真正生效（原先自绘面板时会丢弃调用方配色）。
   - `blurBackground: false` 语义收敛为"不自绘毛玻璃面板、标签条自身透明"，供宿主自带背景（空间页按钮行的通栏带）。
   - 删除 `fittedWidth`（唯一调用方已撤回，避免死代码）。
3. `lib/pages/search/search_result_page.dart`（1-A）
   - `reserveTopStrip: false` 关掉壳层安全行的悬浮返回。
   - 行首插入 56 宽 leading 槽 `const SizedBox(width: 56, child: Center(child: AppBackButton()))`，行左内边距 12 → 0 → 返回键与上级搜索页同位（图标中心 x≈28），输入框起于 x≈56（上级页 `titleSpacing: 0` 亦然）。
4. `lib/pages/member/member_space_page.dart`（3-A）
   - 标签条从 `actions` 首项改为 `SliverAppBar.title`（`titleSpacing: Style.xs`）：宽度由框架按"行内剩余宽度"（总宽 − leading − actions）给出，库内按标签数均分 → 每格拿到容纳进本行的最大尺寸，不再省略。
   - 传 `blurBackground: false`：本行已有通栏毛玻璃带（`flexibleSpace` 内 56 高 `MiuixFrostedSurface(borderRadius: 0)`），避免两层材质叠加发灰。
   - 删除 `tabBarWidth` 计算块（`fittedWidth` + 窗口 50% 封顶）。
