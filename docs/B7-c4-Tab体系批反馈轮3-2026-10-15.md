## 一、现象描述

本轮用户在实机复验后反馈 3 条（附 3 张截图；**本会话无法读取图片**，故第 3 条按文字
描述 + 源码取证定位，见第二节 R3）：

1. **搜索结果页**的搜索框行里，全局返回按钮的**尺寸**与 **HOVER 效果**，没有对齐上级
   **搜索页**的全局返回按钮（两页返回键观感不一致）。
2. **用户空间页**顶栏的分类器应**默认处于 b7-c4 改进之前的位置**（即留在头图下方的原位），
   只有当滚动视图滚到分类器那一行时，才**并入顶栏并吸顶**；滚回来时**恢复到原来的位置**。
3. 若某 Tab 栏**下方或附近还有额外的二级分类器**，该二级分类器的**控件层级应与 Tab 栏的
   容器合并、共享模糊背景**；目前该二级分类器仍是不透明的，导致**看不到 Tab 栏模糊背景
   后方的内容滚动**。

## 二、问题根因

- **R1（返回键尺寸 / hover 不一致）**：不是两个控件不同，而是**外层约束不同**。
  - 搜索页走 `AppBar(leading: ...)`：Material `AppBar` 对 leading 套
    `BoxConstraints.tightFor(width: 56)`（`material/app_bar.dart:1051`），
    `NavigationToolbar` 再给 **tight 高度 56**（`widgets/navigation_toolbar.dart:103`）→
    `AppBackButton` 内的 `MiuixIconButton`（`ConstrainedBox(minWidth:0,minHeight:0)` →
    `Center(widthFactor:1,heightFactor:1)`）在 tight 约束下被**撑满 56×56**，hover 是
    **56×56 大圆盘**。
  - 结果页此前为 `SizedBox(width: 56, child: Center(child: AppBackButton()))`：`Center`
    **放松**约束 → 按钮收缩到 **36×36**（图标 20 + `padding: EdgeInsets.all(8)`）→
    hover 只有小方块，尺寸与观感都对不上。
  - **结论：同控件、不同外层约束**；统一口径必须落在**槽位**上，而不是改控件本身。

- **R2（空间页分类器该"先原位、滚到才吸顶"）**：反馈轮 1 为修"分类文本被收窄省略"，
  把标签条**收进了 `SliverAppBar.title` 槽**——该槽**永远在顶栏里**，天然没有"原位"态，
  与用户期望的形态相反。期望形态即 **b7-c4 之前 `62ac3dc` 的结构**：
  `headerSliverBuilder` 里 `SliverAppBar(...)` 之后接 `SliverPersistentHeader(pinned: true)`
  承载标签条——该结构天然满足"默认在位 → 滚到即吸顶（紧贴顶栏）→ 滚回恢复"。

- **R3（Tab 栏附近二级分类器不透明遮挡）**：全库扫描（Tab 栏 × 二级分类器 × 不透明底）
  的结论：
  - **Ⓐ `bangumi_player_page.dart:1117`（番剧窄屏）**：吸顶 `SliverPersistentHeader` 内的
    `AppTabBar`（默认 `blurBackground:true`）被 `_SliverTabBarDelegate.build` 的
    `ColoredBox(color: background)`（原 `:2434`）**实色底包住** → 毛玻璃背后是纯色、
    滚动内容被垫死。**描述逐字吻合**（该处没有"第二个分类控件"，遮挡物是容器自身的实色底）。
  - Ⓑ 空间页各 Tab 体首行的 `ChoiceChip`/`FilterChip`（M3 选中态实色 `secondaryContainer`）
    确实是"真·二级分类器且不透明"，但在 Tab 体**内部**随内容滚动，与吸顶标签条**不同层**。
  - Ⓒ 视频详情右栏 / 番剧宽屏的排序行（最热/最新、倒序/正序）紧邻 Tab 栏下方，但为**透明文本行**。
  - **本轮按"机制最吻合"取 Ⓐ**，Ⓑ/Ⓒ 暂不动（见第五节）。

## 三、修复方法（1-A / 2-A / 3-A）

### 1-A：返回键统一到"顶栏标准槽位"

- `lib/theme/app_icons.dart`：在 `AppBackButton` 之后新增共享件 **`AppLeadingBackButton`**
  （`SizedBox(width: 56, height: 56)` 包 `AppBackButton`；`slotWidth/slotHeight` 常量 +
  `onPressed/onBeforePop` 透传），注释中写清"为何必须 tight 槽位一致"。
- `lib/pages/search/search_page.dart`：`AppBar(leading: const AppBackButton())`
  → `AppBar(leading: const AppLeadingBackButton())`。
- `lib/pages/search/search_result_page.dart`：`SizedBox(56) + Center(AppBackButton())`
  → `const AppLeadingBackButton()`。
- 效果：两页返回键同为 **56×56 槽**（命中区 = hover 高亮区），观感与交互严格一致。
  **副作用（已知并接受）**：结果页搜索行行高随 56 槽抬到 56（原 ~40），与上级搜索页
  `AppBar` 工具栏高一致。

### 2-A：空间页分类器回到"原位 + 滚到吸顶"

- `lib/ui/components/app_tab_view.dart`：新增静态常量
  **`AppTabBar.defaultHeight = MiuixTabRowDefaults.tabRowHeight`**（避免各处硬编码 42）。
- `lib/pages/member/member_space_page.dart`：
  - `SliverAppBar` **去掉 `title` / `titleSpacing`**（分类器不再住在顶栏里）；
  - 其后**恢复 `SliverPersistentHeader(pinned: true)`**，委托为新的
    `_SliverTabBarDelegate({required Widget child, required double extent})`，
    `minExtent == maxExtent == extent`，**`build` 直接返回 `child`（不包实色底）**；
  - 标签条改为**通栏毛玻璃带**：`MiuixFrostedSurface(borderRadius: 0)` 包
    `AppTabBar(blurBackground: false, height: tabBandHeight, panelPadding: 竖直 4)`，
    `tabBandHeight = AppTabBar.defaultHeight + Style.xs * 2 = 50`；
  - 顶栏那条 56px 通栏带传 **`outline: false`**：贴合时**分隔线只由标签条带底部的
    1px 承担**，不叠双线；
  - 文件尾新增 `_SliverTabBarDelegate`。

### 3-A：吸顶层去实色底，改由通栏毛玻璃承担

- `lib/pages/bangumi/bangumi_player_page.dart`：
  - `_SliverTabBarDelegate` 改形为 `{required Widget child, required double extent}`
    （删除 `AppTabBar tabBar` / `Color color` 字段与 `ColoredBox` 包装）；
  - 调用点（窄屏 `:1114` 一带）改传
    `child: MiuixFrostedSurface(borderRadius: 0, child: AppTabBar(..., blurBackground: false))`、
    `extent: AppTabBar.defaultHeight`；
  - 新增 `import 'package:winwin/common/widgets/miuix_frosted_surface.dart';`。

## 六、总结

本轮把 Tab 体系批的**三处观感缺口**按 1-A / 2-A / 3-A 收口：① 返回键从"控件级复用"升级为
**槽位级统一**（新增 `AppLeadingBackButton`，56×56 标准顶栏槽，搜索页与结果页共用，命中区与
hover 高亮口径一致）；② 空间页分类器从 `SliverAppBar.title` **回退到 pinned
`SliverPersistentHeader`**，恢复"默认原位 → 滚到吸顶并入顶栏 → 滚回复位"的期望形态，并把背景
统一为**通栏毛玻璃带**（顶栏带 `outline:false` 去双线）；③ 吸顶层**彻底去掉实色 `ColoredBox`**
（番剧窄屏），材质交给 `MiuixFrostedSurface`，使模糊背景后方的内容滚动真正可见。验证面全绿
（analyze 0 / test 172 / debug 42.1s / release 19.1s / 闸门 65→65），文档与进度表同批回填。
