- 漏网成因：B6-2 系列扫描口径是 `Icon(Icons.xxx)` **字面量直参**——语义方法化后

- 替换口径：`AppIcon` 与 `Icon` 调用兼容（size/color/shadows，本批补齐
  `semanticLabel`）；散点直参收敛为新增语义方法（字形保留现状，**零字形变化**，
  与 B6-2e/2f 同一约定；美术替换统一归 b7-d）。
- import 收敛：探针法（material_ui → flutter/widgets + analyzer 扫描）判定
  "改动后已零 material 符号"的文件，能切则切。

## 6. 遗留与踩坑

- **踩坑 1（大小写）**：PowerShell `-replace` 默认**大小写不敏感** → `\bIcon\(`
  连带把小写方法 `icon(`（frosted_bottom_bar 的 `NavDestination.icon`）误改为
  `AppIcon`；经 diff 全量筛查后精确还原（定义 1 行 + 调用 3 行）。教训：脚本化
  替换必须显式大小写敏感（String.Replace 或 (?-i)）。
- **踩坑 2（glob 漏匹配）**：grep 工具 glob 花括号混合模式漏匹配 → 得出
  "26 文件中仅 6 个依赖 material_ui"的错误中间结论；改用脚本逐文件字符串
  复核得实际 25 个。教训：名单类统计以脚本复核为准。
- **踩坑 3（行尾）**：多行替换对在 CRLF 文件（demo_editable）上 MISS
  （here-string 为 LF）——按两种行尾兼容处理。
- **保留点（不动，登记）**：
  - `app_icons.dart` 内 64 处 `Icons.xx` 语义字形载体（归 b7-d 美术替换）；
  - `level_icon.dart:142/147` 的 `Icons.bolt_rounded.fontFamily/codePoint`
    （canvas 字体渲染载体，归 b7-d / 封板前处置）。
- **挡路清单（探针报错 log 留档 `scratch/probe_analyze_b7c2.log`，159 行）**：
  18 文件继续持有 material_ui，阻塞符号与后续批次对应——Tab 体系
  （bangumi_player / video detail / dynamics view）、TextField+InputDecoration
  （demo_editable / bangumi 系列）、RefreshIndicator+ColorScheme
