## 2. 定因

`Scaffold` / `AppBar` 是 `material_ui` 的**壳层控件**。项目自 2026-10-08 起：
- 页面骨架统一由 `AppScaffold`（基于纯 widgets 的 `MiuixScaffold`）承载，`lib/` 内已有 **31 处** `AppScaffold(` 在用；
- **去除页面标题栏** —— 由「顶部安全行 + 悬浮返回按钮」取代，位置由窗口标题条 + 左侧导航表达。

本次 6×`Scaffold` + 3×`AppBar` 是前几批迁移中的**漏网**（上述三页与两个基础设施位点未被覆盖）。

## 3. 逐点甄别与定策

| 站点 | 原写法 | 定策 | 依据 / 观感影响 |
|---|---|---|---|
| `search_page` | `Scaffold(appBar: AppBar(leading+title 搜索框+actions))` | `AppScaffold(reserveTopStrip:false, topBar: _buildSearchTopBar())` | **与已迁移子页 `search_result_page` 严格同构**（同一 `reserveTopStrip:false` + 自绘 `Padding+Row`：`AppLeadingBackButton` 56×56 槽 + `AppCapsuleTextField` + `MiuixTextButton('搜索')`）；观感零变化 |
| `season_series_detail_page` | `Scaffold(appBar: AppBar(title: 合集/系列))` | `AppScaffold(body: ...)` | 二级页按项目设计**不显示标题栏**（同 `member_space_page`/`bangumi_detail_page`/`toview_page`）；页面标题**已在正文头部卡片**以 `PBadge` + 文本展示（L174），故标题不丢失；顶部安全行自动提供悬浮返回按钮 |
| `live_room_page` | `Scaffold(backgroundColor:transparent, appBar: isFillWindow?null:AppBar(leading+徽标/标题+刷新·复制 actions))` | `AppScaffold(backgroundColor:transparent, reserveTopStrip:false, topBar: isFillWindow?null:_buildLiveTopBar())` | 直播页顶栏承载状态徽标 / 标题 / 刷新·复制动作，**功能必须保留**；自绘行 `SizedBox(height: Style.toolbarHeight)` + `AppLeadingBackButton` + `_buildStatusBadge()` + 标题 + 两个 `MiuixIconButton`（刷新 / 复制链接），尺寸对齐 `AppBar` 默认（leading 56 + titleSpacing 16） |
| `main.dart` ×2（启动异常面板 / 加载面板） | `Scaffold(backgroundColor: 浅/深常量, body: Center(...))` | `AppScaffold(backgroundColor: 同上, reserveTopStrip:false, body: Center(...))` | 门禁面板无标题 / 无返回按钮，`reserveTopStrip:false` 避免多出 50px 安全行；背景色显式保留 |
| `ui/app.dart`（根壳 `AppRoot`） | `Scaffold(body: MainLayout(...))` | `AppScaffold(reserveTopStrip:false, body: MainLayout(...))` | 根壳仅承担背景 + `Material` 祖先 + body；`reserveTopStrip:false` 不引入安全行 |

**决策：不使用 `MiuixTopAppBar`。** 项目 `lib/` 内**无 `MiuixTopAppBar` 先例**（仅 `AppScaffold` doc 提及该槽位可承载），且已迁移的 `search_result_page` 确立了「自绘 topBar 行」口径；为保持**全站一致**（P4 每概念一处定义），三处 AppBar 一律走自绘行，而非引入未验证的 miuix 顶栏件。

## 7. 遗留与踩坑

1. **换行符不统一致 index 未命中**：`search_page` / `live_room_page` 工作副本为 **LF**，而
   `season_series_detail_page` / `main.dart` / `ui/app.dart` 为 **CRLF**。v1 脚本以 `\n` 匹配，命中 LF 文件
   （`search_page` 成功）、在 CRLF 文件（`season_series_detail_page`）`index` 抛 `ValueError`。
   v2 改为「读字节 → 判主 EOL → 归一 `\n` 匹配 → 按原 EOL 回写」，逐文件保持原口径。
2. **`live_room_page` 未脱库**（仍含 `Material(` + Slider 族），归 c6-4 / c6-5 完成后一并发生。
3. **根壳 `AppScaffold` 使 `MiuixPopupScope` 根上移**：原根壳为材质 `Scaffold`（非 MiuixScaffold），
   最外层 `MiuixScaffold` 在各页 `AppScaffold` 内；改后**根壳自成 popup root**，各页复用。
   预期弹层宿主层级不变（MiuixScaffold 铺满窗口），但**需实机复验**弹层 / 菜单 / Toast 层级无回归。
4. **二级页去除标题栏为设计目标态**：`season_series_detail_page` 顶栏标题移除后，位置信息仍由
   正文头部卡片（`PBadge` + 标题）承载，属「去除页面标题栏」既定方向，非观感回退。
5. **`dart format` 全程未跑**（项目硬约束）。
6. 迁移脚本首次运行在 CRLF 文件处中断，`search_page` 已落盘（v1 先行成功）；v2 加「已迁移则跳过」幂等判定，避免重复插入 import。

## 8. 实机复验指导（建议 6 项）

1. 搜索页顶栏：返回键（56×56 槽）→ 搜索输入框 → 「搜索」按钮，与进入搜索结果页后顶栏**同位同尺寸**；输入清空 × 图标可点。
2. 合集 / 系列详情页：顶部安全行仅悬浮返回按钮（无标题栏），正文头部卡片仍显示 `合集`/`系列` 徽标 + 标题；下拉刷新正常。
3. 直播间顶栏：状态徽标 + 直播间标题 + 刷新 / 复制链接两按钮均可用；复制成功 Toast「已复制直播间链接」；全屏（`isFillWindow`）时顶栏整条隐藏、不留空白。
4. 启动门禁面板（异常 / 加载）：居中卡片无顶部安全行、无返回按钮，背景深浅色正确。
5. 根壳导航（首页 / 动态 / 历史 / 消息 / 我的）与各类**弹层 / 菜单 / Toast** 层级无回归（重点：弹层是否仍浮于底部导航之上且点击命中正常）。
6. 浅 / 深双主题下逐一核对上述站点，并确认 `runtime.log` 无新增 `[E]`。
