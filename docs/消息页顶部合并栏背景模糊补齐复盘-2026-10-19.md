# 消息页顶部合并栏背景模糊补齐复盘-2026-10-19

> 主题：消息页顶部「互动入口行（回复我的 / 艾特我的 / 点赞我的 / 系统消息）」与
> 「分类栏（全部 / 特别关注 / 关注 / …）」的背景模糊补齐。
> 归属：B7 封板（MD3 库级退役收官）之后的**实机反馈修复**；承接
> `docs/根页面Tab栏背景模糊补齐复盘-2026-10-19.md`（同一「可见毛玻璃 = 栏与滚动
> 内容发生层叠」口径）。

## 一、现象

用户实机反馈（附截图）：消息页顶部的「互动入口行」与「分类栏」没有首页
「搜索框 + 分类器合并栏」那样的背景模糊。诉求：**同样**补齐该效果。

## 二、定因（根因链）

沿用上一轮确立的口径：`BackdropFilter` 只模糊「其后方**已绘制**的像素」。

1. 消息页原结构为 `Column[ 互动行(实底), 分隔线, Expanded(会话列表) ]`；其中
   「分类栏」又在 `SessionListSection` 内部以
   `Column[ 分类行, 分隔线, Expanded(列表) ]` 承载。
2. 两行都排在内容**之上**、各占独立纵向空间 ⇒ **栏背后是纯色页底** ⇒ 模糊采样到
   纯色 ⇒ **视觉上等同于「没有模糊」**。
3. 首页合并栏之所以可见，是因为 `_HomeHeader` 用 `Stack` 浮在滚动 feed 之上、内容
   从栏后穿过（与上一轮动态页 Tab 栏缺失模糊同因）。

**结论**：仍是**布局层级**问题，非材质配置。

## 三、方案

把消息页顶部「互动行 + 分类栏」合并为**一个浮动毛玻璃面板**（对齐首页合并栏的
「合并」形态），会话列表铺满并滚到面板后方穿过：

- `WhisperPage.build` → `AppScaffold(body: Stack[ Positioned.fill( AppRefreshIndicator(
  SessionListSection(...) ) ), Positioned(top: 0, left: 0, right: 0,
  RepaintBoundary(合并栏)) ])`。
- 合并栏 = `MiuixFrostedSurface(borderRadius: Style.radiusMd, outline: false)`
  （复用共享材质单一来源）内 `Column[ 互动行, MiuixHorizontalDivider,
  SessionFilterBar ]`；外缩 `EdgeInsets.symmetric(horizontal: Style.lg,
  vertical: Style.sm)`（= 首页 `_HomeHeader` 口径）。取 `outline: false` 以对齐首页
  合并栏「无可见描边 + 下投影」的观感。
- **分类栏上移**：`SessionListSection` 不再持有筛选 chips，新增公开部件
  `SessionFilterBar`（与 `SessionListSection` 同文件，令会话域知识仍单点定义）；
  筛选类型由消息页经 `SessionListSection.sessionType` 下传，`didUpdateWidget` 检测
  变化后重载该类型会话。原私有标记 `_specialCategoryType` 提为公开
  `kSpecialSessionFilterType`。
- **顶部避让**：消息页定义
  `_headerReserve = Style.sm×2 + Style.md×2 + 52 + 6 + 20 + 1 + 44 + Style.sm = 171`，
  经 `SessionListSection.topInset` 落为列表滚动区**首个**
  `SliverToBoxAdapter(SizedBox(height: topInset))`。**必须在滚动区内**：设在滚动区
  外内容就滚不到栏后，模糊又会不可见。
- 取舍：未采用「两行各自独立毛玻璃面板」（与首页「合并栏」形态不一致，且两条
  面板叠放更重）；未采用 `AppScaffold.topBar` 槽（该槽渲染在顶部安全行之上并给
  内容留内边距 → 内容不穿过 → 模糊不可见，此点上一轮已实锤）。

## 六、遗留与踩坑

1. **`CustomScrollView` 无 `padding` 参数**：`ScrollView` 有 `padding`，但
   `CustomScrollView` 未暴露——顶部避让改用**首个 sliver**
   （`SliverToBoxAdapter(SizedBox(height: topInset))`），首轮实现曾因此报
   `undefined_named_parameter`。
2. **筛选状态所有权调整**：`SessionListSection` 由「自持筛选 chips」改为「由宿主页
   下传 `sessionType`」。`SessionListSection` 全仓**仅消息页引用**，改造面已收敛；
   后续如需在别处复用，须一并提供 `SessionFilterBar` 与 `topInset`。
3. **`_headerReserve = 171` 为预算常量**（同首页 120 的做法）：四入口行高度由
   头像 52 + 间距 6 + 标签行约 20 估得，标签行实际行高若有 1~2px 偏差会造成首行
   轻微遮挡或留白；如需精确可改为按实测高度回填。
4. **下拉刷新指示器的位置**：列表视口现已铺满到页顶（面板浮在上方），下拉指示器
   会出现在面板后方（大部分被面板遮住）。此与首页各子页「顶部硬编 120 避让 + 浮动
   头」的既有观感一致，本轮沿用该口径。
5. **未跑 `flutter test`**：按 `dev-workflow-spec` 的验证目标（`dart analyze` +
   debug / release 双编译）执行；本机 `flutter test` 仍受环境变量缺失影响。

## 七、总结

消息页的「互动行」「分类栏」看不到模糊，与前一轮动态页 Tab 栏同一根因：**栏与滚动
内容没有发生层叠**，`BackdropFilter` 采不到可模糊的内容。本轮把两行合并为一个
**浮动毛玻璃面板**（`MiuixFrostedSurface` + `Stack` 浮顶 + 列表顶部 171px 避让），
并把分类栏从列表区上移为公开部件 `SessionFilterBar`（筛选类型经 `sessionType`
下传），使消息页顶部与首页合并栏同观感。改动 2 文件 216+/132-，`dart analyze`
0 错 0 警告，debug / release 双编译均通过。
