# 全局返回按钮上提为壳层单实例 复盘（2026-10-21）

> 需求（CVO）：从深层页面返回根页面时，首页顶栏左上角**残留全局返回按钮**。
> 改进：二级及更深层页面**共用一个全局返回按钮**，不再跟随任意页面转场动画消失，
> **始终固定在默认位置**，返回到根页面时再隐藏消失。
> 决策：CVO 拍板「A 加 B 一起做」= 标准页 + 媒体/搜索页**全量统一**到同一个壳层按钮。
> 起点 HEAD `77cda2d`（改动前快照；`refs/snapshots/latest` 已指向）。

---

## 1. 现象

1. 从根页面（首页/动态/历史/消息/我的）进入任一二级页，再进入更深层（三级）页；
2. 逐级返回根页面：**首页顶栏左上角仍显示一个返回按钮**（不消失）；
3. 另：进出二级页时，该返回按钮**跟随页面转场（淡入 + 轻微上移）一起出现/消失**，并非固定不动。

---

## 2. 定因（源码取证）

### 2.1 按钮的渲染位置 = 每个页面自己的路由子树内（关键）

`lib/core/shell/app_scaffold.dart`（改动前）：

```dart
final canPop = widget.showBackButton &&
    (Navigator.maybeOf(context)?.canPop() ?? false);   // 构建期一次性快照
...
if (canPop) FloatingBackButton(tokens: tokens),          // 直接画在本页子树里
```

- 按钮在**当前路由的子树内** ⇒ 必然继承该路由的转场变换
  （`AppRoute` → `MiuixPageTransition`：`FadeTransition` + `SlideTransition`，
  `lib/core/shell/app_transition.dart`）⇒ 这就是「**跟随任意页面转场动画消失**」。
- 每个二级页各自实例化一个按钮 ⇒ 不是「共用」，是 N 个副本。

### 2.2 残留的直接原因 = `canPop()` 构建期快照 + 被覆盖页不重建

- `canPop()` 只在 `build` 时读一次，`AppScaffold` 未订阅任何路由变化。
- 首页（`lib/ui/home/home_page.dart` `AppScaffold(title: '首页')`）被压栈时被盖住；
  返回时重新可见，但其 `build` 结果里的 `canPop` 仍是「深度 ≥ 2 那一帧」的值
  ⇒ 首页左上角残留返回按钮（直到下一次意外重建才复原）。
- 根部壳 `AppRoot`（`lib/ui/app.dart`）已 `reserveTopStrip:false`，**不是**它画的。

---

## 3. 方案（A+B 全量统一）

### 3.1 核心机制（新增 `lib/core/shell/global_back_button.dart`）

- **`GlobalBackButtonController`**（`NavigatorObserver` + `ChangeNotifier`）：
  维护路由栈（栈深 / 栈顶路由 / 栈顶是否 `PopupRoute`），并收纳**每路由**的
  `BackButtonSpec` 注册表；变更通知**帧内合并**（`SchedulerPhase` 判定，构建/布局期改投
  post-frame），避免构建期触发重建。
- **`GlobalBackButton`**（壳层单实例）：挂在 `AppShell.builder` 内、**Navigator 之上**
  （与 `AppEscapeScope` 同层，`Stack[ routed, GlobalBackButton ]`）。
  - **位置固定**：`left: 8 / top: 4`（= 50 高安全行内居中 42×42），**外框恒定 42**；
  - **显隐只做淡入淡出**（`AnimatedOpacity` 180ms，不位移），隐藏时 `IgnorePointer`；
  - 显隐判据：`栈深 ≥ 2` **且**栈顶非 `PopupRoute` **且**本路由 `spec.visible`；
    栈顶为 `fullscreenDialog` 页路由时渲染「关闭」字形。
- **`BackButtonSpec`**：可覆盖字形/颜色/底色/阴影/尺寸/工具链提示/点击行为/返回前副作用；
  默认（`standard`）= 原标准观感。标准页**无需声明**。
- **`BackButtonOwner`**：页面便捷宿主（`child` 以引用透传 ⇒ 规格变化只重建宿主自身，
  不连带整页重建）；`listenable` 支持规格随滚动等状态变化。

### 3.2 接线与收口

| 文件 | 改动 |
|---|---|
| `lib/core/shell/global_back_button.dart`（**新增**）| 控制器 + 单实例按钮 + `BackButtonSpec` + `BackButtonOwner` + 应用级单例 |
| `lib/core/shell/app_shell.dart` | `builder` 内把 Navigator 包进 `Stack` 并叠加 `GlobalBackButton`；新增 `backButtonController` 参数 |
| `lib/main.dart` | 注册控制器进 `navigatorObservers` 并传入 `AppShell` |
| `lib/core/shell/app_scaffold.dart` | 删除安全行内的 `FloatingBackButton` 与 `showBackButton` 参数（返回键改由壳层承担）；安全行只保留 `title`（根页）/`actions` |

### 3.3 全量统一（B：媒体/搜索页一并接入）

| 页面 | 处置 |
|---|---|
| `search_page` / `search_result_page` | 删除 `AppLeadingBackButton`，保留 56 宽**空槽位**让输入框原位不动；行顶内边距 `8 → 0` 使行中心与壳层按钮默认位对齐；**用默认规格**（无需声明） |
| `live_room_page` | 删除自绘顶栏返回键（普通）与全屏栏返回键；经 `BackButtonOwner` 声明：普通=标准；全屏=白字 + 半透明黑圆底 + 点击 `_handleEscape`（退出全屏） |
| `video/detail_page` | 删除渐变顶栏内返回键（改留 56 槽位）；声明：颜色随滚动在白色/主题可读色间切换，`onBeforePop` 暂停并解绑播放器；全屏/应用内全屏声明隐藏（让位播放器片内控件） |
| `bangumi_player_page` | 同视频详情页 |
| `member_space_page` | 删除覆盖层返回键；声明：白字 + 半透明黑圆底（覆盖在头图上） |
| `image_gallery_viewer` | 无返回键且为 `PopupRoute` ⇒ 壳层按钮自动让位（与今一致） |

> **边界决策**：播放器**片内全屏返回键**（`player_panel.dart`）是「播放器控件」（与播放控制条
> 同步显隐、受锁定态控制），**保留**；页面在全屏时声明让位，避免双按钮。这是「页面级返回键统一」
> 之外的有意保留项（见遗留）。

## 6. 遗留与踩坑

1. **播放器片内全屏返回键未并入**（`player_panel.dart`）：它是与播放控制条同步显隐、受 `_locked`
   控制的**播放器控件**，并非页面级导航；本轮保留并在全屏时让壳层按钮隐藏。若 CVO 要求**连它也统一**
   （代价：壳层按钮需接收播放器控件可见性/锁定态，失去「始终可见」语义），可另起一轮。
2. **非标准页的纵向对齐做了微调**：搜索两页行顶内边距 `8 → 0`、详情/番剧顶栏加了 56 宽槽位
   （返回键走后，标题起点由 ~40 → 56）。属「固定位」的必然代价，已尽量取最小位移，需实机确认观感。
3. **按钮位置固定 ⇒ 覆盖层语义**：壳层按钮恒在 `left:8/top:4`（42×42），故页面左上角原处于
   `x∈[8,50]` 的内容需避让（本轮已处理各页；后续新增页面若在左上角放内容需同样避让）。
4. **`AppLeadingBackButton` 变为无引用**：作为 `app_icons.dart` 的公共组件保留（不删，避免多余改动）；
   若后续确认长期不用可另行收口。
5. `dart format` 全程未跑（项目硬约束）。

## 7. 总结

- **根因**：返回按钮由**每页各自**在**自身路由子树内**内联渲染，显隐依赖构建期快照的 `canPop()`
  ⇒ 既「跟随本页转场」，又在被覆盖页不重建时「回根页面残留」。
- **修复**：把返回按钮**上提为壳层单实例**（Navigator 之上）——不属任何路由 ⇒ 转场带不走；
  位置固定；显隐由**路由栈观察器**驱动 ⇒ 回根页面即隐藏。并按 CVO 要求**全量统一**（A+B）：
  标准页用默认规格，媒体/搜索页经 `BackButtonSpec` 声明各自的观感与副作用。
- **验证**：`analyze` 0/0、`test` 238 全绿、debug/release 双编译通过（各 0 警告）；实机待复验。
- **收益**：一处收口（P4 概念单处定义）——返回按钮的行为/观感/显隐从此只有**一个**来源，
  后续任何页面只需（可选地）声明一份规格，不再各画一份。
