# TAB 栏全圆胶囊改造复盘（2026-10-27）

## 一、现象

CVO 对比上游 PiliPlus 的分类标签条（动态页「全部 / 投稿 / 番剧 / 专栏」）后提出：
WinWin 的页内 TAB 栏当前是 **12px 圆角矩形**，与上游「**浅底全圆胶囊 + 浮起的白色胶囊选中项**」
观感差距明显，要求改成截图中的大圆角胶囊样式。

## 二、定因

1. **圆角口径写死在库默认值**：[app_tab_view.dart](file:///d:/Documents/GitHub/WinWin/lib/ui/components/app_tab_view.dart)
   的 `AppTabBar.borderRadius` 默认取 `MiuixTabRowDefaults.tabRowCornerRadius`（**12**），
   同一值同时喂给面板（`MiuixFrostedSurface`）、选中项（`MiuixTabRow.cornerRadius`）与
   hover/按压高亮层 ⇒ 三处一起停在「圆角矩形」。
2. **选中项与面板同高**：`panelPadding` 默认 `EdgeInsets.zero`，选中胶囊铺满整条高度，
   与面板外轮廓完全重合；即便把圆角调大，也只是一块「整条被涂色」的胶囊，读不出
   「白色切片浮在浅灰底上」的层次。
3. **库本身无胶囊参数**：flutter_miuix 1.3.0 的 `MiuixTabRow` 只有 `cornerRadius`
   （squircle 半径）与 `height`，半径按「自身高度的一半」才等价于全圆；且非 contour
   档的条底色是**不透明 `ColoredBox`、无圆角**，外轮廓只能由外层面板承担。
4. **上游对照**：PiliPlus 的分类条用 `TabBar.indicator: BoxDecoration(color:
   secondaryContainer, borderRadius: 20)` + `indicatorPadding: (h3, v8)` +
   `indicatorSize: tab`（见 `member_contribute/view.dart` 58-84 行、`search_result/view.dart`
   104-152 行），即「指示器独立成胶囊、四周留白」，与截图同源。

## 三、方案

### 3.1 统一胶囊口径（`lib/ui/components/app_tab_view.dart`）

- `borderRadius` 改 **可空**，默认 `null` = **全圆自动**：
  - 面板半径 `_panelRadius = preferredHeight / 2`（整条高度一半，外轮廓成胶囊）；
  - 选中项 / hover 高亮半径 `_pillRadius = 行高 / 2`（内缩后高亮层比面板矮，
    沿用面板半径会退化成方角）。
  - 显式传值（含 `0`）时仍按该值统一作用于面板与选中项，旧口径可回退。
- `panelPadding` 默认 `EdgeInsets.zero` → **`EdgeInsets.all(Style.xs)`（4）**：
  四向留白让选中胶囊浮在面板内（截图同观感），行高随之从 42 收到 34，选中胶囊半径取 17。
- 毛玻璃材质与 1px 描边**全部保留**（CVO 决策：不做成截图那种无描边平铺），
  仅改圆角与内缩——视觉连续性优先、改动面最小。

### 3.2 宿主微调（`lib/pages/member/member_space_page.dart`）

用户空间分类条挂在**通栏毛玻璃带**上（`blurBackground: false` 由宿主画材质），原
`panelPadding` 只有垂直 4 ⇒ 首个标签胶囊会贴死屏幕左缘。补 `horizontal: Style.sm`（8），
与上游分类条左右留白（`padding: horizontal 8`）同口径。

### 3.3 未改的部分（有意收敛）

- 条宽仍**铺满可用宽**（不做「内容宽度收缩」）：`MiuixTabRow` 的横向滚动与
  `_hitIndex` 命中判定都建立在「条宽 = 可用宽」上，收缩会牵动滚动/居中/命中三处；
  桌面宽窗下空余留白与改造前一致，非本次诉求。
- 底部浮动导航栏（`MiuixFloatingNavigationBar`，`cornerRadius: 50`）本身已是全圆，不动。
- 判定阈值 / 点击命中 / hover 与按压反馈逻辑零改动。

## 六、遗留与踩坑

1. **半径不能共用**：面板与选中项高度不同（42 vs 34），只改一个 `borderRadius`
   会让选中胶囊变成「方角卡片」；必须拆成 `_panelRadius` / `_pillRadius` 两个派生值。
2. **`MiuixFrostedSurface` 的 0 是特例**：传 `0` 走全宽档（无圆角/无投影/仅底边线），
   本次默认值改为 `null` 自动计算，不能顺手把「0 = 直角」语义带进来。
3. **通栏宿主不吃默认内缩**：用户空间页显式传 `panelPadding`，默认值的水平留白不会
   自动生效，需在宿主补 `horizontal`（否则胶囊贴屏幕边）。
4. **宽窗留白**：桌面宽窗下分类条仍是整宽胶囊、标签靠左（与改造前同构）。若要
   完全复刻截图「胶囊随内容收缩」，需另立一项改造（涉及滚动与命中换算）。
5. **未跑全量 `flutter test`**：沿用本项目惯例只跑受影响的 Miuix 采纳测试。

## 七、总结

页内 TAB 栏（搜索结果 / 动态 / 视频详情右栏 / 番剧播放器 / 弹幕屏蔽 / 用户空间六处共用）
的外观由「12px 圆角矩形」统一换成「全圆胶囊 + 4px 内缩的浮起选中胶囊」，毛玻璃与描边材质
保持不变；圆角口径收敛到 `AppTabBar` 一处派生值，后续再调只需改 `borderRadius` / `panelPadding`。
静态分析与 Windows Debug/Release 双编译全部通过。
