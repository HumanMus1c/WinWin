# 播放器弹层常显、投币动效与评论互动胶囊复盘（2026-11-02）

> 任务来源：本轮 CVO 反馈四条（音量弹层行为 / 投币对角线动画 / 评论互动胶囊 / 楼中楼末条回复展开收起）。
> 目标：逐条定位根因并修复，走完整验证序列（analyze / test / Windows Debug+Release 双编译）。

---

## 一、现象描述（CVO 反馈）

1. **音量弹层未对齐其它弹层行为**：播放器的音量弹层打开后，鼠标移出播放器时控制栏仍会隐藏、
   音量弹层自身也随之关闭；而章节面板、弹幕/字幕设置、发弹幕、画质/音轨/倍速菜单打开时，
   控制栏与弹层都保持外露。要求音量弹层与其它控件弹层口径一致。
2. **投币浮层对角线动画方向不对**：投币互动正上方的浮层出现/消失时，缩放原点不在浮层自身
   **正下方底边中心**，观感为斜向漂移；要求以浮层底边中心为缩放点（从该点放大 / 缩回该点）。
3. **评论互动操作缺少胶囊容器**：每条评论的点赞、点踩、回复、展开/收起回复仍是裸
   `GestureDetector` + 图标/文本，点击命中区只覆盖内容本身；要求统一套 Miuix 设计规范的胶囊
   容器、整块可点击，并把图标与文本整体增大到评论正文行高的 70%。
4. **楼中楼末条回复缺少展开/收起入口**：楼中楼展开后，只有根评论操作行有
   「展开/收起 N 条回复」，末条回复操作行没有；要求在最末条回复的「回复」右侧复用
   「展开回复 / 收起回复」，未加载完时两者并存，收起一次性折叠整串，展开沿用分批加载；
   底部「查看更多回复」按钮保留且仍可点击加载。

## 二、问题定因

### 2.1 音量弹层（`lib/pages/video/player_panel.dart`）

控制栏隐藏入口 `_hideControlsNow()` 原实现为：

```dart
if (_popupSuspend > 0 && !_volumePopupOpen) return; // 其它弹层保持显示
_controlsVisible.value = false;
if (_volumePopupOpen) _setVolumePopupOpen(false);   // 音量弹层单独关闭
```

即**音量弹层被显式排除**在「弹层挂起」保护之外：鼠标移出播放器时，控制栏隐藏且音量弹层被
强制关闭，而其它弹层靠 `_popupSuspend > 0` 保持外露。两套口径分叉导致反馈现象。

### 2.2 投币浮层（`lib/pages/video/coin_dialog.dart` + `lib/core/shell/app_dialogs.dart`）

投币浮层通过 `showAppDialog` 打开，`AppDialogRoute.buildTransitions` 使用
`FadeTransition + ScaleTransition`，且 `ScaleTransition` 默认 **`Alignment.center`**，
作用于整页（`Stack` 铺满全屏）而非浮层自身。缩放原点落在整页中心，浮层相对投币按钮出现
斜向漂移；浮层自身没有独立的底边中心缩放。

### 2.3 评论互动胶囊（`lib/pages/video/detail_page.dart`、`lib/pages/bangumi/bangumi_player_page.dart`）

主评论与楼中楼操作行均为：

```dart
Row(spacing: Style.lg, children: [
  GestureDetector(onTap: ..., child: Row(icon + Text(fontSize: 12/11.5))),
  ...
])
```

- 无胶囊底衬与整块命中区，点击只命中图标/文本内容；
- 字号固定 12 / 11.5，未按评论正文行高比例推导；
- 演示模式 `_DemoReplyTile` 复用同一裸按钮形态，需保持 1:1。

### 2.4 楼中楼末条回复（同上两页）

楼中楼只有根评论操作行的 `_toggleSubReplies`（展开/收起整串）与列表底部的
「查看更多回复」按钮（`_loadSubReplies` 分批加载）。末条回复操作行只有点赞/点踩/回复，
无展开/收起入口；且收起逻辑未处理「加载中收起」的竞态，响应回来会重新撑开已收起的整串。

## 三、修复方案

### 3.1 音量弹层对齐其它弹层

- `_hideControlsNow()` 改为统一由 `_popupSuspend > 0` 把关，删除音量弹层特判与强制关闭：
  弹层打开期间鼠标移出播放器不再隐藏控制栏、不再关闭弹层。
- 为保持「锁定控制条」会把整条控制栏移出子树的既有语义，锁定前先关闭音量弹层
  （`_toggleLock` 与 `PlayerFocus.onLockToggle` 两处），避免弹层悬空。
- 用 Flutter `TapRegion` 把「音量按钮 + 音量弹层」编成同一**全局点击分组**：
  - 分组内点击（音量按钮 / 弹层面板）不触发关闭，按钮仍走原有开关；
  - 分组外点击（含播放器以外的整页区域）触发 `onTapOutside` 关闭弹层；
  - `consumeOutsideTaps: true` 阻止外部点击穿透到底层控件，与菜单/章节面板等模态弹层一致。
- 首版曾用播放器内 `Positioned.fill` 透明层，只能覆盖播放器区域；反馈轮 1 已改为
  `TapRegion` 全局分组，点击播放器以外区域同样触发关闭。

### 3.2 投币浮层底边中心缩放

- `AppDialogRoute` / `showAppDialog` 新增 `enableScale`（默认 true，其它弹层行为不变）。
- 投币浮层传 `enableScale: false`，关闭路由级整页中心缩放；`_CoinPopup` 自身用
  `ScaleTransition(alignment: Alignment.bottomCenter)` 驱动面板，动画时钟复用
  `ModalRoute.of(context).animation`，因此展开/收起两段动画都以浮层**正下方底边中心**
  为原点，且与路由淡入淡出同步。

### 3.3 评论互动 Miuix 胶囊容器

- 新增共享组件 `lib/common/widgets/comment/comment_action_pill.dart`：
  - `MiuixPressable` + `MiuixPressFeedbackType.sink`（0.98）提供整块按压/悬停反馈；
  - 全圆角胶囊底衬（`surfaceContainerHighest` α0.35），最小 24×24 命中区；
  - 图标尺寸走 `appRowIconSize(context, fontSize)`，与同行标签同口径；
  - 支持 `labelWidget`（演示模式可内联编辑的点赞计数）。
- 视频详情页与番剧播放页的主评论、楼中楼操作行统一改为 `Wrap + CommentActionPill`；
  行内间距 8、换行间距 4，窄栏自动换行，避免长计数/长标签溢出。
- 字号口径：主评论 `14.5 × 1.55 × 0.7 ≈ 15.7`；楼中楼 `13.5 × 1.5 × 0.7 ≈ 14.2`
  （= 评论正文行高的 70%）。演示模式 `_DemoReplyTile` 同步切换为胶囊形态，保持 1:1。

### 3.4 楼中楼末条回复展开/收起

- `_buildSubReplyTile` 增加 `isLast` 参数；末条回复操作行在「回复」右侧追加：
  - `!subEnd` 时显示「展开回复」（加载中显示环形进度并禁用点击）+「收起回复」；
  - `subEnd` 时仅显示「收起回复」。
- 新增 `_collapseSubReplies(root)`：一次性移除该根评论的 `_subReplies/_subPage/_subEnd/_subLoading`，
  即收起整串已展开回复；「展开回复」继续调用原 `_loadSubReplies(root)`，保留页码分批加载能力。
- 底部「查看更多回复」按钮保持原样、仍可点击加载。
- 在 `_loadSubReplies` 请求返回后补 `if (!_subReplies.containsKey(rpid)) return;`：
  加载中若已收起，丢弃迟到响应，避免收起后被重新撑开。

## 七、反馈轮 1（音量弹层外部点击未覆盖播放器以外）

### 7.1 现象

初版把外部点击关闭层挂在播放器 `Stack` 内（`Positioned.fill`），只能覆盖播放器区域；
点击播放器以外的页面区域（标题、简介、评论区等）不会关闭音量弹层。而其它控制栏弹层
（菜单 / 章节面板 / 设置对话框）的遮罩挂在根层，点击播放器以外同样会关闭。

### 7.2 定因

`_PlayerPanel` 只是播放器面板子树，其内部 `Positioned.fill` 的命中范围止于播放器边界；
播放器以外的页面区域在该子树之外，点击事件根本不会进入该关闭层。

### 7.3 方案

- 删除播放器内透明关闭层；
- 用 Flutter `TapRegion` 把「音量按钮 + 音量弹层面板」编入同一 `groupId`：
  - 分组内点击（按钮 / 面板）不触发关闭；
  - 分组外点击通过 `onTapOutside` 关闭，覆盖 `WidgetsApp` 的整个 `TapRegionSurface`
    （即播放器内外全窗口）；
  - `consumeOutsideTaps: true` 让外部点击被消费，不穿透到底层控件，与模态弹层一致。
- 该实现依赖项目 `AppShell` 的 `WidgetsApp` 自带 `TapRegionSurface`，无需额外挂根层遮罩。

## 八、反馈轮 2（章节面板点击播放器外部不关闭）

### 8.1 现象

章节面板（右侧滑出面板）打开后，只有点击播放器内部的遮罩区域才会关闭；点击播放器以外的
页面区域（标题、简介、评论区等）不会关闭。与音量弹层反馈同类。

### 8.2 定因

章节面板的 Dismiss 遮罩同样是播放器 `Stack` 内的 `Positioned.fill`，命中范围止于播放器
边界；播放器以外的页面区域不属于该子树，点击无法触发面板关闭。

### 8.3 方案

- 在 `_buildChapterPanel` 的 `Positioned.fill` 内包一层 `TapRegion`（`groupId =
  _chapterTapGroup`），仅在 `_chapterPanelOpen` 时启用；
- 面板区域（播放器内）作为 TapRegion 的"内部"：播放器内点击仍由原遮罩关闭；
- 播放器外任意区域作为"外部"：触发 `onTapOutside` 调用 `_setChapterPanelOpen(false)`；
- `consumeOutsideTaps: true` 消费外部点击，不穿透到底层控件；
- 面板自身的滚动、章节点击、关闭按钮均在 TapRegion 内，不受影响。
