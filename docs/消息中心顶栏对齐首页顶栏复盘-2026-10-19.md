# 消息中心顶栏对齐首页顶栏复盘（2026-10-19）

> 主题：消息中心（`WhisperPage`）顶栏容器毛玻璃背景的**颜色 / 亮度**与整页背景、首页顶栏不一致。
> 定性：**材质单一来源缺失**（两处顶栏各写一份、且不同源的毛玻璃）。
> 类型：实机反馈修复 · 跨页横切（P4 一处定义）。

---

## 一、现象描述

CVO 实机反馈原话：

> 「消息中心的顶栏容器背景模糊看起没有对齐程序整体仓库背景颜色和亮度，导致看起来不和谐，请将消息中心顶栏对齐首页的顶栏背景设计。」

即：进入「消息」页，顶部那块「互动入口行（回复/艾特/点赞/系统）+ 分隔线 + 分类栏」的合并栏，其毛玻璃底色相对**整页背景的亮度/色相**明显不搭；对照「首页」顶部「搜索框 + 分类器合并栏」，两处观感不一致。

---

## 二、问题根因

两处顶栏**各写一份毛玻璃材质，且参数不同源**：

| 项 | 首页 `_HomeHeader`（`lib/ui/home/home_page.dart`） | 消息中心 `_buildFrostedHeader`（`lib/pages/whisper/view.dart`） |
|---|---|---|
| 半透明底色 | `cs.surface` × **0.72**（跟随主题面） | `MiuixFrostedSurface` 硬编码 `0xFF262626`(暗) / `0xFFEAEAEA`(亮) × `kMiuixSurfaceAlpha` **0.85** |
| backdrop 模糊 | `ImageFilter.blur` σ = **20** | σ = **16** |
| 容器圆角 | `chrome.containerRadius` = **20** | `Style.radiusMd` = **12** |
| 外距 | `Style.lg / Style.sm` | `Style.lg / Style.sm`（同） |

关键差异 = **第 1 行「底色」**：消息中心的底是**写死的灰** `0xFF262626/0xFFEAEAEA`，**不随主题 `surface` 走**；而首页用的是主题 `cs.surface` 的 72% 半透明。叠加融合后，消息中心顶栏的亮度/色相与整页背景面（`cs.surface` 系）不在同一「材质谱」，故显得不和谐。第 2、3 行的模糊强度与圆角差异进一步放大了不一致感。

根因一句话：**「App 顶部合并栏毛玻璃」这一概念在项目里被定义了两处、且取值不同**（违反 P4「每个概念只在一处定义」），首页那套是用户认可的基准，消息中心那套是旁支。

---

## 三、修复方法

**收敛为单一来源**：抽出新组件 `AppTopBarSurface`（`lib/common/widgets/app_top_bar_surface.dart`），把**首页那套材质**固化为唯一实现，两页共用。

```
AppTopBarSurface
  = Padding(h: Style.lg, v: Style.sm)
  + ClipRRect(radius = chrome.containerRadius)
  + BackdropFilter(blur σ = blurSigma)
  + Container(color = barColor, radius, border: α0 × 0.5px)
其中：surfaceAlpha = 0.72，blurSigma = 20，
      barColor = AppTopBarSurface.barColor(cs.surface) = cs.surface × 0.72
```

改动落点（3 文件）：

1. **新增** `lib/common/widgets/app_top_bar_surface.dart`：`AppTopBarSurface` 组件。除材质外，把底色口径做成静态成员——`static const surfaceAlpha = 0.72` / `static const blurSigma = 20` / `static Color barColor(Color surface)`——供「容器上色」与「前景色对比度解析」共用，避免 `cs.surface.withValues(alpha: 0.72)` 再被写第二遍而漂移。
2. **改** `lib/ui/home/home_page.dart`（`_HomeHeader`）：删掉内联的 `Padding + ClipRRect + BackdropFilter + Container`，改 `return AppTopBarSurface(child: headerContent);`；`barColor` 改取 `AppTopBarSurface.barColor(cs.surface)`；移除后失效的 `final chrome = tokens.chrome;` 与 `final barRadius = chrome.containerRadius;`，并移除仅存此处用到的 `import 'dart:ui';`。
3. **改** `lib/pages/whisper/view.dart`（`_buildFrostedHeader`）：`Padding + MiuixFrostedSurface(...)` 整体换为 `AppTopBarSurface(child: Column(...))`（内容不变：入口行 padding + 分隔线 + `SessionFilterBar` + `_filterBarBottomGap`）；import 由 `miuix_frosted_surface.dart` 换成 `app_top_bar_surface.dart`；doc 注释同步更新。

**副产物（顺带消解）**：新材质不含面板 4px 下投影（首页口径本就没有），故消息中心旧面板「自身投影画在 `BackdropFilter` 之前 → 被模糊核从下缘向内采样 → 分类栏一行糊出发白浸润带」的**成因随材质替换一并消失**——此前靠 `MiuixFrostedSurface(shadow: false)` 规避的问题不再存在。

## 五、遗留与踩坑

1. **顶栏 vs 浮层弹层材质分工**：`MiuixFrostedSurface`（含「边缘无渐变」`_edgeSafeFrost` 外扩 + 可选描边/投影）仍是**浮层**类（`MiuixOverlayPanel` / `MiuixPopupMenu` / 页内浮起面板）的材质来源，本次**未改**它；顶栏合并栏改走 `AppTopBarSurface`。两者用途不同、不冲突。若后续发现「首页/消息顶栏在其自身边缘也存在模糊核夹断渐变」，再评估是否给 `AppTopBarSurface` 引入同款外扩（首页当前无此反馈）。
2. **顶栏外距口径**：`AppTopBarSurface` 把外距 `Style.lg / Style.sm` 也纳入内部，两页不再各自 `Padding`。若将来某页顶栏需要不同外距，需给组件加参数——目前两页一致，保持最小面。
3. **Release 被占用进程锁 DLL**：本机运行中的 `winwin.exe` 会锁 `WebView2Loader.dll`；**必须按 PID** 关闭（单条 `taskkill /PID <n> /F`），**绝不可按进程名批量杀**（会误杀宿主）。
4. **`python` 噪声**：`python -c` 输出 `certifi_win32 ... KeyError: 'LOCALAPPDATA'`——沙箱缺 `LOCALAPPDATA` 的无害噪声，不影响写文件。
5. **未做项**：未跑 `flutter test`（本机历史性崩溃，以静态分析 + 双编译替代）；未做「改动后截图 vs 原截图」逐像素回归（需用户实机截图）。

## 六、总结

消息中心顶栏「颜色亮度不搭」的根因**不是**某页参数调错，而是**同一个「顶栏毛玻璃」概念被定义了两处且不同源**：首页用主题 `surface`×0.72 的半透明（随主题），消息中心用写死的 `0xFF262626/0xFFEAEAEA`×0.85（不随主题），再加模糊 20 vs 16、圆角 20 vs 12 的三重差异。

修法照 P4 落：抽出 `AppTopBarSurface` 把首页那套材质固化为**唯一来源**，首页与消息中心两页共用——两页同源即天然对齐，并杜绝再度漂移；顺带消解了消息中心旧面板下投影自采样导致的分类栏发白浸润带。静态分析 0/0、debug 32.7s、release 45.9s 三连通过；提交 `bb48174`，回滚 `56fa55f`。
