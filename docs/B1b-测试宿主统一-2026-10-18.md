# B1b · 测试宿主 harness 统一（2026-10-18，首批 12/19）

## 目标

test 面去 `package:material_ui`：以**统一测试宿主**替换各测试文件手搭的
`MaterialApp` / `Scaffold` 外壳，为 test 面归零（B1b）铺路。纯 test 基建，
**不触碰 lib**。

## 改动

### 新增 `test/support/app_test_host.dart`

- `Widget appTestHost(Widget child, {...})` —— 函数式宿主。
- `class AppTestApp` —— `MaterialApp` 同形零-material 替身（子集：`home` /
  `navigatorKey` / `navigatorObservers` / `escapeObserver` / `dark` /
  `fontFamily` / `title` / `debugShowCheckedModeBanner` / `theme`〔兼容入参，不参与装配〕）。
- `class AppTestScaffold` —— `Scaffold` 同形替身（`body` / `appBar` /
  `backgroundColor` / `resizeToAvoidBottomInset`）。
- 宿主链路与 `AppShell` 同构：`AppThemeHost(tokens)` → `ScrollConfiguration(AppScrollBehavior)`
  → `WidgetsApp(pageRouteBuilder: appPageRouteBuilder, home)`，`builder` 链 =
  `AppEscapeScope` → `MiuixThemeScope` → `MiuixToastHost` → `DefaultTextStyle`。
- **与 `AppShell` 的有意差异**：**不含** `ImmersiveTitleBarShell`（Windows 窗口标题条
  属宿主外壳 / 平台关注点，见「踩坑」）。
- 本文件**不** import `package:material_ui`（B1b 门槛）。

### 迁移 12 个 test 文件（import → `flutter/widgets` + 宿主替换 + 符号替换）

`skeleton` / `demo_mask` / `miuix_selection_context_menu` / `danmaku_controller` /
`system_font_scanner` / `app_tooltip_lifecycle` / `chapter_panel` /
`badges_and_interaction` / `glass_contrast_widgets` / `select_dialog` /
`toast_probe` / `app_escape_scope`。

符号替换口径：

- `MaterialApp(` → `AppTestApp(`；`Scaffold(` → `AppTestScaffold(`。
- `TextButton` → `GestureDetector` + `Padding` + `Text`（测试内发信按钮）。
- `Colors.white/black/blue/...` → 字面 `Color(0x…)`。
- `Icons.x` → `AppGlyphs.x`（b7-d 载体，同 codePoint）；`AppGlyphs` 未含者
  （如 `star` / `play_arrow`）改用测试局部 `const IconData` 载体。
- `find.byType(Switch)` → runtimeType 谓词（避免直接引用 material 类型）。
- `TextField` → `AppTextField`；`showDialog(AlertDialog)` → `showAppDialog(AppAlertDialog)`
  （`app_escape_scope`）。

## 踩坑

1. **标题条即元凶**：首版 harness 直接用 `AppShell` 作宿主，`miuix_selection_context_menu_test`
   两条用例失败（右键 Miuix 菜单不弹）。根因 = `AppShell` 的 `ImmersiveTitleBarShell`
   （窗口标题条）改变了指针命中 / 布局；改为**自建轻量宿主**（同链路、去标题条）后复绿。
   教训：widget 测试宿主不应包含平台外壳层（窗口标题条）。
2. **相对 import 层级**：`test/ui/components/` → `test/support/` 是**上两级**
   （`../../support/app_test_host.dart`），首版误写一级。
3. **导入路径**：`app_theme_host.dart` 位于 `core/shell/`（同 `app_shell`），非 `theme/`。
