# 余批（2026-10-18，7 → 4）

## 目标

清掉首批遗留 7 文件中「可落地」的 3 个（`theme/app_icons_test` /
`pages/player_slider_test` / `ui/components/miuix_adoption_test`），并把 3 个 shell
文件与 `tools/icon_sheet_test` 生成器**定性登记**（前者随 b7-e，后者豁免）。

## 现象 → 定因 → 方案

- **`theme/app_icons_test`**：`Icons.*` 图标表断言 + `MaterialApp` / `Scaffold` 宿主。
  定因＝直接引用 material 图标与宿主。方案＝`Icons.subtitles_outlined` /
  `alternate_email_rounded` / `campaign_outlined` → `AppGlyphs.*`（同 codePoint）；
  `arrow_back(0xe092)` / `more_vert(0xe404)` 未入 `AppGlyphs` → 测试局部
  `const IconData(…, fontFamily:'MaterialIcons')`；宿主替换为 `AppTestApp` / `AppTestScaffold`。
- **`pages/player_slider_test`**：以 material `Slider` 为载体测「seek 派发」。
  定因＝`MiuixSlider` API 不兼容 —— **无 `onChangeStart`**；点击只触发 `onValueChanged`，
  拖拽结束才触发 `onValueChangeFinished`，且结束回调**不带值**。方案＝把「点击」用例改为
  **拖拽**用例（`startGesture(center) → moveBy(+60,0) → up`），在 `onValueChangeFinished`
  用最后值按**毫秒精度**派发 seek；断言放宽为 `dispatchedSeek != null`、`== position.value`、
  `.inMilliseconds == (lastValue*1000).round()`、`> 50000`（保留「无整秒跳变」精度契约）；
  宿主 → `AppTestApp` / `AppTestScaffold`。
- **`ui/components/miuix_adoption_test`**（最重）：重度 material 符号 + 源码级断言。
  方案＝`MaterialApp` / `Scaffold` → 容器宿主；`wrapMiuix` 直接改用 `AppTestApp(dark:…, home:…)`
  （宿主已内置 `MiuixThemeScope` + `MiuixToastHost`，故**去掉**手工 `MiuixThemeScope` 与
  显式 `MiuixToastHost` —— 避免**双重宿主导致 Toast 卡片重复**）；`TextButton` →
  `GestureDetector` + `Text`；`showDialog<double>` → `showAppDialog<double>`；
  `find.byType(Switch/SnackBar/RefreshIndicator)` → runtimeType 谓词；`Colors.blue/pink` →
  字面 `Color(0x…)`；`Icons.code` → `AppGlyphs.code`、`Icons.settings/search` → 局部
  `const IconData`、`Icons.volunteer_activism_outlined` → `AppGlyphs.*`。

## `tools/icon_sheet_test`：**豁免（随 B7 / generator 处置）**

- **尝试迁移**：`Icons.*` → `AppOldGlyphs.*`（新增 `test/tools/material_old_glyphs.g.dart`，

## 踩坑

1. **`replace_all` 子串误伤（本批两起）**：① `Icons.` → `AppOldGlyphs.` 命中 `AppIcons.` 的
   子串，生成 `AppAppOldGlyphs.`；② 手工写入 `AppTestScaffold(` 后再 blanket
   `Scaffold(` → `AppTestScaffold(`，生成 `AppTestAppTestScaffold`。教训：`replace_all` 前先
   确认目标 token **不是其它标识符的子串**，或先改「包含关系较短」的再改较长的；改完全局

   `APPDATA` / `LOCALAPPDATA` / `USERPROFILE` / `HOME`）。
3. **生成器测试会写库内产物**：任何触动其渲染宿主的改动都可能重生成 `docs/icon-sheets/**`；
   改此类生成器务必**单跑并 `git status` 核对产物**，避免污染已提交位图。
