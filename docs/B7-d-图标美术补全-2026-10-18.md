# B7-d 图标美术补全 复盘（2026-10-18）

## 背景

- 承接 B7-c7 残余收口批第三批：`lib/` 内 import `material_ui` 的闸门已降至 **5 文件**，其中两处为**字形载体**残点（此前各批复盘统一登记为「归 b7-d 美术替换」）：
  - `lib/theme/app_icons.dart`：`Icons.xx` **87 处**（`AppIcons` 语义方法的字形载体）；
  - `lib/common/widgets/level_icon.dart`：`Icons.bolt_rounded` **2 处**（Canvas 字体渲染载体）。
- 另 3 文件属他批：`app_theme.dart` / `app_shell.dart`（`ThemeData` 族 → b7-e）、`member_space_page.dart`（Sliver 族，**保留·待专项**）。

## 目标

1. **载体去库**：消除上述两文件对 `material_ui` 的依赖，使闸门 **5 → 3**。
2. **美术补全**：对「无矢量、当前回退 Material 字体」的字形，按项目既有映射惯例补 Miuix 矢量；无同语义对应者保留并登记。
3. **零回归**：载体替换**逐像素不变**（见下「关键决策」）；映射项为预期的观感升级，随实机对照验收。

## 关键决策：为何是「项目自有字形表」而非直接换字形

`AppIcons` 的字形不是终点，而是**查表键**：`AppIcon` 经 `miuixVectorForGlyph(glyph)` 按 **codePoint** 依次查 BDC / Web / BiliSite / Official / Art / 三集映射 / Builtin 七层矢量。因此：

- 若直接把载体换成别的字形（如 Cupertino 近似形），**codePoint 改变 → 矢量层失配 → 已上线的 B站/官方美术全部回退**，必产生大面积观感回退。
- 故本批新增**项目自有载体** `lib/theme/app_glyphs.g.dart`：从 material_ui `icons.dart` **原样抄录** `(codePoint, fontFamily: 'MaterialIcons')`。
  - codePoint 完全相同 → 矢量命中结果**不变**；
  - fontFamily 仍为 `'MaterialIcons'`（该字体由 **Flutter SDK 自带**，与 material_ui 包无关）→ 未命中矢量的字形回退渲染**逐像素不变**；
  - 仅解除对 `material_ui` 的 import 依赖。

即：**载体替换 = 零视觉变化**；观感变化只来自 §美术补全 的显式映射。

## 遗留与踩坑

- **踩坑 1（生成器幂等）**：首版生成器仅扫描 `Icons.`，而替换后源码已无 `Icons.` → 重跑产出**空表**，引发 88 处 `undefined_getter`。修正：扫描识别 `(?:Icons|AppGlyphs)\.`。教训：**代码生成器要对「已迁移态」幂等**，否则二次运行即自毁。
- **踩坑 2（CRLF）**：`io.open(newline="")` 读入保留 `\r\n`，而替换串写作 `...;\n` → import 行**静默 MISS**（正则替换因不含行尾故命中）。教训：行级替换须兼容 `\r?\n`（与 B7-c2「踩坑 3 行尾」同族，第二次踩中）。
- **踩坑 3（lint 名）**：`// ignore_for_file: non_constant_identifier_names` 写错 → 应为 `constant_identifier_names`（66 条 info）。
- **保留点**：52 枚回退字形（见上）；b7-d 不引入新依赖；生成器留在 `tools/` 供复现。
