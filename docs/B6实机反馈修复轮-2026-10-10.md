# B6 实机反馈修复轮复盘（四项）— 2026-10-10

> 承接 B6 全线收官后的首轮实机复测反馈（用户四项），逐项修复。

## 1. 现象描述（用户反馈原文）

1. 按压反馈效果是卡片整体变暗，而不是涟漪效果；
2. 看图预览界面顶部出现空白预留（图片未顶到顶）；「1/1」标注应移顶部居中，
   「下载/复制/关闭」应移到底部垂直偏上并水平居中，按钮加大到全局返回按钮
   统一尺寸并保留半透明度；
3. 有右键弹层菜单的地方偶尔无法长按触发；
4. 下拉刷新指示器被某些页面顶栏控件遮挡（经确认：首页与消息中心被遮挡；
   评论区与用户空间缺失下拉刷新）。

## 2. 问题根因

1. `MiuixPressable` 默认 `feedbackType = none`：按压仅叠加 ~10% 的
   `onBackground` 遮罩 → 整卡均匀变暗、无微缩（口径已确认改为"下沉微缩"）。
2. 画廊预览页根为 `AppScaffold` 且未关预留：默认 50px 顶安全行 + 悬浮返回
   按钮 → 顶部留白；序号与三按钮挂在顶栏行（用户期望：序号顶部居中、
   按钮组底部居中偏上）。
3. 长按菜单依赖 `lastTapPosition`（仅 `onSecondaryTapDown` 写入）：**从未
   右键过时 `lastTapPosition == null` → 长按静默失效**；且长按用的是"上次
   右键的位置"而非当前按压点。
4. 首页（热门/推荐）为浮动顶栏(52)+分类行(36) 叠在滚动区之上（页内预留
   120px），刷新指示器固定在其下方被遮挡；消息中心与会话列表的刷新作用域
   挂在页头之下（观感为局部而非页面级）；评论区原本无刷新入口；用户空间
   `NestedScrollView` 内层滚动通知带 depth>0，外层指示器接不住内层下拉。

## 3. 修复方案

1. **按压反馈**：全部 73 处 `MiuixPressable` 统一补
   `feedbackType: MiuixPressFeedbackType.sink` + `sinkAmount: 0.98`——
   按下叠加 ~2% 微缩（动效主导），"整体变暗感"显著降低（脚本批量 + 导入合并）。
2. **画廊预览改版**（`image_gallery_viewer.dart`）：
   - `reserveTopStrip: false, showBackButton: false` → 图片真正全屏顶边；
   - 顶部仅保留序号胶囊、**水平居中**（渐变底保留保证可读性）；
   - 新增**底部操作栏**：保存/复制/关闭 三按钮水平居中、`SafeArea + bottom 28`
     偏上；`minWidth/minHeight: 42` 对齐全局返回按钮、图标 18→20；
     背景保持 `black@0.4` 半透明。
3. **长按修复**（6 站点：视频卡 H/V、演示遮罩×2、收藏、稍后再看）：
   长按回调从 `MiuixPressable.onLongPress`（无位置）外提为外层
   `GestureDetector.onLongPressStart`，**直接取当前按压点**弹菜单；删除
   `lastTapPosition` 机制（含 `onSecondaryTapDown` 捕获）——长按恒定可用、
   位置准确；右键 `onSecondaryTapUp` 同级保留不变。
4. **下拉刷新**：
   - 首页（`hot`/`rcmd`）：指示器加 `edgeOffset: 88` + `displacement: 24`
     （88 = 浮动顶栏 52 + 分类行 36），下拉指示器从其下方出现、不被遮挡；
   - 消息中心（`whisper/view`）与会话列表页：刷新作用域上提为**包裹整页正文**
     （四入口/分类 chips 也在其内）——指示器浮于页头之上（图层最高）；
   - 评论区（视频详情右栏）：`AppRefreshIndicator` 包裹评论列表，下拉
     重拉首页评论（`_loadReplies(refresh: true)`），列表补
     `AlwaysScrollableScrollPhysics`；
   - 用户空间：每个页签内容再包一层 `AppRefreshIndicator(_loadAll)`
     （解决 NestedScrollView 内层通知 depth>0 外层接不住的问题）；
     外层保留，覆盖头图区拖拽。

## 5. 遗留与踩坑

- 遗留：评论区**窄屏单列（sliver 版）**未加下拉刷新（宽屏右栏 Tab 已加，
  Windows 桌面主用宽屏；如窄窗常用可补）。
- 踩坑：① `MiuixPressable` 无 `onLongPressStart`——带位置的长按必须外提
  到 `GestureDetector`；② 演示遮罩的菜单调用是**位置参数**
  （`_showDemoCardMenu(context, pos, seed)`），脚本只识别命名参数，需手工补；
  ③ 仓库工作区文件为 **CRLF**，Node 批处理正则必须 `\r?\n` 容错；
  ④ `NestedScrollView` 场景判断刷新是否被接住，关键看通知 depth。

## 7. 测试验证指导（本轮产物）

- **按压反馈**：首页/收藏/历史/动态/成员的视频卡与动态卡——按下为轻微
  下沉微缩 + 轻遮罩（不再整卡明显变暗）；小控件同步微缩。
- **画廊预览**：打开任意图片预览——图片顶到屏幕最顶端（无 50px 留白）；
  序号胶囊在**顶部居中**；下载/复制/关闭三按钮在**底部居中偏上**、
  尺寸 42、半透明黑底；Esc/关闭按钮/下滑关闭照常。
- **长按菜单**：冷启动后直接**长按**任意视频卡（不经右键）→ 菜单应在按压点
  弹出；右键同样弹出；收藏/稍后再看卡片同验。
- **下拉刷新**：首页（热门/推荐）下拉——指示器出现在分类行下方、不被遮挡；
  消息中心/会话列表下拉——指示器浮在四入口/分类 chips 之上；视频详情
  评论区下拉——重拉评论；用户空间各页签（投稿/动态等）下拉——触发刷新。
- **日志**：复测后核对 `D:\Documents\.winwin_logs.json` 与
  `D:\Documents\logs\runtime.log` 有无新增条目。
