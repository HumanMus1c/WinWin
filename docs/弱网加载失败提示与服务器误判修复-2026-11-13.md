# 弱网加载失败提示与「服务器连接失败」误判修复（2026-11-13）

## 一、现象

弱网环境下加载视频详情失败时，界面只弹出类似「服务器连接失败」的 toast，而不是用户可读的「网络较慢，请检查网络或更换网络环境」；详情页可能停留在加载态，没有页内错误说明与重试入口。

## 二、定因

### 1. 实际错误是客户端网络超时，不是服务器故障

`D:\Documents\logs\blackbox_api.log` 在 2026-11-13 弱网时段记录：

- `14:18:59` GET `/x/v2/history/toview/web` → `DioExceptionType.receiveTimeout`（10027ms）
- `14:21:51` POST `/x/click-interface/web/heartbeat` → `receiveTimeout`（12109ms）
- `14:21:59` ~ `14:26:34` 多次 POST heartbeat → `connectionTimeout`（约 10s）
- 同一时段其余请求均为 HTTP 200；**没有任何 5xx、502/503/504 或服务端错误响应**。

`runtime.log` 同一时刻的记录也是 `HeartBeat: exception ... receive timeout`。因此结论是：**没有真实发生服务器连接失败，根因是本地网络到 B 站 API 的连接/响应超时**，旧文案把客户端网络问题误报成了服务器问题。

### 2. 旧提示链路把技术细节暴露给用户

- `dioErrorMessage` 对超时返回「网络连接超时/响应超时」，不是弱网场景可直接理解的建议；
- `AccountManager.dioError` 对 `unknown` 直接拼接 `error.error`，可能带出 `Connection failed` 等英文原始异常；
- `AccountManager.toast` 统一拼接 `'请求错误：$res\n$url'`，把请求 URL 和异常细节一起展示；
- `VideoHttp.videoIntro` 没有 `try/catch`，弱网时异常直接抛出，详情页停留在 Loading，只能依赖全局 toast，没有页内错误态与重试按钮。

## 三、方案

- [dio_error_message.dart](file:///d:/Documents/GitHub/WinWin/lib/http/dio_error_message.dart)：
  - 超时（connection/send/receive/transform）统一提示「网络较慢，请检查网络或更换网络环境」；
  - 连接中断提示「网络连接失败，请检查网络或更换网络环境」；
  - 仅 HTTP 5xx 提示「服务器暂时不可用，请稍后重试」；401/403、404 分别给出对应提示；
  - 非 Dio 异常不再输出原始 `Exception`，改为「加载失败，请稍后重试」。
- [account_mgr.dart](file:///d:/Documents/GitHub/WinWin/lib/core/account/account_mgr.dart#L189-L215)：
  - `dioError` 复用统一文案；
  - 全局 toast 只显示用户可读文案，不再拼接 URL/原始异常；
  - 支持请求级 `extra['silent'] == true` 静默，避免页面已有错误态时再弹技术性 toast。
- [video.dart](file:///d:/Documents/GitHub/WinWin/lib/http/video.dart#L170-L192)：
  - `videoIntro` 增加 `try/catch`，失败返回 `Error(dioErrorMessage(e))`，详情页据此展示播放区错误文案与「点击重试」；
  - `videoIntro`、`playInfo`、`onlineTotal`、`videoTags` 标记 `silent`，后台增强请求失败不再打扰用户。
- 新增 [dio_error_message_test.dart](file:///d:/Documents/GitHub/WinWin/test/http/dio_error_message_test.dart)：覆盖超时、断网、5xx、401/403、404、取消、证书、非 Dio 异常 6 组文案。

## 六、遗留与踩坑

1. **实机弱网待复测**：需断网/限速后打开视频详情，确认显示「网络较慢，请检查网络或更换网络环境」+「点击重试」，且不再出现技术性 toast；恢复网络后重试应正常加载。
2. **其他页面仍可能弹全局 toast**：本次只给详情主数据与后台增强请求加了 `silent`；如「稍后再看」等页面弱网失败仍有提示，但文案已统一为用户可读文本，不再暴露 URL/原始异常。
3. **未发现真实服务端故障**：日志中没有任何 5xx；若后续出现 5xx，新文案会明确提示「服务器暂时不可用」，与本地弱网区分。

## 七、主动弱网判定（2026-11-13 补充）

- 现象：进入弱网后界面只进入缓冲，需等到某次请求失败才出现提示；用户无法及时判断是网络问题。
- 方案：
  - 新增 [weak_network_detector.dart](file:///d:/Documents/GitHub/WinWin/lib/core/network/weak_network_detector.dart)：全局单例统一判定与提示；
  - HTTP 信号：`WeakNetworkInterceptor` 采集请求总耗时（含重试），≥3 秒或连接/响应超时即判定弱网；
  - 播放信号：`PlayerController` 在流速连续不健康 ≥3 秒，或缓冲停滞 ≥3 秒时上报；
  - 回合去重：一次弱网只提示一次；连续健康 ≥10 秒后重置回合，并保留 60 秒跨回合冷却；
  - 提示文案「网络较慢，请检查网络或更换网络环境」，同时写 `WeakNetwork: prompt` 运行日志便于核对。
- 验证：`dart analyze` **No issues found!** / `flutter test` **317 项全过**（新增 5 项）/ `windows --debug` **√ Built**（26.8s）/ `--release` **√ Built**（64.6s）。
- 提交：`eb905cd`；回滚：`git reset --hard d878647`。
- 调参：3 秒判定、10 秒健康重置、60 秒冷却均为可调参数；若实机误报/漏报，优先调整 `WeakNetworkDetector` 构造参数与播放器门限。

## 八、总结

弱网失败被误报为「服务器连接失败」的根因是客户端超时文案与全局 toast 拼接技术细节，而非真实服务端故障。本次统一了弱网/服务端错误文案，补上详情页 `videoIntro` 的异常兜底与静默策略，使弱网时由页内错误态和重试按钮承接；并新增主动弱网判定（HTTP 慢响应/超时或播放流速异常 ≥3 秒即提示一次），避免必须等到失败才反馈。静态分析零问题、317 项测试与 Windows debug/release 双编译均通过。实际弱网 UI 效果需按 §六 步骤复测。
