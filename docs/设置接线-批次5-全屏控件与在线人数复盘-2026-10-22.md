# 设置接线-批次5（全屏控件显隐 + 显示在线人数）复盘

> 日期：2026-10-22　范围：`showFsLockBtn` / `showFsScreenshotBtn` / `enableOnlineTotal`
> 代码提交：`ea379a1`　快照基准：`610647f`（批次 5 前 HEAD）

## 一、现象描述

设置页以下三项写入 Hive 后，实际播放/详情页无任何行为变化：

1. **全屏显示锁定按钮**（`showFsLockBtn`）：全屏下锁定按钮不受开关控制。
2. **全屏显示截图按钮**（`showFsScreenshotBtn`）：全屏下无截图按钮入口（开关无效）。
3. **显示在线人数**（`enableOnlineTotal`）：详情页统计行始终不显示「N 人在看」。

## 二、问题根因

- `showFsLockBtn` / `showFsScreenshotBtn` 属 **A 类断裂**：`storage_key.dart` 有键、设置页有 UI（写 `setKey`），但 `storage_pref.dart` **没有对应 getter**，功能代码无从读取。
- `enableOnlineTotal` 属 **B 类断裂**：`Pref.enableOnlineTotal` getter 已存在，但 **零消费者**——详情页从未读取该开关；且接口常量 `Api.onlineTotal = '/x/player/online/total'`（`api.dart:435`）虽已定义，**全项目零调用**，`lib/http/video.dart` 亦无对应请求方法。
- 另注：锁定按钮与截图逻辑在 `player_panel.dart` **本已实现**（`_toggleLock`/`_takeScreenshot`/`_buildLockIndicator`/`_ScreenshotPreviewDialog`），此前仅缺「按设置门控」这一步，并非功能缺失。

## 三、修复方法

| 文件 | 改动 |
|------|------|
| `lib/core/storage/storage_pref.dart` | 新增 getter `showFsLockBtn`（默认 `true`）、`showFsScreenshotBtn`（默认 `true`） |
| `lib/pages/video/player_panel.dart` | 控制栏锁定按钮改为 `if (!widget.fullscreen \|\| Pref.showFsLockBtn)` 门控；新增全屏截图按钮 `if (widget.fullscreen && Pref.showFsScreenshotBtn)`，`onPressed` 调 `_takeScreenshot()` |
| `lib/http/video.dart` | 新增 `VideoHttp.onlineTotal({aid, cid, bvid})` → `GET Api.onlineTotal`，`code==0` 且 `data['total']` 为 String 非空则 `Success(total)`，否则 `Success(null)` |
| `lib/pages/video/detail_page.dart` | 新增字段 `_onlineTotal`；`_loadDetail` 成功分支内 `if (Pref.enableOnlineTotal) unawaited(_loadOnlineTotal(aid, cid))`；新增 `_loadOnlineTotal`；`_buildInfoSection` 统计行末尾 `if (Pref.enableOnlineTotal && _onlineTotal != null) Text('$_onlineTotal 人在看', ...)` |

设计分寸：

- 锁定按钮语义为「非全屏常显、全屏时可关」——非全屏一律显示（不影响普通窗口操作），仅全屏时受开关约束；截图按钮仅在**全屏**时按开关显示，与设置项命名（"全屏显示截图按钮"）严格对齐。
- 在线人数为**增强展示**：开关关、接口失败或 `total` 为空时静默不显示，绝不阻塞详情渲染（`unawaited` 并发拉取）。

## 五、遗留与踩坑

- **cid 非空提升未生效**：`_loadDetail` 内 `if (cid != null)` 块中 `_loadOnlineTotal(res.aid, cid)` 仍报 `int? → int`（局部变量未被 promote）。修法：方法签名放宽为 `int? cid` 并在内部判 `cid == null || cid <= 0`，避免依赖提升。
- **grep 工具对该大文件（detail_page.dart）返回空**：`grep`/`grep -A` 对 `_loadOnlineTotal`、`onlineTotal` 均返回空但 `read_file` 可见内容；改用 bash `grep -n` 正确定位（工具异常记录在案）。
- **在线人数 UI 位置为新增设计**：PiliPlus 原版无此展示位，本实现落在详情页信息区统计行末尾，属项目自有设计，需 CVO 实机确认观感。
- 二次编辑同一文件需先 `read_file` 再改，否则报 "modified externally since last read"。

## 六、总结

批次 5 补齐了三处断裂：两项全屏控件（A 类，补 getter + 门控）与在线人数（B 类，getter 已存但从未被消费、接口常量从未被调用）。核心教训有二：其一，功能代码存在 ≠ 已接线，门控缺失同样表现为"设置不生效"；其二，Dart 局部可空变量的类型提升在跨语句/特定结构下可能失效，方法入口显式判空比依赖提升更稳。本批已通过 analyze 0 issue 与 debug/release 双编译，代码提交 `ea379a1`，等待 CVO 实机验收。
