## 1. 分析根因

### 1.1 现象描述（用户实机验收反馈）

1. **预览评论图片时视频播放被打断**（打开画廊即暂停，应保持播放）；
2. **预览界面的操作控件会被隐藏**（顶栏：序号/保存/复制/关闭；左右翻页箭头）。

### 1.2 取证证据

**（a）Flutter SDK 路由观察者语义**（`D:\flutter\packages\flutter\lib\src\widgets\routes.dart`，`RouteObserver` 实现，Flutter 3.47.0）：

```dart
@override
void didPush(Route<dynamic> route, Route<dynamic>? previousRoute) {
  if (route is R && previousRoute is R) {   // ← 关键门槛：新路由必须同为 R
    final Set<RouteAware>? previousSubscribers = _listeners[previousRoute];
    if (previousSubscribers != null) {
      for (final RouteAware routeAware in previousSubscribers) {
        routeAware.didPushNext();
      }
    }
  }
}
```

- 项目 `routeObserver` 类型为 `RouteObserver<PageRoute<dynamic>>`（`lib/main.dart:33`）；
- 播放页订阅方式：`if (route is PageRoute<dynamic>) routeObserver.subscribe(this, route);`（`video/detail_page.dart:161`、`bangumi/bangumi_player_page.dart` 同款）。

**（b）画廊原实现**：`showImageGallery` 使用 `PageRouteBuilder`（**PageRoute 子类**）压栈 →
`route is R && previousRoute is R` 成立 → 派发 `didPushNext()`：

- `video/detail_page.dart:215` / `bangumi_player_page.dart:191` 的 `didPushNext()` 执行
  `ctrl.pause()` + `ctrl.detachListeners()` + 上报进度（设计意图是"离开本页"，但**图片预览只是浮层**，被误判为离页）；
- 关闭画廊触发 `didPopNext()` → `ctrl.attachListeners()` 并按 `_wasPlaying` 恢复 + `reloadDanmaku()` 弹幕重建。

**（c）控件隐藏机制**：`_ImageGalleryViewerState._showControls`（初值 true）由
`_GalleryItemView.onTapUp → onToggleControls` **点按切换**（图片区域内单击即隐藏；全文件无任何计时器，
即不存在"自动隐藏"，实际由点按触发）。

### 1.3 根因链

```
showImageGallery 以 PageRouteBuilder（PageRoute）压栈
  → RouteObserver<PageRoute> 判定"页面被覆盖"派发 didPushNext / 关闭时 didPopNext
  → 播放页执行 离页暂停 + 卸载监听 / 回页恢复 + 弹幕重建
  → 预览图片打断播放；返回时产生不必要的重载链路
控件隐藏：sole 由 _showControls 的点按切换驱动（单击图片区域即隐藏，无恢复提示）
```

## 2. 设计修复计划

### 2.1 方案与关键决策

| # | 决策 | 依据 / 取舍 |
|---|---|---|
| 1 | `showImageGallery` 改用新增的私有 `_ImageGalleryRoute extends PopupRoute<void>` 承载 | `PopupRoute` 非 `PageRoute` → 不再命中 `route is R` 门槛，**完全绕开** didPushNext/didPopNext；SDK 中 `PopupRoute` 本身即 `opaque=false + maintainState=true`，与"全屏浮层"定位一致 |
| 2 | 原体验全保留：280ms 渐入 / 240ms 渐出、透明屏障（`barrierDismissible`）、点击黑边关闭、Esc/←→、长按菜单、双击缩放 | 只替换路由基类，不改任何交互 |
| 3 | **控件常显**：移除 `_showControls` 状态与 `onToggleControls` 全管线；顶栏无条件下渲染，左右箭头保留"多图且非边界"条件 | 用户明确要求"操作不应自动隐藏"；"点击图片外黑边关闭"保留 |
| 4 | 备选方案（已评估，放弃）：① 全局标志位让 `didPushNext` 跳过暂停（跨层耦合）；② 自定义 NavigatorObserver 暴露栈顶路由（复杂度高）；③ Overlay 承载画廊（需重写全部 pop/dispose 逻辑） | PopupRoute 方案零跨层耦合、最小改动面、语义正确（浮层不属于页面导航） |
| 5 | 影响面：全部 `showImageGallery` 调用方（视频/番剧/文章/动态/空间）一致生效 | 统一语义：预览图片是浮层行为，不应触发任何"离页/回页"生命周期 |

### 2.2 关键代码

