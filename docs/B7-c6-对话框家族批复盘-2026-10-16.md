# B7-c6-1a 对话框家族批复盘（2026-10-16）

> 批次：b7-c6（杂项残点批）首子批 · 起点 HEAD `73d3e35` · 闸门 **61 → 52**

## 1. 现象（要解决的问题）

b7-c5 收官后，`lib/` 内仍有 **61 个文件** import `package:material_ui/material_ui.dart`。
其中处数最多、且几乎每页都要用到的残留符号是 **`AlertDialog`（19 处）** 与
**`Dialog`（6 处，集中于 `MiuixDialogShell`）**。要退役 `material_ui`，必须先为「对话框
内容容器」建立零-material 替身，并把 `AlertDialog` 全族切过去。

## 2. 定因（为什么这样改）

- **`Dialog` / `AlertDialog` 是纯布局容器**，不改交互语义：路由（遮罩、
  `barrierDismissible`、淡入缩放转场）已由 `AppDialogRoute`（`core/shell/app_dialogs.dart`）
  承担，`AppDialogRoute.buildPage` 已提供
  `Material(type: MaterialType.transparency)` 透明祖先 ⇒ 容器层可安全去 Material。
- **零视觉变化是硬口径**（`coding-conventions.md`：机械替换批次以零视觉变化为验收目标）。
  故替身按 `material_ui` 1.5.0 的 `dialog.dart` 真值**逐项复刻**，而非直接套 Miuix 观感。
- 项目最终观感由 `app_theme.dart` 的 `dialogTheme` 覆写决定：
  `elevation: 0` + `_miuixRadiusLarge = (14 × 1.15).roundToDouble() = 16`，与
  `AppShapes.miuix.large = Radius.circular(16)` **同值**；背景 `surfaceContainerHigh`。
  ⇒ 替身取 `tokens.shapes.large` / `AppPalette.surfaceContainerHigh` 即零漂移。

## 5. 遗留与踩坑

1. **11 个已迁移文件仍保留 material import**：因仍用 `SimpleDialog`（13）/ `ChoiceChip`（7）/
   `Scaffold`（6）/ `TextField` / `Scrollbar` / `AppBar` 等，归 b7-c6 后续子批（见
   `scratch/plan_b7c6.md`）。
2. **`Wrap` 替代 `OverflowBar`**：M3 下 `OverflowBar.spacing = (buttonPadding ?? 16)/2 = 8`；
   现有调用点动作数 ≤ 3 不会触发换行，`Wrap(runSpacing: 0)` 单行等价。若将来出现 ≥4 个宽动作，
   需回到溢流换行语义。
3. **`AppDialogShell` 表面用 `DecoratedBox`**：项目 `dialogTheme` 的 `elevation` 已为 0 且
   shadow/tint 透明 ⇒ 无阴影差异。若上游主题改回有阴影，此处需补阴影绘制（当前 `AppDialogRoute`
   场景阴影由 `MiuixSurface` 承担）。
4. **探针必须还原**：11 个保留文件中被临时改写 import 的已全部自动还原，未留死代码。
5. **弹层 1px 描边口径**（`MiuixDialogShell` / Toast）仍未统一，属弹层材质收口后续批次，非本批范围。
6. **环境**：`flutter test` / `flutter build` 在本机需注入 `LOCALAPPDATA` / `APPDATA` /
   `PROGRAMFILES(X86)` / `HOME` / `USERPROFILE`（否则 `test_core/_globalConfigPath` 空崩溃）。
