## 3. 方案

### 3.1 新增共用锚定浮层组件（P4 单点定义）

`lib/ui/components/app_anchored_popup.dart`（**新增**）：

- `AppAnchoredPopup({anchor, child, gap=8, edge=8})`：作为 `Stack` 直接子节点使用（内部 `Positioned.fill` + `CustomSingleChildLayout`；组件自身无渲染对象，不破坏 `Positioned` 的父级 Stack 校验）。
- 定位委托 `_AppAnchoredPopupLayout`：**上方优先** → 上方放不下翻转到下方 → 两轴 `clamp` 进 `edge` 边距（同 `app_tooltip` / `miuix_context_menu` 既定范式）。
- 锚点取矩形助手：`anchorRectOf(anchorContext, ancestorContext:)` 与 `anchorRectInRootOverlay(anchorContext)`（任一 RenderObject 未就绪返回 null ⇒ 调用方跳过）。
- 该组件由**音量弹层与投币浮层共用**，避免两处各写一份定位数学。

### 3.3 接线过程中修掉的分析器问题

`bangumi_player_page.dart:2296` 与 `video_interaction_mixin.dart:301`。

## 6. 遗留与踩坑

1. **「对齐官方网页」为姿态复刻而非 1:1**：检索未取得官方投币浮层的视觉稿（仅操作流程说明），
   故按公开结构复刻 + 用户确认的形态（金币图形双选 / 锚定按钮上方）落地；金币图形复用项目
   `AppIcons.coin(active:)`（与互动行投币按钮同源字形），非 B 站官方金币位图。实机若观感有差，可再一轮微调。
2. **锚点坐标系差异**：音量弹层锚点取"面板自身坐标系"（弹层与页面同栈），投币浮层锚点取"根 Overlay 坐标系"
   （浮层独占整页）；二者由 `AppAnchoredPopup` 的同一委托定位，仅取矩形助手不同。
3. **未动范围**：`Material(` 全库余 9 处仍归 c6-5；过渡主题归 b7-e；`TextInputAction` 归输入组件层。本轮零涉及。
4. **`dart format` 全程未跑**（项目硬约束）；工作副本 `LF will be replaced by CRLF` 为既有 EOL 混合现象，非错误。
5. **进程占用**：`MSB3026` 只出现在**用户端仍开着上一版实例**时；关闭旧窗口后复跑 release 可得零告警日志。
