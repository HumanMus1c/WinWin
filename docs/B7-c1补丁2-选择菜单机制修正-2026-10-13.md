# B7-c1 补丁#2 复盘：文本选择右键菜单机制修正 — 2026-10-13

> 承接 b7-c1 补丁#1（`e0e0943`）：文章页右键菜单 Miuix 化首版未生效
> （复测仍为 cupertino 默认工具栏），本补丁校正选择控件版本后真正生效。
> 回滚基准：上一提交 `269bb9f`（本补丁改动直接落于其上）。

## 1. 现象描述（复测反馈）

补丁#1 交付后复测：文章页右键菜单**仍为 "Copy / Select all" 英文样式**，
与改动前几乎无差异——Miuix 面板（"文本操作"标题 + 中文条目）未出现。

## 2. 根因

**机制误判（Flutter 3.47 的迁移口径）**：`SelectableRegion.contextMenuBuilder`
**仅在 `selectionControls` 混入 `TextSelectionHandleControls` 时被采用**：

- `selectable_region.dart` 的 `_showToolbar`：`selectionControls is! TextSelectionHandleControls`
  时走 `showToolbar()`（控件自带 `buildToolbar` 默认路径），`is` 时才把
  `widget.contextMenuBuilder` 交给 `_contextMenuController`；
- `SelectionOverlay.toolbarIsVisible` 三元同构（Handle 版 → `_contextMenuController`；
  其它 → `_toolbar`）；
- SDK 注释原文：混入 `TextSelectionHandleControls` 后"本控件**不管工具栏**、
  交给 `contextMenuBuilder`"。
- 补丁#1 传入的是**非 Handle 版** `cupertinoDesktopTextSelectionControls` →
  框架忽略 builder、回退到控件自带 cupertino 桌面工具栏（即复测所见的
  "Copy / Select all"）。

**钉死过程**：最小复现测试（Windows 平台覆写 + 鼠标拖选 + 选区右键）在测试
环境完整复刻真机症状（实测渲染文本出现 "Copy" 而非"文本操作"）；换用 Handle
版控件后，同一测试转为出现"文本操作 / 复制 / 全选"。

## 3. 修复方案

- `article_page.dart`：`selectionControls` 由 `cupertinoDesktopTextSelectionControls`
  改为 **`cupertinoDesktopTextSelectionHandleControls`**（同族控件 +
  `with TextSelectionHandleControls`，cupertino_ui 现成实例）——`contextMenuBuilder`
  即刻生效（补丁#1 的 Miuix 菜单构建器保持不变）；
- 新增回归测试 `test/ui/components/miuix_selection_context_menu_test.dart`：
  Windows 平台覆写 + 鼠标拖选 + 选区右键，断言出现 Miuix 菜单
  （"文本操作/复制/全选"）且不出现默认工具栏（"Copy/Select all"）。

## 4. 修复效果验证

- 新增回归测试：**通过**（修复前同测试可复现 "Copy"，修复后为 Miuix 菜单）；
- `dart analyze`：0/0；`flutter test`：**170/170 全绿**；

## 5. 遗留与踩坑

- **关键机制点（入库）**：要用 `SelectableRegion.contextMenuBuilder`，必须给
  `selectionControls` 传混入 `TextSelectionHandleControls` 的控件（cupertino_ui：
  `cupertinoDesktopTextSelectionHandleControls`）；普通控件会被忽略并回退到
  控件自带工具栏。
- 测试踩坑：`debugDefaultTargetPlatformOverride` 必须在**测试体内**恢复
  （框架的 foundation 变量校验先于 tearDown 执行，放 `addTearDown` 会报
  "foundation debug variable was changed"）。
- 补丁#1 复盘（`e0e0943`）保留为历史记录，其"待复测"结论以本复盘为准修正。
