WinWin · Toast 提示样式演示

三种改造方案、共 18 种样式。每张卡片内是静态实物预览，点「触发弹出」可在页面真实位置看到弹出动画与自动消失效果。 点击弹出中的 Toast 可立即关闭，鼠标悬停可暂停倒计时。

还原依据：Material 3 规范；toastification v3.2 源码（配色 / 圆角 / 间距为精确值）；motion_toast v2.16 与 awesome_snackbar_content 0.1.8 官方样式（高保真近似）。 本页为纯 HTML 静态模拟，非真实 Flutter 渲染，仅用于样式选型对比。

方案① · M3 原生 SnackBar 主题化 零依赖

只改 lib/theme/app_theme.dart 增加 SnackBarThemeData，全项目约 150 处 showSnackBar 调用点不用动，一次生效。以下 4 种为同一机制的不同主题配置。

现状 · 默认 SnackBar（fixed 全宽）

对比基线：现在程序里的黑长条。贴底、全宽、无圆角，M2 式直条观感。弹出位置：底部贴边。

floating · 深色反色卡

悬浮 + 12px 圆角 + 底部留距，仍用 M3 inverseSurface 深色面，保留高对比警示感。弹出位置：底部居中。

floating · 浅色高表面卡

改用 M3 surfaceContainerHigh 浅色面 + 前导图标，观感更轻、更现代，适合提示类信息。弹出位置：底部居中。

floating · 带动作按钮

深色卡 + 前导图标 + 右侧「撤销」动作（inversePrimary 高亮），适合可恢复操作。弹出位置：底部居中。

方案② · awesome_snackbar_content 彩色大卡 +1 依赖

保留现有 SnackBar 机制，只把 SnackBar 的 content 换成 AwesomeSnackbarContent（背景透明 + floating 时效果最佳）。 改动集中在统一入口层。弹出位置：底部居中。

Success · 成功

绿色系 #2D6A4F。左上悬浮圆徽章 + 白色标题 + 正文，左下气泡装饰、右上关闭。

Failure · 失败

红色系 #C72C41，结构同上。适合当前“请求错误”类提示的直接替代。

Warning · 警告

橙色系 #FCA652，结构同上。适合网络波动、区域限制等提醒。

Help · 帮助

蓝色系 #3282B8，结构同上。「?」徽章，适合操作引导与提示。

方案③-A · toastification 五种内置样式 +1 依赖 · 需封装入口

当前最主流的现代 Toast 库（1.29k likes / 20.5 万下载 / 维护良好）。五种样式均可搭配 success / error / warning / info 四色语义自动换色；支持队列、悬停暂停、拖拽关闭、进度条。 演示弹出位置：右上角（桌面端推荐，可任意配置）。

flat · 描边白卡

白底 + 1.5px 浅灰描边 + 彩色图标，最百搭的默认款。示例类型：error 红。

fillColored · 彩色实底

整卡彩色实底 + 白字白图标，强提醒。示例类型：success 绿。

flatColored · 彩边浅底

彩色描边 + 5% 主题色浅底 + 黑色图标文字，介于 flat 与 fillColored 之间。示例类型：warning 橙。

minimal · 侧条 + 进度条

白卡左侧 3px 彩条 + 底部自动消隐进度条，通知中心既视感；弹出时进度条会随剩余时间走完。示例类型：info 蓝。

simple · 单行轻提示

无图标、无装饰的单行白卡 + 关闭按钮，适合「已复制」这类极轻反馈。

方案③-B · motion_toast 五种类型 +1 依赖 · 需封装入口

动画表现更强的现代库（Material 3、23 天前刚更新）。大圆角彩色卡 + 左侧深色描边 + 图标呼吸脉冲动画， 内置五种语义类型。演示弹出位置：底部居中（默认从底部滑入）。

success · 成功

绿色卡 #33A852 + 对勾图标脉冲动画。停留约 3 秒。

error · 错误

红色卡 #E33B3B + 叉号图标，替代现在黑条错误提示的强视觉方案。

warning · 警告

橙色卡 #F19A36 + 感叹号图标，适合网络波动等场景。

info · 信息

蓝色卡 #3E82F1 + 信息图标，中性提示。

delete · 删除

深灰卡 #5F6368 + 垃圾桶图标，用于删除类操作反馈。

演示说明：点击卡片按钮触发弹出；弹出位置与自动关闭时长按各库/各配置的默认值模拟；点击弹出中的 Toast 立即关闭；悬停暂停倒计时。 另外支持 URL 参数自动触发（用于截图/联调）：?show=sb-float-dark,mt-error&hold=1。
