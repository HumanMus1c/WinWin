以下是本项目按分类制定的阶段性移植开发计划。

**设计准则**（Phase 7 起）：
- **前端布局**：优先采用 PiliPlus 项目的布局设计（`MainLayout` 三槽位 / `SimpleScaffold` / `CustomScrollView+Sliver` / 滚动联动 / 瀑布流）
- **控件美术**：优先采用 BiliPai 项目的美术设计，必须支持 **Material Design 3 / Miuix / iOS** 三种控件样式的热切换
- **三风格热切换架构**（参照 BiliPai）：`UiStyle` 单一枚子 → `InheritedUiStyle` 广播 → 每个自适应组件读取后用 `resolvePrimitiveRenderer()` 分发到 `IOS / MATERIAL3 / MIUIX` 三条渲染路径；Token 层（Color/Shape/Typography/Chrome）按风格解析
