## Phase 7 — 前端 UI 深化（对齐 BiliPai）

**目标**：在现有 Flutter 首页/我的页面的基础上，对齐 BiliPai 的交互细节和视觉效果。

**BiliPai 交互模式移植到 Flutter**：
- 顶栏滚动折叠：BiliPai 的 `headerOffsetHeightPx` 嵌套滚动机制 → Flutter `CustomScrollView` + `SliverAppBar` 的 `flexibleSpace` + 手动 offset 控制。顶栏随 feed 向上滚动时竖向位移消失，回滚时恢复，到顶自动展开。
- 分类标签滑动同步：BiliPai 的 `HorizontalPager` + `HomePagerSyncPolicy` 双向同步 → Flutter `TabBar` + `TabBarView`（已天然支持双向同步），加上 BiliPai 的分段控制样式（胶囊指示器 + 弹簧动画）。
- 视频卡片共享元素转场：BiliPai 的 `SharedTransitionProvider` → Flutter `Hero` widget。从卡片封面到详情页的形变过渡。
- 下拉刷新：BiliPai 的 CupertinoActivityIndicator 样式 → Flutter `RefreshIndicator` + 自定义 `CupertinoActivityIndicator` 指示器。
- 瀑布流网格：BiliPai 的 `LazyVerticalStaggeredGrid` → Flutter `waterfall_flow` 包（PiliPlus 已用）。
- 底部导航栏滚动隐藏：BiliPai 的 200px 滞后阈值 + 三模式（SCROLL_HIDE / ALWAYS_VISIBLE / ALWAYS_HIDDEN）→ Flutter `AnimatedSlide` + 滚动监听。
- 个人页面 iOS 风格内容卡片：BiliPai 的 `ProfileContentSheet`（20dp 圆角，向上覆盖壁纸 20dp）→ Flutter `SliverToBoxAdapter` + `ClipRRect`。
- 毛玻璃效果增强：BiliPai 的 `BlurBudgetPolicy`（按性能档位分配模糊预算）+ `BlurIntensityVisualPolicy`（模糊强度策略）→ Flutter `BackdropFilter` + 运行时 sigma 值动态调整。
- 预测性返回手势：BiliPai 的 4 种样式（SCALE/DEFAULT/AOSP/CLASSIC）→ Flutter `PopScope` + `predictiveBack` 配置。

**验证标准**：顶栏滚动折叠动画流畅、TabBar 与 TabBarView 双向同步、视频卡片到详情页 Hero 转场、下拉刷新 Cupertino 指示器、底部导航栏滚动隐藏/显示、个人页面圆角内容卡片覆盖壁纸。
